Repositório Supabase — Código de Referência

Aula 25 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

Um repositório que cumpre o mesmo contrato do adaptador em memória, agora gravando no Postgres do Supabase. O núcleo da aplicação não muda: só a linha de instanciação no server.js.

src/infra/db/supabase.js

// Início: cliente Supabase único para a API, usando a chave secreta que só existe no servidor
const { createClient } = require('@supabase/supabase-js');

const supabase = createClient(process.env.SUPABASE_URL, process.env.SUPABASE_SECRET_KEY, {
  auth: { persistSession: false }
});

module.exports = supabase;
// Fim de supabase.js

src/infra/repositories/TarefaSupabaseRepository.js

// Início: repositório que cumpre o contrato de tarefas consultando o Supabase
const supabase = require('../db/supabase');

class TarefaSupabaseRepository {
  // devolve todas as tarefas ordenadas por id
  async buscarTodos() {
    const { data, error } = await supabase.from('tarefas').select('id, titulo, feita').order('id');
    if (error) throw error;
    return data;
  }

  // devolve a tarefa do id ou null quando não existe
  async buscarPorId(id) {
    const { data, error } = await supabase
      .from('tarefas')
      .select('id, titulo, feita')
      .eq('id', id)
      .maybeSingle();
    if (error) throw error;
    return data;
  }

  // grava a tarefa e devolve a linha criada com id
  async salvar(tarefa) {
    const { data, error } = await supabase
      .from('tarefas')
      .insert({ titulo: tarefa.titulo, feita: tarefa.feita, projeto_id: tarefa.projetoId })
      .select('id, titulo, feita')
      .single();
    if (error) throw error;
    return data;
  }

  // devolve as tarefas com o nome do projeto numa única consulta
  async buscarComProjeto() {
    const { data, error } = await supabase.from('tarefas').select('id, titulo, projetos(nome)').order('id');
    if (error) throw error;
    return data;
  }
}

module.exports = TarefaSupabaseRepository;
// Fim de TarefaSupabaseRepository.js

server.js

// Início: ponto de entrada que escolhe o adaptador de dados na borda do sistema
require('dotenv').config();
const criarApp = require('./src/app');
const TarefaSupabaseRepository = require('./src/infra/repositories/TarefaSupabaseRepository');

const app = criarApp(new TarefaSupabaseRepository());
const PORTA = process.env.PORT || 3000;

app.listen(PORTA, () => console.log(`API ligada ao Supabase em http://localhost:${PORTA}`));
// Fim de server.js

Como rodar

  1. npm install @supabase/supabase-js dotenv
  2. Preencha SUPABASE_URL e SUPABASE_SECRET_KEY no .env
  3. node server.js
  4. Crie uma tarefa, reinicie a API e liste de novo

O que observar

  • A entidade Tarefa precisa carregar projetoId para que o repositório saiba em qual projeto gravar.
  • maybeSingle devolve null quando não acha; single devolveria erro — a escolha muda quem decide o 404.
  • A chave secreta ignora o RLS: é por isso que ela só pode existir no servidor e nunca num arquivo enviado ao navegador.
