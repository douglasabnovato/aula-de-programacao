Upload com Multer — Código de Referência

Aula 27 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

Uma rota que recebe foto e legenda em multipart/form-data, grava em disco com nome aleatório, e uma variação para várias fotos. Inclui o formulário HTML para testar sem ferramenta extra.

src/routes/anexos.routes.js

// Início: rota de anexo recebendo arquivo em multipart/form-data com Multer em disco
const crypto = require('crypto');
const path = require('path');
const express = require('express');
const multer = require('multer');

const armazenamento = multer.diskStorage({
  destination: 'uploads/',
  // gera um nome aleatório mantendo a extensão enviada (provisório: a próxima prática troca isso)
  filename(req, arquivo, callback) {
    callback(null, `${crypto.randomUUID()}${path.extname(arquivo.originalname).toLowerCase()}`);
  }
});

const upload = multer({ storage: armazenamento });
const router = express.Router();

// recebe uma foto e a legenda de uma tarefa
router.post('/tarefas/:id/anexos', upload.single('foto'), (req, res) => {
  if (!req.file) return res.status(400).json({ erro: 'Envie o arquivo no campo foto' });
  res.status(201).json({
    tarefaId: Number(req.params.id),
    legenda: req.body.legenda || null,
    arquivo: req.file.filename,
    tipoDeclarado: req.file.mimetype,
    tamanho: req.file.size
  });
});

// recebe até cinco fotos de uma vez
router.post('/tarefas/:id/anexos/lote', upload.array('fotos', 5), (req, res) => {
  res.status(201).json({ recebidos: req.files.map((f) => ({ arquivo: f.filename, tamanho: f.size })) });
});

module.exports = router;
// Fim de anexos.routes.js

Como rodar

  1. npm install multer e crie a pasta uploads/
  2. Registre o roteador com app.use(rotasAnexos)
  3. node server.js
  4. Abra public/teste-upload.html no navegador e envie uma imagem

O que observar

  • Sem enctype="multipart/form-data", o navegador manda só o nome do arquivo, e req.file chega vazio.
  • O nome passado a upload.single precisa ser igual ao name do input, ou o Multer recusa com Unexpected field.
  • A extensão ainda vem do nome original enviado pelo cliente — é o ponto fraco que a próxima atividade corrige.
