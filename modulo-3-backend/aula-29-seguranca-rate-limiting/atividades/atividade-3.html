Auditoria de Segurança — Código de Referência

Aula 29 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

Validação das variáveis de ambiente que impede a API de subir mal configurada, cabeçalhos ajustados para uma API JSON, o modelo .env.example e os scripts que juntam tudo num comando.

src/config/env.js

// Início: validação das variáveis de ambiente na subida da API
require('dotenv').config();
const { z } = require('zod');

const esquema = z.object({
  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  PORT: z.coerce.number().int().positive().default(3000),
  JWT_SECRET: z.string().min(32, { error: 'JWT_SECRET precisa de pelo menos 32 caracteres' }),
  SUPABASE_URL: z.url({ error: 'SUPABASE_URL precisa ser uma URL' }),
  SUPABASE_SECRET_KEY: z.string().min(1, { error: 'SUPABASE_SECRET_KEY é obrigatória' }),
  ORIGENS_PERMITIDAS: z.string().min(1, { error: 'ORIGENS_PERMITIDAS é obrigatória' })
});

const resultado = esquema.safeParse(process.env);

if (!resultado.success) {
  console.error('Configuração inválida — a API não vai subir:');
  resultado.error.issues.forEach((issue) => console.error(` - ${issue.path.join('.')}: ${issue.message}`));
  process.exit(1);
}

module.exports = Object.freeze(resultado.data);
// Fim de env.js

src/config/helmet.js

// Início: cabeçalhos de segurança ajustados para uma API que só devolve JSON
const helmet = require('helmet');

const cabecalhos = helmet({
  contentSecurityPolicy: {
    useDefaults: false,
    directives: {
      defaultSrc: ["'none'"],
      frameAncestors: ["'none'"]
    }
  },
  crossOriginResourcePolicy: { policy: 'same-site' }
});

module.exports = cabecalhos;
// Fim de helmet.js

package.json (trecho)

{
  "scripts": {
    "start": "node server.js",
    "test": "jest",
    "audit:prod": "npm audit --omit=dev --audit-level=high",
    "checar:env": "node -e \"require('./src/config/env')\"",
    "seguranca": "npm run audit:prod && npm run checar:env"
  }
}

.env.example

# Início: modelo das variáveis de ambiente — copie para .env e preencha
NODE_ENV=development
PORT=3000
JWT_SECRET=
SUPABASE_URL=
SUPABASE_SECRET_KEY=
ORIGENS_PERMITIDAS=http://localhost:5500,http://localhost:5173
# Fim de .env.example

Como rodar

  1. npm install zod helmet dotenv
  2. Importe src/config/env.js na primeira linha do server.js
  3. npm run seguranca
  4. Apague uma variável do .env e rode de novo

O que observar

  • A API que não sobe é melhor do que a API que sobe e falha no primeiro login às três da manhã.
  • --omit=dev olha só o que vai para produção; falha em ferramenta de teste entra em outra fila de prioridade.
  • A CSP default-src 'none' faz sentido para JSON; a página /docs da aula 24, se ficar no mesmo app, precisa de uma política própria.
