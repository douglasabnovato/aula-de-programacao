Contrato OpenAPI e Swagger UI — Código de Referência

Aula 24 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

Um documento OpenAPI 3.1 descrevendo as rotas de tarefas, com esquemas reutilizáveis e respostas de erro, servido como página navegável em /docs.

docs/openapi.yaml

# Início: contrato OpenAPI da API de tarefas
openapi: 3.1.0
info:
  title: API de Tarefas — ByteClass
  version: 1.0.0
  description: Contrato das rotas de tarefas usadas nas aulas 21 a 24.
servers:
  - url: http://localhost:3000
paths:
  /tarefas:
    get:
      summary: Lista todas as tarefas
      responses:
        '200':
          description: Lista de tarefas
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/Tarefa'
    post:
      summary: Cria uma tarefa
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [titulo]
              properties:
                titulo:
                  type: string
                  example: Ligar para fornecedor
      responses:
        '201':
          description: Tarefa criada
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Tarefa'
        '400':
          description: Título ausente ou vazio
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Erro'
  /tarefas/{id}:
    get:
      summary: Detalha uma tarefa
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: Tarefa encontrada
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Tarefa'
        '404':
          description: Tarefa não encontrada
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/Erro'
components:
  schemas:
    Tarefa:
      type: object
      properties:
        id:
          type: integer
          example: 1
        titulo:
          type: string
          example: Estudar testes
        feita:
          type: boolean
          example: false
    Erro:
      type: object
      properties:
        erro:
          type: string
          example: Tarefa não encontrada
# Fim de openapi.yaml

server.js

// Início: ponto de entrada com a documentação OpenAPI servida em /docs
require('dotenv').config();
const fs = require('fs');
const path = require('path');
const YAML = require('yaml');
const swaggerUi = require('swagger-ui-express');
const criarApp = require('./src/app');
const TarefaMemoriaRepository = require('./src/infra/repositories/TarefaMemoriaRepository');

const documento = YAML.parse(fs.readFileSync(path.join(__dirname, 'docs', 'openapi.yaml'), 'utf8'));
const app = criarApp(new TarefaMemoriaRepository([{ titulo: 'Estudar testes' }]));

app.use('/docs', swaggerUi.serve, swaggerUi.setup(documento));

const PORTA = process.env.PORT || 3000;
app.listen(PORTA, () => console.log(`API em http://localhost:${PORTA} — docs em /docs`));
// Fim de server.js

Como rodar

  1. npm install swagger-ui-express yaml
  2. Salve o contrato em docs/openapi.yaml
  3. node server.js
  4. Abra http://localhost:3000/docs e use Try it out

O que observar

  • O $ref evita repetir o formato de Tarefa em cada rota: muda num lugar, muda em todas.
  • Os status do contrato são os mesmos que os testes de integração verificam — contrato e teste contam a mesma história.
  • O YAML é sensível à indentação: dois espaços fora do lugar mudam o significado ou quebram a leitura.
