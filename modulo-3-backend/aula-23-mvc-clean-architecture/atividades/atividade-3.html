Aula 23 · Módulo 3: Backend e Banco de Dados · ByteClass

Como usar

Responda as nove perguntas olhando o código, não a intenção. Cada resposta é um fato verificável, não uma opinião.

Sinais de que falta camada

  1. O mesmo bloco de validação aparece em quantos arquivos?
  2. Para testar uma regra de negócio, é preciso subir o servidor? (sim = falta camada)
  3. Trocar o banco exigiria mexer em quantos arquivos?

Sinais de que sobra camada

  1. Quantos arquivos têm métodos que só repassam a chamada sem decidir nada?
  2. Quantos contratos têm exatamente uma implementação, sem previsão de segunda?
  3. Quantos arquivos é preciso abrir para seguir uma requisição de ponta a ponta? (acima de 6 é suspeito)

Sinais de risco

  1. Existe arquivo com mais de 200 linhas?
  2. Existe arquivo que importa tanto o framework web quanto o driver do banco?
  3. Alguém da equipe evita mexer em algum arquivo por medo? Qual?

Modelo de registro da decisão

## [D-01] Título da decisão            data
Contexto:     o que forçou a escolha
Alternativas: A, B, C — e por que A e C caíram
Escolha:      B
Custo aceito: o que fica pior por causa disso

O critério de parada

Camada se acrescenta quando a dor já apareceu duas vezes — não na primeira, que pode ser coincidência, e não na terceira, que já virou hábito.
