Checklist de Entrega e Deploy — Projeto Final

Aula 30 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

O checklist que o instrutor usa para conferir a entrega técnica, dividido em código, qualidade, segurança e publicação, mais o modelo de README que acompanha o repositório.

Código

  • Cada rota tem esquema de entrada, caso de uso e repositório separados.
  • Nenhuma rota tem try/catch repetido: os erros chegam ao middleware central.
  • Não há segredo escrito no código nem no histórico do Git.

Qualidade

  • npm test passa com um teste de sucesso e um de erro por rota.
  • O contrato OpenAPI tem as mesmas rotas e status que os testes verificam.
  • O log mostra uma linha JSON por requisição com requestId.

Segurança

  • npm run seguranca sem itens de gravidade alta.
  • CORS com lista de origens; rate limit no login e nas rotas caras.
  • RLS ligado nas tabelas com dados de usuário; chave secreta só no servidor.

Publicação no Render

  1. Crie o Web Service no plano gratuito ligado ao repositório
  2. Build command: npm install · Start command: node server.js
  3. Cadastre todas as variáveis do .env.example em Environment
  4. Confira o log do deploy e a URL pública com /docs
