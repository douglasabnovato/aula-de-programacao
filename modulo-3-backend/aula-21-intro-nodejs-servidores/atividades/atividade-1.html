Servidor HTTP Nativo — Código de Referência

Aula 21 · Módulo 3: Backend e Banco de Dados · ByteClass

O que esta atividade entrega

Um servidor HTTP escrito sem framework, respondendo duas rotas e devolvendo JSON. Roda com node server.js e responde em http://localhost:3000.

server.js

const http = require('http');

const PORTA = 3000;

const servidor = http.createServer((req, res) => {
  console.log(`${req.method} ${req.url}`);

  if (req.url === '/' && req.method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
    return res.end(JSON.stringify({ mensagem: 'Servidor no ar' }));
  }

  if (req.url === '/sobre' && req.method === 'GET') {
    res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' });
    return res.end(JSON.stringify({ projeto: 'ByteClass', aula: 21 }));
  }

  res.writeHead(404, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify({ erro: 'Rota não encontrada' }));
});

servidor.listen(PORTA, () => console.log(`Escutando em http://localhost:${PORTA}`));

Como rodar

  1. npm init -y
  2. Salve o código acima em server.js
  3. node server.js
  4. Abra http://localhost:3000 e depois /sobre

O que observar

  • O console.log imprime toda requisição — inclusive a do favicon que o navegador pede sozinho.
  • Sem o return antes de res.end, o código continuaria e tentaria responder duas vezes.
  • O charset=utf-8 é o que faz o acento aparecer certo.
