🟢 1. O que é Node.js e o Modelo de Execução

Antes de escrever um servidor, entender por que o Node existe: JavaScript fora do navegador, um processo só, e um laço de eventos que não trava esperando o disco ou a rede.

  • 📄 Introdução ao Node.js — documentação oficial O que o Node é, de onde vem e por que o modelo assíncrono define tudo que se escreve nele.
  • 📄 Módulo HTTP — API oficial do Node O módulo nativo que cria servidores: é ele que o Express embrulha por baixo do capô.
  • 📄 Sistema de Módulos do Node Como o require e o import resolvem arquivos, e por que a estrutura de pastas importa.
  • 📄 Métodos HTTP — MDN GET, POST, PUT, PATCH e DELETE: o vocabulário que o cliente usa para pedir coisas ao servidor.

Siga os 10 passos abaixo para construir a prática aplicando os conceitos do bloco:

  1. Configuração do Ambiente: confirme a instalação com node --version e crie a pasta meu-servidor na sua máquina.
  2. Iniciando o Projeto: rode npm init -y e abra o package.json gerado para entender cada campo.
  3. Arquivo de Entrada: crie server.js e importe o módulo nativo com const http = require('http').
  4. Criando o Servidor: use http.createServer((req, res) => {}) e guarde o retorno numa constante.
  5. A Primeira Resposta: dentro do callback, escreva o cabeçalho com res.writeHead(200) e finalize com res.end('Olá').

  7. Lendo a Requisição: imprima req.url e req.method no console e observe o que chega a cada acesso.
  8. Roteamento Manual: escreva um if que responda algo diferente para / e para /sobre.
  9. Respondendo JSON: troque o cabeçalho para application/json e devolva um objeto com JSON.stringify.
  10. Validação e Testes: teste as duas rotas no navegador, confirme o status 200 na aba Rede e registre o que aprendeu no README.

🚏 2. Express, Rotas e o Ciclo Requisição-Resposta

O servidor à mão mostra o mecanismo; o Express mostra por que ninguém escreve assim em produção. Rotas, parâmetros e o objeto de resposta como contrato com o cliente.

  • 📄 Express — Hello World oficial O menor servidor possível em Express, com a documentação em português.
  • 📄 Guia de Roteamento do Express Como declarar rotas, capturar parâmetros e encadear manipuladores.
  • 📄 Códigos de Status HTTP — MDN A lista completa com o significado de cada faixa: o que você devolve comunica intenção.
  • 📄 Anatomia de uma Mensagem HTTP — MDN Linha de início, cabeçalhos e corpo: o que exatamente viaja entre cliente e servidor.

Siga os 10 passos abaixo para construir a prática aplicando os conceitos do bloco:

  1. Configuração do Ambiente: na pasta do projeto, instale o framework com npm install express.
  2. Estrutura Base: crie app.js, importe o Express e inicialize com const app = express().
  3. Leitura de JSON: registre app.use(express.json()) para que o servidor entenda corpo em JSON.
  4. Estrutura de Dados: declare um array tarefas em memória com dois objetos de exemplo.
  5. Rota de Listagem: crie GET /tarefas devolvendo o array com res.json().
  6. Rota de Detalhe: crie GET /tarefas/:id usando req.params.id para encontrar um item.
  7. Tratando o Não Encontrado: quando o id não existir, responda 404 com uma mensagem clara.
  8. Rota de Criação: crie POST /tarefas lendo req.body e respondendo 201.
  9. Validação de Entrada: recuse corpo sem título com status 400 e uma mensagem explicando o motivo.
  10. Validação e Testes: teste as quatro rotas com o Thunder Client ou Insomnia e confira cada status devolvido.

🧱 3. Organização de Projeto e Variáveis de Ambiente

Um arquivo de 300 linhas funciona até a segunda semana. Aqui o projeto ganha pastas com responsabilidade definida, configuração fora do código e tratamento de erro num lugar só.

  • 📄 Middlewares no Express A peça que roda entre a requisição e a resposta: log, autenticação e validação vivem aqui.
  • 📄 Tratamento de Erros no Express Como capturar falhas num lugar só em vez de repetir try/catch em toda rota.
  • 📄 process.env — API oficial do Node De onde vêm as variáveis de ambiente e como o processo as enxerga.
  • 📄 The Twelve-Factor App — Configuração O princípio de separar configuração de código, escrito de forma curta e direta.

Siga os 10 passos abaixo para construir a prática aplicando os conceitos do bloco:

  1. Configuração do Ambiente: instale npm install dotenv e crie o arquivo .env na raiz.
  2. Protegendo o Segredo: crie um .gitignore e adicione .env e node_modules nele.
  3. Lendo a Configuração: carregue o dotenv no topo do app.js e leia a porta de process.env.PORT.
  4. Criando as Pastas: monte src/routes, src/controllers e src/services.
  5. Extraindo as Rotas: mova as declarações de rota para src/routes/tarefas.routes.js usando express.Router().
  6. Extraindo o Controlador: mova a lógica de cada rota para src/controllers/tarefas.controller.js.
  7. Extraindo o Serviço: deixe no serviço tudo que manipula o array, sem conhecer req nem res.
  8. Middleware de Log: escreva um middleware que imprime método, rota e horário de cada requisição.
  9. Erro Centralizado: registre um middleware de quatro argumentos que devolve 500 com mensagem padronizada.
  10. Validação e Testes: repita os testes da prática anterior e confirme que o comportamento não mudou — só a organização.
