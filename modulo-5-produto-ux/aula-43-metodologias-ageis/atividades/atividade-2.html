Sprint Goal — uma frase, não uma lista

"Ao fim desta sprint, o aluno consegue encontrar um projeto específico em menos de 15 segundos."

Repare que o objetivo não é "fazer os itens 1, 2 e 3". É o resultado que esses itens produzem juntos. Se na quarta-feira ficar claro que o item 2 não é necessário para o objetivo, ele sai — e a sprint continua válida.

Definition of Done

Um item só está pronto quando:
  [ ] funciona no Chrome e no Firefox, desktop e celular
  [ ] navegável só por teclado, com foco visível
  [ ] sem erro no console
  [ ] o README foi atualizado se o comportamento mudou
  [ ] o commit está no branch principal

DoD é um contrato da equipe com ela mesma, e vale para todos os itens. "Quase pronto" não existe.

Retrospectiva — três colunas, uma ação

MANTER                    MUDAR                      EXPERIMENTAR
testar no celular         estimar em horas           limitar a 3 itens
antes de fechar           (sempre erra)              simultâneos

AÇÃO PARA A PRÓXIMA SPRINT (uma só, com responsável):
  Trocar estimativa em horas por tamanho P/M/G — responsável: ___

Retrospectiva que gera cinco ações não gera nenhuma. Uma ação, com responsável e prazo, é o que muda o comportamento da próxima sprint.
