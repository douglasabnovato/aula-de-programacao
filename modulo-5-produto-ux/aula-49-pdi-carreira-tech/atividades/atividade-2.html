# PDI — Carla

## Meta de 12 meses
Ser considerada pelo time capaz de entregar uma funcionalidade
completa, do banco à tela, sem pair obrigatório.

## Metas
### M1 — API
Antes: "fazer curso de Node"
Depois: entregar sozinha um endpoint usado em produção.
Hipótese: acredito que assumir o endpoint de relatórios com revisão do sênior
  vai me levar a construir APIs sozinha. Vou saber porque o próximo endpoint
  terá no máximo 2 rodadas de correção no PR.
Evidência: PR aprovado + endpoint em produção. Verificação: 30/11.
Aprender: prática — endpoint de relatórios | pessoa — pair semanal com o sênior
          | estudo — documentação oficial do Express.

### M2 — Testes
Depois: todo PR meu tem teste do caminho principal e de um erro.
Evidência: 5 PRs seguidos com testes aprovados. Verificação: 31/10.

### M3 — Revisão de código
Depois: revisar 2 PRs por semana com comentário que gera mudança.
Evidência: 8 revisões com pelo menos 1 sugestão aceita. Verificação: 31/12.

## Roadmap
| Agora (out–nov) | Próximo (dez–jan)   | Depois (fev+)            |
|-----------------|---------------------|--------------------------|
| M2 Testes       | M1 API              | SQL avançado             |
| (destrava M1)   | M3 Revisão          | Explicar decisões        |

Capacidade: 3h/semana de desenvolvimento pessoal (medido na aula 48).

Como usar

  1. Troque cada atividade pela mudança que ela deveria causar.
  2. Escreva a hipótese e a evidência antes de começar.
  3. Coloque em Agora a meta que destrava as outras.

O que observar

  • O curso não sumiu: virou uma das formas de aprender dentro da meta.
  • M2 veio antes de M1 porque o time exige teste em todo PR de API.
  • Cada meta tem data de verificação, não só prazo final.
