Checklist de Acessibilidade — o Mínimo Obrigatório

Aula 42 · Módulo 5: Produto, UX e Agilidade · ByteClass

O teste que leva dois minutos

Guarde o mouse. Percorra a tela inteira com Tab e execute a tarefa principal. Se você não conseguir, ninguém que depende do teclado vai conseguir.

1. Foco visível — o erro mais comum

/* NUNCA: */
*:focus { outline: none; }

/* SEMPRE: */
:focus-visible {
  outline: 3px solid var(--cor-acao);
  outline-offset: 3px;
}

:focus-visible mostra o contorno para quem usa teclado e não mostra para quem clica com o mouse — que é exatamente o motivo pelo qual as pessoas removiam o outline.

2. A tag certa entrega acessibilidade de graça

<!-- Não é focável, não responde a Enter nem Espaço,
     não é anunciado como botão: -->
<div class="botao" onclick="salvar()">Salvar</div>

<!-- Focável, teclado funciona, leitor anuncia "botão Salvar": -->
<button type="button" onclick="salvar()">Salvar</button>

3. Rótulo ligado ao campo

<label for="email">E-mail</label>
<input id="email" type="email" autocomplete="email">

<!-- Ou, quando o label embrulha: -->
<label>E-mail <input type="email"></label>

Placeholder não é rótulo: some quando a pessoa digita, e o leitor de tela pode não anunciar.

4. Texto alternativo com critério

<!-- Informativa: descreva a informação, não a imagem -->
<img src="grafico.png" alt="Vendas subiram de 120 para 340 no trimestre">

<!-- Decorativa: alt vazio, para o leitor pular -->
<img src="ornamento.svg" alt="">

<!-- Errado: o leitor anuncia "imagem imagem-1-ponto-png" -->
<img src="imagem-1.png">

Checklist de cinco itens antes de publicar

  1. Consigo completar a tarefa só com teclado?
  2. Vejo onde o foco está, o tempo todo?
  3. Todo campo tem rótulo ligado?
  4. Todo texto passa de 4.5:1 de contraste?
  5. Cliquei em algum <div> que deveria ser <button>?
