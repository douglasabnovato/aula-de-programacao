Tokens: Primitivo, Semântico e Tema

Aula 42 · Módulo 5: Produto, UX e Agilidade · ByteClass

O diagnóstico

# Quantas cores literais existem fora do :root?
grep -oE "#[0-9a-fA-F]{3,8}|rgba?\([^)]*\)" style.css | sort | uniq -c | sort -rn

Dois níveis, e a seta aponta num sentido só

:root {
  /* Primitivos: nomeados pelo valor. Não são usados direto nos componentes. */
  --verde-400: #00ff66;
  --verde-600: #00cc52;
  --cinza-050: #ffffff;
  --cinza-500: #8b949e;
  --cinza-850: #161b22;
  --cinza-900: #0d1117;
  --cinza-700: #30363d;

  /* Semânticos: nomeados pela função. São estes que o CSS usa. */
  --cor-fundo:      var(--cinza-900);
  --cor-superficie: var(--cinza-850);
  --cor-borda:      var(--cinza-700);
  --cor-texto:      var(--cinza-050);
  --cor-texto-fraco:var(--cinza-500);
  --cor-acao:       var(--verde-400);
  --cor-acao-forte: var(--verde-600);
}

Por que dois níveis

Com um nível só, trocar a cor da marca vira busca e substituição em todo o projeto. Com dois, você troca --cor-acao em uma linha. E o tema alternativo redefine apenas os semânticos — os primitivos continuam iguais.

Tema claro, sem duplicar CSS

@media (prefers-color-scheme: light) {
  :root {
    --cor-fundo:       var(--cinza-050);
    --cor-superficie:  #f3f5f8;
    --cor-borda:       #d8dee6;
    --cor-texto:       var(--cinza-900);
    --cor-texto-fraco: #5b6673;
    --cor-acao:        var(--verde-600);
  }
}

Nenhuma regra de componente mudou. Só os sete semânticos foram redefinidos.

A métrica de saúde

Depois da refatoração, rode o grep de novo. Toda cor literal deve estar dentro do :root. Qualquer uma fora é uma decisão que escapou do sistema.
