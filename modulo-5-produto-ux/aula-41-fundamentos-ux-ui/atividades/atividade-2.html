Escala Tipográfica e de Espaçamento

Aula 41 · Módulo 5: Produto, UX e Agilidade · ByteClass

O diagnóstico que quase sempre dá o mesmo resultado

# Conte quantos tamanhos de fonte existem no seu CSS:
grep -oE "font-size: *[0-9.]+(px|rem|em)" style.css | sort -u | wc -l

Se voltar mais de seis, não existe escala — existe uma decisão avulsa por elemento.

Cinco tamanhos resolvem quase tudo

:root {
  --txt-xs:  0.78rem;   /* legenda, metadado */
  --txt-sm:  0.88rem;   /* texto secundário */
  --txt-md:  1rem;      /* corpo */
  --txt-lg:  1.32rem;   /* título de card */
  --txt-xl:  clamp(1.6rem, 3vw, 2.4rem);  /* título de página */
}

Espaçamento em múltiplos de 4

:root {
  --esp-1: 4px;
  --esp-2: 8px;
  --esp-3: 16px;
  --esp-4: 24px;
  --esp-5: 40px;
  --esp-6: 64px;
}

A régua elimina o margin-top: 13px que apareceu porque ficou bom naquele dia.

Três regras que mudam a percepção na hora

  • Proximidade: o espaço entre o rótulo e seu campo tem que ser menor que o espaço entre um campo e o próximo. Quando é igual, a tela parece uma lista solta.
  • Medida: linha de texto acima de 80 caracteres cansa. max-width: 65ch resolve.
  • Altura de linha: corpo de texto pede line-height: 1.5; título grande pede menos, perto de 1.15.

Contraste: o número, não a impressão

Texto normal:     mínimo 4.5:1
Texto grande:     mínimo 3:1
Componente de UI: mínimo 3:1

O DevTools do navegador mostra a razão ao inspecionar a cor. Cinza-claro sobre branco costuma ficar em 2.8:1 — reprova.
