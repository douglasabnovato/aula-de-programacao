# Tree testing — 3 pessoas, árvore v1

| Tarefa                                             | Sucesso | Primeiro clique errado     |
|----------------------------------------------------|---------|----------------------------|
| Cabo para ligar o notebook na TV                   | 1 de 3  | "TV e casa" (2 pessoas)    |
| Algo para ouvir música sem fio na academia         | 3 de 3  | —                          |
| Algo para o celular não quebrar se cair            | 3 de 3  | —                          |
| Carregador que funcione no notebook e no celular   | 2 de 3  | "Computadores" (1 pessoa)  |
| Algo para digitar confortável no notebook          | 3 de 3  | —                          |

## Correção (árvore v2)
- "Cabos e carregadores" também aparece dentro de "TV e casa" (polihierarquia)
  com o atalho "Cabos para TV".

Como usar

  1. Rode o card sorting antes de desenhar qualquer menu.
  2. Monte a árvore com os nomes que mais se repetiram.
  3. Escreva tarefas de tree testing sem usar as palavras dos rótulos.

O que observar

  • O rótulo antigo "Periféricos e Conectividade" não apareceu em nenhum grupo dos participantes.
  • O tree testing encontrou um problema que o card sorting não mostrou: cabo de TV mora em dois lugares na cabeça das pessoas.
  • Cinco pessoas bastaram para ver padrão claro nos agrupamentos principais.
