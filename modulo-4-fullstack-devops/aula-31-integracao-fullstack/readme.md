# ⚡ Ementa da Aula 31: Integração Fullstack (Frontend + Backend) | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa liga as duas metades que o aluno aprendeu separadas: o React do Módulo 2 conversando com a API do Módulo 3, incluindo os três estados que todo consumo de rede tem e quase ninguém trata.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: O Contrato entre Frontend e Backend
* **Contrato de API:** rota, método, formato de entrada e de saída acordados antes do código.
* **Formato de erro padronizado:** por que toda falha deve ter a mesma forma de resposta.
* **Ambientes:** a mesma aplicação apontando para API local e API publicada.

### 2. Bloco 2: Os Três Estados de Toda Chamada de Rede
* **Estado de carregamento:** o que mostrar enquanto a resposta não chegou.
* **Estado de erro:** diferenciar falha de rede, erro do cliente e erro do servidor.
* **Estado vazio:** a lista que voltou certa e sem itens não é erro, e precisa de tela própria.

### 3. Bloco 3: Publicando as Duas Metades
* **Build do frontend:** o que o Vite gera e por que a variável de ambiente entra no build, não em execução.
* **Deploy separado:** frontend estático e API em serviços diferentes, cada um com seu endereço.
* **CORS em produção:** por que a origem muda e precisa ser reconfigurada.
