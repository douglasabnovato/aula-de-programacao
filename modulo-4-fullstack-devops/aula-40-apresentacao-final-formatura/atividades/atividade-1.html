# Agenda Lírio

Agendamento online para o salão fictício Studio Lírio: acaba com horários
sobrepostos e remarcações perdidas no caderno da recepção.

![Fluxo de criação de agendamento, do login à agenda do dia](docs/fluxo.gif)

**Aplicação:** https://agenda-lirio.vercel.app
**Contrato da API:** [docs/openapi.yaml](docs/openapi.yaml)
**Decisões técnicas:** [docs/adr/](docs/adr/)

## O problema
A recepção perdia cerca de 8 clientes por semana por conflito de horário.

## O que o sistema faz
- Login da recepção
- Agenda do dia por profissional
- Criação, remarcação e cancelamento sem sobreposição
- Consulta pública de horários livres

## Tecnologias e por quê
| Parte     | Tecnologia           | Por quê                                                     |
|-----------|----------------------|-------------------------------------------------------------|
| Frontend  | React + Vite         | componentes reaproveitados entre agenda e formulário        |
| API       | Node + Express       | mesma linguagem do front e ecossistema visto no curso       |
| Banco     | PostgreSQL           | restrição de não sobreposição garantida no próprio banco    |
| Deploy    | Vercel, Render, Neon | planos gratuitos, deploy a cada push na main                |

## Como rodar localmente
```
git clone <url-do-repositorio>
cp api/.env.example api/.env
cp web/.env.example web/.env
docker compose up --build
```

## Limites conhecidos
- A API no plano gratuito hiberna; a primeira requisição pode demorar.
- Sem lembrete automático por mensagem (fora do escopo do MVP).

## Próximos passos
- Lembrete por e-mail um dia antes do horário.
- Relatório mensal de ocupação por profissional.

## Equipe
- Nome Sobrenome — API e banco — github.com/usuario
- Nome Sobrenome — frontend e deploy — github.com/usuario

Versão 1.0 apresentada na formatura ByteClass.
