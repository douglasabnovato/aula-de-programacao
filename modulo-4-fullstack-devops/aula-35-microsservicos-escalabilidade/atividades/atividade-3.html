Réplicas Sem Estado atrás do Nginx — Código de Referência

Aula 35 · Módulo 4: Fullstack, DevOps e Projeto Final · ByteClass

O que esta atividade entrega

Três cópias da mesma API atrás de um Nginx na porta 8080, com o contador de visitas guardado no Redis. Cada resposta mostra qual réplica atendeu e o total compartilhado.

api/server.js

// Início: server.js — API sem estado; o contador vive no Redis, não na memória do processo
const express = require('express');
const os = require('os');
const { createClient } = require('redis');

const app = express();
const redis = createClient({ url: process.env.REDIS_URL || 'redis://redis:6379' });

// soma uma visita no Redis e devolve qual réplica respondeu
app.get('/visitas', async (req, res, next) => {
  try {
    const total = await redis.incr('visitas');
    res.json({ replica: os.hostname(), total });
  } catch (erro) {
    next(erro);
  }
});

// trata falhas de forma padronizada
app.use((erro, req, res, next) => {
  console.error(erro.message);
  res.status(500).json({ erro: 'Erro interno' });
});

// conecta ao Redis antes de aceitar requisições
async function iniciar() {
  redis.on('error', (erro) => console.error('Redis:', erro.message));
  await redis.connect();
  app.listen(3000, () => console.log(`Réplica ${os.hostname()} ouvindo na porta 3000`));
}

iniciar();
// Fim de server.js

nginx.conf

# Início: nginx.conf — distribui as requisições entre as réplicas do serviço api
events {}

http {
  upstream api_replicas {
    server api:3000;
  }

  server {
    listen 80;

    location / {
      proxy_pass http://api_replicas;
      proxy_set_header Host $host;
      proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
  }
}
# Fim de nginx.conf

compose.yaml

# Início: compose.yaml — três réplicas da API, Redis compartilhado e Nginx na frente
services:
  api:
    build: ./api
    environment:
      REDIS_URL: redis://redis:6379
    deploy:
      replicas: 3
    depends_on:
      - redis

  redis:
    image: redis:7-alpine

  nginx:
    image: nginx:1.27-alpine
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    ports:
      - "8080:80"
    depends_on:
      - api
# Fim de compose.yaml

Como rodar

  1. Em api/, rode npm init -y e npm install express redis e crie o Dockerfile da aula 32
  2. Na raiz, rode docker compose up --build
  3. Chame várias vezes: for i in $(seq 10); do curl -s localhost:8080/visitas; echo; done
  4. Aumente a escala com docker compose up -d --scale api=5 e rode docker compose restart nginx

O que observar

  • A API não tem ports: com três réplicas, três contêineres tentariam publicar a mesma porta do host.
  • O Nginx resolve o nome api na subida e recebe o endereço de todas as réplicas; réplicas novas só entram depois de reiniciá-lo.
  • Troque o redis.incr por uma variável em memória e repita o laço: o total passa a depender de qual réplica respondeu.
