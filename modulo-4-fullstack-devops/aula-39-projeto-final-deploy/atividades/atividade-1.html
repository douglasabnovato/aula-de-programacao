Prontidão para Produção — Checklist

Aula 39 · Módulo 4: Fullstack, DevOps e Projeto Final · ByteClass

O que esta atividade entrega

O checklist que a dupla marca antes do primeiro deploy e o trecho da API que concentra as mudanças de configuração para produção.

Checklist de configuração

  • [ ] Porta lida de process.env.PORT.
  • [ ] Banco lido só de DATABASE_URL, com SSL em produção.
  • [ ] JWT_SECRET com pelo menos 32 caracteres aleatórios, diferente do de desenvolvimento.
  • [ ] CORS com origem de ORIGEM_FRONT, sem *.
  • [ ] .env.example da API e do frontend listando todas as variáveis.

Checklist de segurança

  • [ ] helmet() registrado antes das rotas.
  • [ ] Middleware de erro devolve mensagem genérica e requestId, sem pilha.
  • [ ] Nenhum segredo no histórico do Git (confira com git log -p | grep -i senha).
  • [ ] npm audit --audit-level=high sem alertas.

Checklist de operação

  • [ ] npm start roda sem dependências de desenvolvimento.
  • [ ] npm run migrar aplica migrações num banco vazio do zero.
  • [ ] /saude/vivo e /saude/pronto respondendo.
  • [ ] Logs em JSON na saída padrão.

api/src/config.js

// Início: config.js — toda configuração da API num lugar, lida do ambiente
const producao = process.env.NODE_ENV === 'production';

// lê uma variável obrigatória e encerra cedo se ela faltar
function obrigatoria(nome) {
  const valor = process.env[nome];
  if (!valor) {
    console.error(`Variável de ambiente ausente: ${nome}`);
    process.exit(1);
  }
  return valor;
}

const config = {
  producao,
  porta: Number(process.env.PORT || 3000),
  bancoUrl: obrigatoria('DATABASE_URL'),
  bancoSsl: producao ? { rejectUnauthorized: false } : false,
  jwtSecret: obrigatoria('JWT_SECRET'),
  origemFront: producao ? obrigatoria('ORIGEM_FRONT') : process.env.ORIGEM_FRONT || 'http://localhost:5173'
};

module.exports = config;
// Fim de config.js

O que observar

  • A API encerra na subida se faltar variável: o erro aparece no log do deploy, não na primeira requisição do usuário.
  • rejectUnauthorized: false aceita o certificado do provedor sem validar a cadeia; se o provedor fornecer o certificado raiz, prefira configurá-lo.
  • Em desenvolvimento a origem tem valor padrão; em produção ela é obrigatória.
