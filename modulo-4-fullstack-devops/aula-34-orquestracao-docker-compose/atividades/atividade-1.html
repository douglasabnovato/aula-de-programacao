API e PostgreSQL com Docker Compose — Código de Referência

Aula 34 · Módulo 4: Fullstack, DevOps e Projeto Final · ByteClass

O que esta atividade entrega

Um compose.yaml com dois serviços, db e api, e a API de tarefas gravando no PostgreSQL pela rede do Compose. Sobe com docker compose up --build e responde em http://localhost:3000/tarefas.

compose.yaml

# Início: compose.yaml — API de tarefas e PostgreSQL na mesma rede do Compose
services:
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: tarefas
      POSTGRES_PASSWORD: senha_local_exemplo
      POSTGRES_DB: tarefas

  api:
    build: ./api
    environment:
      PORT: 3000
      DATABASE_URL: postgres://tarefas:senha_local_exemplo@db:5432/tarefas
    ports:
      - "3000:3000"
    depends_on:
      - db
# Fim de compose.yaml

api/src/db.js

// Início: db.js — pool de conexões com o PostgreSQL a partir de DATABASE_URL
const { Pool } = require('pg');

const pool = new Pool({ connectionString: process.env.DATABASE_URL });

// cria a tabela de tarefas se ela ainda não existir
async function prepararBanco() {
  await pool.query(`
    CREATE TABLE IF NOT EXISTS tarefas (
      id SERIAL PRIMARY KEY,
      titulo TEXT NOT NULL,
      feita BOOLEAN NOT NULL DEFAULT false
    )
  `);
}

module.exports = { pool, prepararBanco };
// Fim de db.js

api/app.js

// Início: app.js — API de tarefas persistindo no PostgreSQL do Compose
const express = require('express');
const { pool, prepararBanco } = require('./src/db');

const app = express();
app.use(express.json());

// lista todas as tarefas
app.get('/tarefas', async (req, res, next) => {
  try {
    const { rows } = await pool.query('SELECT id, titulo, feita FROM tarefas ORDER BY id');
    res.json(rows);
  } catch (erro) {
    next(erro);
  }
});

// cria uma tarefa a partir do título enviado
app.post('/tarefas', async (req, res, next) => {
  try {
    const { titulo } = req.body;
    if (!titulo || titulo.trim() === '') {
      return res.status(400).json({ erro: 'O campo titulo é obrigatório' });
    }
    const { rows } = await pool.query(
      'INSERT INTO tarefas (titulo) VALUES ($1) RETURNING id, titulo, feita',
      [titulo.trim()]
    );
    res.status(201).json(rows[0]);
  } catch (erro) {
    next(erro);
  }
});

// trata qualquer falha num ponto só
app.use((erro, req, res, next) => {
  console.error(erro.message);
  res.status(500).json({ erro: 'Erro interno' });
});

// garante a tabela e só então abre a porta
async function iniciar() {
  await prepararBanco();
  const porta = process.env.PORT || 3000;
  app.listen(porta, () => console.log(`API ouvindo na porta ${porta}`));
}

iniciar().catch((erro) => {
  console.error('Falha ao iniciar:', erro.message);
  process.exit(1);
});
// Fim de app.js

Como rodar

  1. Na pasta api/, rode npm install express pg e confira o Dockerfile da aula 32
  2. Na raiz, rode docker compose up --build
  3. Crie uma tarefa: curl -X POST localhost:3000/tarefas -H "Content-Type: application/json" -d '{"titulo":"Testar o Compose"}'
  4. Consulte no banco: docker compose exec db psql -U tarefas -c "SELECT * FROM tarefas"
  5. Encerre com docker compose down

O que observar

  • O banco não publica porta: a API chega nele pela rede interna do projeto, usando o nome db.
  • Se o banco demorar a subir, a API cai com ECONNREFUSED — o depends_on curto só espera o contêiner iniciar, não o PostgreSQL aceitar conexão.
  • A consulta usa $1 em vez de concatenar o título: o driver envia o valor separado do SQL.
