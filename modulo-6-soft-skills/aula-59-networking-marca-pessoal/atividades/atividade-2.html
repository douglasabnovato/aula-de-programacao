O que esta atividade entrega

O registro da primeira contribuição da aluna fictícia Carla Brandão: a issue escolhida, a descrição do Pull Request e as respostas à revisão.

Issue escolhida

  • Título: comando de instalação no README está desatualizado.
  • Como encontrei: ao seguir o README, o comando falhou na minha máquina.
  • Comentário na issue: "Posso cuidar desta? Consegui reproduzir seguindo o README."

descricao-pull-request.md

<!-- Início: descrição de Pull Request (exemplo fictício) -->
## O que muda
Atualiza o comando de instalação no README.

## Por que
O comando antigo usava um script que não existe mais no package.json.
Resolve #42.

## Como testar
1. Clonar o repositório em uma pasta nova.
2. Seguir o README a partir da seção Instalação.
3. Confirmar que `npm run dev` sobe o projeto.

## Fora do escopo
Não alterei a formatação dos outros arquivos.
<!-- Fim de descricao-pull-request.md -->

Respostas à revisão

  • Revisor: "Pode incluir também a versão mínima do Node?" Resposta: "Incluí no commit abc123, conferindo com o campo engines do package.json."
  • Revisor: "Talvez valha trocar npm por pnpm." Resposta: "Mantive npm porque é o que o projeto usa hoje; posso abrir uma issue para discutir a troca."

O que observar

  • A contribuição nasceu de um problema real encontrado ao usar o projeto.
  • A seção Fora do escopo evita que o revisor procure mudanças que não existem.
  • Discordar com motivo técnico e propor uma issue separada mantém o Pull Request pequeno.
