# Erro de CORS ao chamar a API local a partir do React

## O problema
O frontend em http://localhost:5173 chamava a API em http://localhost:3000
e o navegador bloqueava a resposta com erro de CORS.

## O que tentei
- Mudar a URL para 127.0.0.1: o erro continuou.
- Desativar a checagem no navegador: funcionou só na minha máquina.

## O que funcionou
Configurar a API para responder com o cabeçalho Access-Control-Allow-Origin
permitindo apenas a origem do frontend, lida de uma variável de ambiente.

## Por que funcionou
Origens diferentes (porta diferente conta) exigem que o servidor declare
quem pode ler a resposta. A checagem é do navegador; por isso o teste
com ferramentas de linha de comando funcionava.

## Ambiente
Node 20, Express 4, Vite 5.

## Referências
- MDN — CORS: https://developer.mozilla.org/pt-BR/docs/Web/HTTP/CORS
