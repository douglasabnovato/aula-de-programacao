Declaração de Posicionamento — Modelo Preenchido

Aula 54 · Módulo 6: Soft Skills, Carreira e Inteligência Emocional · ByteClass

O que esta atividade entrega

O posicionamento da desenvolvedora fictícia Júlia Rocha antes e depois do recorte, nas três versões de tamanho. Use a estrutura para escrever a sua a partir dos projetos que você já tem.

Antes

  • Dev fullstack, mobile, dados e UX, aberto a qualquer oportunidade, apaixonada por tecnologia.
  • Problema: não diz para qual vaga serve e nenhum projeto comprova as cinco áreas.

Evidência mapeada

  • Projeto 1 — painel de pedidos em React consumindo API REST (frontend, React, painel de operação).
  • Projeto 2 — loja com carrinho e checkout simulado (frontend, React, e-commerce).
  • Projeto 3 — API de tarefas em Node.js (backend, Express, CRUD).
  • Padrão: frontend com React em telas de operação e venda.

Depois — três tamanhos

  • Uma linha: Desenvolvedora Frontend React | Interfaces para operação e e-commerce.
  • Três linhas: Desenvolvo interfaces em React e TypeScript para painéis de operação e lojas virtuais. Meus projetos publicados incluem um painel de pedidos e uma loja com checkout. Busco vaga de desenvolvedora frontend júnior.
  • Trinta segundos: Sou desenvolvedora frontend e trabalho com React. Construí um painel que mostra pedidos em tempo real e uma loja com carrinho. O que mais gosto é transformar um processo confuso numa tela que alguém usa sem manual. Estou procurando a primeira vaga de frontend.

Como usar

  1. Liste seus projetos e mapeie função, tecnologia e problema.
  2. Escolha o padrão que mais se repete.
  3. Escreva as três versões e teste a de trinta segundos em voz alta.
  4. Use a versão de uma linha no título do LinkedIn e do GitHub na próxima aula.

O que observar

  • Cada afirmação da versão de três linhas aponta para um projeto que existe.
  • Adjetivos como 'apaixonada' saem: não informam nada que um projeto não mostre melhor.
  • Recorte não é prisão; ele muda quando a evidência mudar.
