Aula 56 · Módulo 6: Soft Skills, Carreira e Inteligência Emocional · ByteClass

O que esta atividade entrega

A solução do problema de agrupar transações por cliente, com os testes, e o roteiro de fala usado durante os 30 minutos.

solucao.js

// Início: agrupa transações por cliente e soma os valores
// Entrada: [{ cliente: 'Ana', valor: 10 }, { cliente: 'Ana', valor: '5.5' }]
// Saída:   { Ana: 15.5 }

// soma os valores de cada cliente, convertendo texto em número e rejeitando valor inválido
function somarPorCliente(transacoes) {
  const totais = {};
  for (const { cliente, valor } of transacoes) {
    const numero = Number(valor);
    if (Number.isNaN(numero)) {
      throw new Error(`Valor inválido para ${cliente}: ${valor}`);
    }
    totais[cliente] = (totais[cliente] || 0) + numero;
  }
  return totais;
}

module.exports = { somarPorCliente };
// Fim de solucao.js

solucao.test.js

// Início: testes da função somarPorCliente com o executor nativo do Node
const test = require('node:test');
const assert = require('node:assert');
const { somarPorCliente } = require('./solucao');

test('soma valores do mesmo cliente, inclusive texto numérico', () => {
  const r = somarPorCliente([
    { cliente: 'Ana', valor: 10 },
    { cliente: 'Ana', valor: '5.5' },
    { cliente: 'Bruno', valor: 3 },
  ]);
  assert.deepStrictEqual(r, { Ana: 15.5, Bruno: 3 });
});

test('lista vazia devolve objeto vazio', () => {
  assert.deepStrictEqual(somarPorCliente([]), {});
});

test('valor inválido lança erro', () => {
  assert.throws(() => somarPorCliente([{ cliente: 'Ana', valor: 'abc' }]));
});
// Fim de solucao.test.js

Roteiro de fala

  1. "Deixa eu repetir para confirmar: recebo uma lista de transações e devolvo o total por cliente, certo?"
  2. "O valor pode vir como texto? E se a lista vier vazia?"
  3. "Vou começar com um laço e um objeto acumulador, que é o jeito mais direto."
  4. "Rodei e deu concatenação: o valor veio como texto. Vou converter com Number."
  5. "Agora dois testes para provar, e se sobrar tempo mostro a versão com reduce."

Como rodar

  1. Salve os dois arquivos na mesma pasta.
  2. node --test
  3. Confira que os três testes passam.

O que observar

  • O erro da concatenação é o momento em que o entrevistador mais aprende sobre você: narrar a correção vale mais que não errar.
  • A decisão sobre valor inválido foi tomada em voz alta e virou teste.
  • A versão com reduce é melhoria opcional, não o ponto de partida.
