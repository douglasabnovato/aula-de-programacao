# Checklist de Entrega — Portfólio de Formatura

Aluno(a): ______________________   Data da revisão: __/__/____
Posicionamento (uma linha): ______________________________________

## Página de entrada
- [ ] Posicionamento em três linhas no topo
- [ ] Ordem sugerida de leitura dos projetos
- [ ] Links para LinkedIn e GitHub funcionando

## Para cada projeto (de 3 a 6)
- [ ] Link publicado abre em janela anônima e no celular
- [ ] README com problema, como rodar, tecnologias, decisões e link
- [ ] Projeto roda a partir de um clone limpo seguindo o README
- [ ] Nenhum segredo no código ou no histórico; existe .env.example
- [ ] Contraste, texto alternativo e navegação por teclado conferidos
- [ ] Riscos do OWASP Top 10 revisados nos projetos com backend

## Teste dos dez minutos
- [ ] Avaliador 1: ____________ — desistiu em: ____________
- [ ] Avaliador 2: ____________ — desistiu em: ____________
- [ ] Correções feitas após cada teste

## Materiais de carreira
- [ ] Currículo em PDF de uma página atualizado
- [ ] Perfil do LinkedIn com título e destaques revisados
- [ ] Pelo menos um artigo técnico ou contribuição publicada

Como usar

  1. Copie o checklist para o repositório do portfólio.
  2. Marque cada item só depois de conferir, anotando a data.
  3. Faça o teste dos dez minutos com duas pessoas diferentes.
  4. Entregue o link do checklist junto com o do portfólio.

O que observar

  • O teste dos dez minutos mede o que um recrutador realmente consegue ver.
  • Corrigir o ponto de desistência vem antes de qualquer melhoria estética.
  • O checklist reúne critérios de todos os módulos: é a trilha inteira revisada num documento.
