Comparador Anual CLT x PJ — Modelo e Código

Aula 58 · Módulo 6: Soft Skills, Carreira e Inteligência Emocional · ByteClass

O que esta atividade entrega

Uma função que compara as duas propostas no ano recebendo todos os valores como parâmetro. Nenhuma alíquota fica escrita no código: INSS, IR, impostos da empresa e custos vêm das tabelas vigentes e das cotações que você pesquisar. O exemplo de uso tem valores hipotéticos só para mostrar o cálculo, sem qualquer relação com salários de mercado.

comparador.js

// Início: comparador anual entre proposta CLT e proposta PJ, sem alíquotas fixas no código

// calcula o valor anual disponível na CLT a partir do salário e dos descontos anuais informados
function anualCLT({ salario, inssAnual, irAnual, aliquotaFgts, beneficiosMensais }) {
  const brutoAnual = salario * 12 + salario + salario / 3;
  const descontos = inssAnual + irAnual;
  const fgts = brutoAnual * aliquotaFgts;
  const beneficios = beneficiosMensais * 12;
  return { disponivel: brutoAnual - descontos + beneficios, fgts };
}

// calcula o valor anual disponível no PJ a partir do faturamento e dos custos informados
function anualPJ({ valorMensal, mesesFaturados, aliquotaImpostoEmpresa, custosMensais, reservaMeses }) {
  const faturamento = valorMensal * mesesFaturados;
  const impostos = faturamento * aliquotaImpostoEmpresa;
  const custos = custosMensais * 12;
  const reserva = valorMensal * reservaMeses;
  return { disponivel: faturamento - impostos - custos - reserva, reserva };
}

// imprime as duas propostas lado a lado e a diferença percentual
function comparar(clt, pj) {
  const a = anualCLT(clt);
  const b = anualPJ(pj);
  const diferenca = ((b.disponivel - a.disponivel) / a.disponivel) * 100;
  console.log('CLT disponível no ano:', a.disponivel.toFixed(2), '| FGTS depositado:', a.fgts.toFixed(2));
  console.log('PJ  disponível no ano:', b.disponivel.toFixed(2), '| reserva separada:', b.reserva.toFixed(2));
  console.log('Diferença do PJ em relação à CLT:', diferenca.toFixed(1) + '%');
}

comparar(
  { salario: 1000, inssAnual: 0, irAnual: 0, aliquotaFgts: 0.08, beneficiosMensais: 0 },
  { valorMensal: 1500, mesesFaturados: 11, aliquotaImpostoEmpresa: 0, custosMensais: 0, reservaMeses: 0 }
);
// Fim de comparador.js

Como rodar

  1. Salve o código em comparador.js.
  2. Substitua os valores hipotéticos pelos das propostas que você recebeu.
  3. Preencha inssAnual e irAnual somando os descontos dos 12 salários, do 13º e das férias, calculados nas tabelas vigentes do INSS e da Receita.
  4. Preencha a alíquota e os custos do PJ com a informação do seu contador ou da legislação do regime escolhido.
  5. node comparador.js

O que observar

  • A alíquota de FGTS do exemplo é a prevista no caput do artigo 15 da Lei 8.036; confira no texto se o seu caso segue a regra geral.
  • Com todos os custos zerados, o PJ sempre parece melhor: é exatamente o erro que a prática quer mostrar.
  • O FGTS aparece separado porque é patrimônio do trabalhador, mas não é dinheiro disponível no mês.
