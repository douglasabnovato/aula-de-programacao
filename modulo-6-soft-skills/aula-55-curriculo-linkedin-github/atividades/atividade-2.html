Perfil do LinkedIn — Modelo Preenchido

Aula 55 · Módulo 6: Soft Skills, Carreira e Inteligência Emocional · ByteClass

O que esta atividade entrega

O antes e o depois do perfil do aluno fictício Diego Faria, campo por campo, com o checklist de auditoria usado na prática.

Antes

  • Título: Estudante
  • Sobre: vazio
  • Competências: Pacote Office, Liderança, Trabalho em equipe
  • Destaques: nenhum

Depois

  • Título: Desenvolvedor Frontend | React e JavaScript | Busco primeira vaga
  • Sobre (parágrafo 1): Desenvolvo interfaces em React que consomem APIs REST.
  • Sobre (parágrafo 2): Publiquei um painel de pedidos e uma loja virtual; os links estão nos destaques.
  • Sobre (parágrafo 3): Procuro vaga de frontend júnior em Juiz de Fora ou remota.
  • Competências: React, JavaScript, HTML, CSS, Git, APIs REST
  • Destaques: link do painel publicado, link da loja publicada, repositório do GitHub

Checklist de auditoria

  • O título tem função e tecnologia principal?
  • A cidade e a modalidade de trabalho estão corretas?
  • O Sobre tem link ou referência a projeto verificável?
  • As competências usam os mesmos nomes das vagas?
  • Os dados de contato públicos são os que você quer expor?

Como usar

  1. Faça o teste de busca em janela anônima e anote o resultado.
  2. Preencha os campos na ordem do checklist.
  3. Peça uma recomendação a quem acompanhou um projeto seu, indicando o projeto específico.
  4. Refaça o teste de busca depois de alguns dias.

O que observar

  • O perfil repete o currículo, mas em blocos curtos para leitura em tela.
  • Competências genéricas não ajudam a aparecer em busca técnica.
  • Uma recomendação que cita um projeto concreto vale mais que várias genéricas.
