# Painel de Pedidos

Painel que lista pedidos de uma loja fictícia com filtro por status.

**Projeto publicado:** https://exemplo.github.io/painel-pedidos

## Problema
A equipe de expedição precisava ver os pedidos pendentes sem abrir o sistema administrativo.

## Como rodar
1. `git clone https://github.com/exemplo/painel-pedidos.git`
2. `cd painel-pedidos`
3. `cp .env.example .env` e preencha `VITE_API_URL`
4. `npm install`
5. `npm run dev`

## Tecnologias
React, React Router, Vite

## Decisões
- Filtro feito no cliente porque a API de exemplo não aceita parâmetros de busca.
- Estado de erro exibido quando a API não responde em 5 segundos.

## O que eu faria a seguir
Paginação no servidor e testes de ponta a ponta.

Como usar

  1. Preencha a planilha para todos os seus repositórios.
  2. Aplique o modelo de README nos seis escolhidos.
  3. Fixe os seis no perfil.
  4. Arquive o que não representa seu nível atual.

O que observar

  • Remover o .env num commit novo não apaga a chave do histórico; por isso a chave é revogada primeiro.
  • A seção Decisões é a que mais gera conversa em entrevista.
  • O .env.example mostra quais variáveis existem sem expor nenhum valor.
