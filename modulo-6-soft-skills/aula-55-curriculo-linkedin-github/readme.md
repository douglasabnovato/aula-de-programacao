# ⚡ Ementa da Aula 55: Otimização de Currículo, LinkedIn e GitHub de Alto Impacto | ByteClass

## 🎯 Visão Geral da Ementa
Os três materiais contam a mesma história em formatos diferentes: o currículo para triagem, o LinkedIn para ser encontrado e o GitHub para provar.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: Currículo Técnico de Uma Página
* **Triagem em segundos:** função, tecnologia e evidência compatíveis com a vaga, nessa ordem.
* **Dados pessoais:** o mínimo para contato, com base na LGPD e na Lei 9.029.
* **Frase de evidência:** ação, tecnologia e resultado verificável no lugar de adjetivos.

### 2. Bloco 2: LinkedIn: Perfil que Recrutador Encontra e Entende
* **Perfil como buscador:** título, localização e competências definem se o perfil aparece.
* **Primeira tela:** resumo curto e destaques com link para os projetos.
* **Privacidade:** escolher o que é público com o mesmo cuidado do currículo.

### 3. Bloco 3: GitHub como Portfólio Verificável
* **Curadoria:** poucos repositórios fixados que provam o posicionamento.
* **README que se executa:** problema, como rodar, decisões e link publicado.
* **Cuidado básico:** segredos fora do repositório e histórico revisado.

---

## 🛠️ Aplicação Prática e Dinâmica
* **Desafio de abertura:** cada tema começa com um problema concreto que a teoria e a prática vão resolver.
* **Roadmap de 10 Passos:** execução guiada de laboratórios práticos para fixar cada conceito abordado na teoria.
* **Validação com o Instrutor:** fechamento do ciclo prático com checagem individualizada dos resultados obtidos.
