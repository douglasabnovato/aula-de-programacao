# ⚡ Ementa da Aula 11: React.js Componentes & State | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa leva o aluno do primeiro componente funcional criado com Vite até um projeto reativo organizado, com estado local controlado por useState e fluxo de dados de cima para baixo.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: A Filosofia do React: O que são Componentes e o DOM Virtual
* **Componentes como funções:** cada parte da interface é uma função que devolve JSX.
* **DOM virtual e reconciliação:** o React compara a nova descrição da tela com a anterior e altera só o que mudou.
* **Vite e JSX:** criação do projeto, estrutura de pastas e exportação e importação de componentes.

### 2. Bloco 2: Gerenciamento de Estado Local com o Hook useState
* **`useState`:** o valor que, ao mudar, faz o componente renderizar de novo.
* **Imutabilidade:** o estado muda só pela função `set`, nunca por atribuição direta.
* **Regras na interface:** limite mínimo, reset e botões desabilitados conforme o estado.

### 3. Bloco 3: Boas Práticas e Fluxo de Dados Unidirecional
* **Fluxo de cima para baixo:** o estado vive no componente pai e desce para quem exibe.
* **Organização do projeto:** PascalCase, pasta de componentes, variáveis CSS e imports limpos.
* **Verificação antes do commit:** console limpo, `npm run build` sem falhas e `git status` revisado.
