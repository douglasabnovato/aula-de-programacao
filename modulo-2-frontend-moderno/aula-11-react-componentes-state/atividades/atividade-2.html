Construindo um Contador Dinâmico com useState — Resposta

Aula 11 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O componente Counter com o estado count criado por useState(0), botões de somar, subtrair e zerar, e a regra de limite mínimo: o valor nunca fica negativo e o botão −1 fica desabilitado no zero.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/Counter.jsx

// Início: src/components/Counter.jsx — contador com estado local
import { useState } from 'react';

// Contador com incremento, decremento limitado a zero e reset
export default function Counter() {
  const [count, setCount] = useState(0);

  return (
    <section className="card">
      <h2>Contador</h2>
      <p className="valor">{count}</p>
      <div className="linha">
        <button onClick={() => setCount(Math.max(0, count - 1))} disabled={count === 0}>−1</button>
        <button onClick={() => setCount(count + 1)}>+1</button>
        <button className="secundario" onClick={() => setCount(0)}>Reset</button>
      </div>
      {count === 0 && <p className="muted">O contador não fica abaixo de zero.</p>}
    </section>
  );
}
// Fim de Counter.jsx

src/App.jsx

// Início: src/App.jsx — renderiza o contador
import Counter from './components/Counter.jsx';

// Componente raiz
function App() {
  return (
    <main>
      <h1>Aula 11 — Estado local</h1>
      <Counter />
    </main>
  );
}

export default App;
// Fim de App.jsx

Como rodar

  1. No projeto da prática anterior, crie src/components/Counter.jsx
  2. Substitua o App.jsx pelo arquivo acima
  3. npm run dev
  4. Clique em +1, −1 e Reset observando o número mudar sem recarregar a página

O que observar

  • Trocar count por uma variável comum (let) faz o valor mudar na memória, mas a tela não é redesenhada.
  • setCount não altera count na hora: agenda uma nova renderização com o valor novo.
  • A regra do mínimo está em dois lugares de propósito: Math.max protege o valor e disabled comunica o limite a quem usa.
