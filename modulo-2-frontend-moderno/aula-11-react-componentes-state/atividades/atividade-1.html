Estruturando o Primeiro Componente Funcional — Resposta

Aula 11 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um projeto React criado com Vite, com a pasta src/components e o primeiro componente, WelcomeCard, exportado no próprio arquivo, importado no App.jsx e renderizado com <WelcomeCard />.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/WelcomeCard.jsx

// Início: src/components/WelcomeCard.jsx — primeiro componente funcional
// Cartão de boas-vindas escrito uma vez e reutilizável em qualquer página
function WelcomeCard() {
  return (
    <section className="card">
      <h2>Bem-vindo à ByteClass</h2>
      <p>Este cartão é um componente React: uma função que devolve JSX.</p>
    </section>
  );
}

export default WelcomeCard;
// Fim de WelcomeCard.jsx

src/App.jsx

// Início: src/App.jsx — componente raiz que usa o WelcomeCard
import WelcomeCard from './components/WelcomeCard.jsx';

// Monta a página e renderiza o componente importado
function App() {
  return (
    <main>
      <h1>Aula 11 — Primeiro componente</h1>
      <WelcomeCard />
    </main>
  );
}

export default App;
// Fim de App.jsx

src/main.jsx

// Início: src/main.jsx — ponto de entrada gerado pelo Vite
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App.jsx';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);
// Fim de main.jsx

Como rodar

  1. npm create vite@latest aula-11 -- --template react e cd aula-11
  2. npm install
  3. Apague o conteúdo de exemplo de App.jsx e App.css, crie src/components/WelcomeCard.jsx e salve os arquivos acima
  4. npm run dev e abra o endereço mostrado no terminal

O que observar

  • O nome do componente começa com maiúscula: <welcomeCard /> seria tratado como uma tag HTML desconhecida.
  • A função devolve um único elemento raiz (<section>); dois elementos soltos no return geram erro de sintaxe.
  • Salvar o arquivo atualiza a tela sem recarregar: é o recarregamento rápido do Vite.
