Refatorando e Organizando um Projeto Reativo — Resposta

Aula 11 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O projeto da aula depois da revisão: componentes em PascalCase dentro de src/components, cores e medidas em variáveis CSS globais, manipuladores de clique com nome (handleIncrement, handleDecrement, handleReset), estado atualizado só por funções set e a exibição separada num componente sem estado.

src/components/CounterDisplay.jsx

// Início: src/components/CounterDisplay.jsx — só apresentação, sem estado
// Mostra o valor e o histórico recebidos, sem saber como eles mudam
export default function CounterDisplay({ value, history }) {
  return (
    <>
      <p className="valor">{value}</p>
      <ol className="historico">
        {history.map((acao, indice) => (
          <li key={indice}>{acao}</li>
        ))}
      </ol>
    </>
  );
}
// Fim de CounterDisplay.jsx

src/components/Counter.jsx

// Início: src/components/Counter.jsx — estado e manipuladores organizados
import { useState } from 'react';
import CounterDisplay from './CounterDisplay.jsx';

// Guarda o estado do contador e o histórico, e delega a exibição ao CounterDisplay
export default function Counter() {
  const [count, setCount] = useState(0);
  const [history, setHistory] = useState([]);

  // Registra a ação no histórico criando um array novo
  function registrar(acao) {
    setHistory((atual) => [...atual, acao].slice(-5));
  }

  // Soma uma unidade
  function handleIncrement() {
    setCount((atual) => atual + 1);
    registrar('+1');
  }

  // Subtrai uma unidade sem passar de zero
  function handleDecrement() {
    setCount((atual) => Math.max(0, atual - 1));
    registrar('−1');
  }

  // Volta ao valor inicial
  function handleReset() {
    setCount(0);
    registrar('reset');
  }

  return (
    <section className="card">
      <h2>Contador organizado</h2>
      <CounterDisplay value={count} history={history} />
      <div className="linha">
        <button onClick={handleDecrement} disabled={count === 0}>−1</button>
        <button onClick={handleIncrement}>+1</button>
        <button className="secundario" onClick={handleReset}>Reset</button>
      </div>
    </section>
  );
}
// Fim de Counter.jsx

Como rodar

  1. Mantenha o WelcomeCard.jsx da primeira prática e salve os arquivos acima
  2. Apague App.css e os imports que apontavam para ele
  3. npm run dev e confira o console sem erros nem avisos
  4. npm run build e depois git status para conferir o que mudou antes do commit

O que observar

  • history.push(acao) alteraria o array existente e o React poderia não perceber a mudança; o spread cria um array novo.
  • A atualização por função (setCount((atual) => atual + 1)) usa sempre o valor mais recente, mesmo com cliques rápidos.
  • O CounterDisplay não sabe de onde vêm os dados: pode ser reaproveitado com qualquer outro estado.
