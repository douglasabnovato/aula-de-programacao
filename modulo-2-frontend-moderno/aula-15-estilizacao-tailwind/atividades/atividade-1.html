Card de Plano Estilizado Só com Utilitários — Resposta

Aula 15 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um projeto Vite + React com Tailwind CSS v4 configurado pelo plugin oficial e um card de plano da academia fictícia Pulso Fit estilizado sem nenhuma classe CSS escrita à mão. O demo usa o build de navegador do Tailwind, que serve só para prototipar; no projeto o CSS é gerado pelo Vite.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

vite.config.js

// Início: vite.config.js — Vite com os plugins de React e Tailwind
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
// Fim de vite.config.js

src/index.css

/* Início: src/index.css — única linha necessária para ligar o Tailwind */
@import "tailwindcss";
/* Fim de index.css */

src/components/PlanoCard.jsx

// Início: src/components/PlanoCard.jsx — card estilizado só com utilitários
// Card de um plano da academia, com nome, preço, benefícios e botão
export default function PlanoCard({ nome, preco, beneficios }) {
  return (
    <article className="max-w-sm space-y-4 rounded-2xl bg-slate-800 p-6 text-slate-100 shadow-md">
      <h2 className="text-2xl font-bold">{nome}</h2>
      <p>
        <span className="text-4xl font-extrabold">R$ {preco}</span>
        <span className="text-sm text-slate-400"> /mês</span>
      </p>
      <ul className="list-disc space-y-1 pl-5 text-slate-300">
        {beneficios.map((b) => (
          <li key={b}>{b}</li>
        ))}
      </ul>
      <button className="w-full rounded-lg bg-emerald-400 py-2 font-semibold text-slate-900">
        Quero este plano
      </button>
    </article>
  );
}
// Fim de PlanoCard.jsx

src/App.jsx

// Início: src/App.jsx — página com um card de plano
import PlanoCard from './components/PlanoCard.jsx';

// Componente raiz: fundo da página e um card centralizado
export default function App() {
  return (
    <main className="min-h-screen bg-slate-950 p-8">
      <h1 className="mb-6 text-3xl font-bold text-white">Planos Pulso Fit</h1>
      <PlanoCard nome="Mensal" preco="99" beneficios={['Musculação livre', 'Avaliação física', 'App de treinos']} />
    </main>
  );
}
// Fim de App.jsx

Como rodar

  1. npm create vite@latest pulso-fit -- --template react, cd pulso-fit e npm install
  2. npm install tailwindcss @tailwindcss/vite
  3. Salve os quatro arquivos acima (o main.jsx gerado pelo Vite já importa o index.css)
  4. npm run dev; depois npm run build e abra o CSS gerado em dist/assets

O que observar

  • O <h1> sem classes perde tamanho e margem: é o Preflight, o reset de estilos que o Tailwind aplica.
  • O CSS de produção contém só as classes usadas nos arquivos, por isso fica pequeno.
  • Ler a lista de classes descreve o visual inteiro do card, sem abrir outro arquivo.
