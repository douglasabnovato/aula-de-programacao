Tokens da Marca e Componente Botao com Variantes — Resposta

Aula 15 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

As cores e a fonte da marca Pulso Fit declaradas uma vez no @theme, gerando utilitários como bg-marca, e um componente Botao que concentra as classes repetidas em variantes (primário, contorno, discreto) e tamanhos. Trocar a cor da marca passa a ser uma edição de uma linha.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/index.css

/* Início: src/index.css — tokens da marca Pulso Fit */
@import "tailwindcss";

@theme {
  --color-marca: #22c55e;
  --color-marca-escura: #15803d;
  --color-tinta: #0f172a;
  --font-titulo: "Trebuchet MS", system-ui, sans-serif;
}
/* Fim de index.css */

src/components/Botao.jsx

// Início: src/components/Botao.jsx — botão único com variantes e tamanhos
const variantes = {
  primario: 'bg-marca text-white hover:bg-marca-escura',
  contorno: 'border-2 border-marca text-marca hover:bg-marca hover:text-white',
  discreto: 'text-tinta underline-offset-4 hover:underline',
};

const tamanhos = {
  sm: 'px-3 py-1 text-sm',
  md: 'px-5 py-2 text-base',
};

// Junta as classes fixas com as da variante e do tamanho escolhidos
export default function Botao({ variante = 'primario', tamanho = 'md', children, ...resto }) {
  const classes = [
    'rounded-lg font-semibold transition disabled:cursor-not-allowed disabled:opacity-50 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-marca',
    variantes[variante],
    tamanhos[tamanho],
  ].join(' ');

  return (
    <button className={classes} {...resto}>
      {children}
    </button>
  );
}
// Fim de Botao.jsx

src/App.jsx

// Início: src/App.jsx — vitrine dos tokens e do componente Botao
import { useState } from 'react';
import Botao from './components/Botao.jsx';

// Componente raiz: mostra as variantes e conta os cliques de teste
export default function App() {
  const [cliques, setCliques] = useState(0);

  return (
    <main className="min-h-screen space-y-6 bg-white p-8 text-tinta">
      <h1 className="font-titulo text-3xl font-bold text-marca">Pulso Fit</h1>
      <p>Todos os botões abaixo vêm do mesmo componente. Cliques: {cliques}</p>
      <div className="flex flex-wrap items-center gap-3">
        <Botao onClick={() => setCliques(cliques + 1)}>Assinar</Botao>
        <Botao variante="contorno" onClick={() => setCliques(cliques + 1)}>Ver planos</Botao>
        <Botao variante="discreto" tamanho="sm">Falar com a recepção</Botao>
        <Botao disabled>Esgotado</Botao>
      </div>
    </main>
  );
}
// Fim de App.jsx

Como rodar

  1. No projeto com Tailwind, substitua o index.css pelo arquivo acima
  2. Crie src/components/Botao.jsx e substitua o App.jsx
  3. npm run dev e confira as três variantes
  4. Troque --color-marca por outra cor, salve e veja todos os botões mudarem

O que observar

  • O Tailwind lê os arquivos como texto: uma classe montada como `bg-${cor}-500` não é gerada. Por isso as variantes são strings completas.
  • Cada variável --color-* do @theme vira bg-*, text-* e border-* automaticamente.
  • O ...resto repassa onClick, disabled e outras props nativas ao <button>. O estado desabilitado vem de disabled:, sem classe extra.
