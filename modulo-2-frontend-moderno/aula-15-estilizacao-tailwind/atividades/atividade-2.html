Grade de Planos Responsiva com Estados e Tema Escuro — Resposta

Aula 15 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

A página de planos em uma coluna no celular, duas no tablet e três no desktop, com resposta visual ao passar o mouse, contorno visível ao navegar com Tab, um plano em destaque e um botão que alterna o tema escuro. Nenhuma media query foi escrita à mão.

src/components/PlanoCard.jsx

// Início: src/components/PlanoCard.jsx — card com estados de interação e tema
// Card que muda de visual no hover, no foco do teclado, no destaque e no tema escuro
export default function PlanoCard({ plano }) {
  const base = 'flex flex-col gap-4 rounded-2xl border p-6 shadow-sm transition hover:-translate-y-1 hover:shadow-lg';
  const cores = plano.destaque
    ? 'border-emerald-500 bg-emerald-50 dark:bg-emerald-950'
    : 'border-slate-200 bg-white dark:border-slate-700 dark:bg-slate-800';

  return (
    <article className={`${base} ${cores}`}>
      {plano.destaque && (
        <span className="self-start rounded-full bg-emerald-500 px-3 py-1 text-xs font-bold text-white">Mais escolhido</span>
      )}
      <h2 className="text-xl font-bold text-slate-900 dark:text-white">{plano.nome}</h2>
      <p className="text-3xl font-extrabold text-slate-900 dark:text-white">
        R$ {plano.preco}<span className="text-sm font-normal text-slate-500 dark:text-slate-400"> /mês</span>
      </p>
      <ul className="flex-1 list-disc space-y-1 pl-5 text-slate-600 dark:text-slate-300">
        {plano.beneficios.map((b) => (
          <li key={b}>{b}</li>
        ))}
      </ul>
      <button className="rounded-lg bg-emerald-500 py-2 font-semibold text-white hover:bg-emerald-600 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-emerald-500">
        Assinar {plano.nome}
      </button>
    </article>
  );
}
// Fim de PlanoCard.jsx

src/App.jsx

// Início: src/App.jsx — grade responsiva de planos com alternância de tema
import { useState } from 'react';
import PlanoCard from './components/PlanoCard.jsx';
import { planos } from './data/planos.js';

// Componente raiz: controla o tema e monta a grade mobile-first
export default function App() {
  const [escuro, setEscuro] = useState(false);

  return (
    <div className={escuro ? 'dark' : ''}>
      <main className="min-h-screen bg-slate-100 p-6 dark:bg-slate-950">
        <header className="mb-6 flex flex-wrap items-center justify-between gap-3">
          <h1 className="text-2xl font-bold text-slate-900 md:text-3xl dark:text-white">Escolha seu plano</h1>
          <button
            onClick={() => setEscuro(!escuro)}
            className="rounded-lg border border-slate-300 px-4 py-2 text-slate-800 focus-visible:outline-2 focus-visible:outline-emerald-500 dark:border-slate-600 dark:text-slate-100">
            {escuro ? 'Tema claro' : 'Tema escuro'}
          </button>
        </header>
        <section className="grid gap-6 md:grid-cols-2 lg:grid-cols-3">
          {planos.map((p) => (
            <PlanoCard key={p.id} plano={p} />
          ))}
        </section>
      </main>
    </div>
  );
}
// Fim de App.jsx

Como rodar

  1. Use o projeto da prática anterior, com Tailwind já configurado
  2. Salve os arquivos acima, substituindo index.css, PlanoCard.jsx e App.jsx
  3. npm run dev e abra o modo dispositivo do DevTools
  4. Teste 375px, 768px e 1280px de largura, navegue com Tab e alterne o tema

O que observar

  • Utilitário sem prefixo vale para todas as larguras; md: quer dizer "a partir de 768px". Por isso a base é a versão do celular.
  • focus-visible: mostra o contorno para quem usa teclado e não aparece no clique do mouse.
  • Sem a linha @custom-variant, o dark: segue a preferência do sistema operacional e o botão de tema não tem efeito.
