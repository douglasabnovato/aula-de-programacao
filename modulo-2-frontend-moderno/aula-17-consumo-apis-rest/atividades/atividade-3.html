Serviço de API, Hook useBusca e Troca sem Condição de Corrida — Resposta

Aula 17 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O acesso à API organizado em três camadas: services/api.js guarda a URL base e a checagem de status, hooks/useBusca.js guarda os estados de carregando, erro e dados, e o componente só decide o que mostrar. Ao trocar de pessoa, a requisição anterior é cancelada com AbortController, então a lista nunca mostra tarefas de quem já não está selecionado.

src/services/api.js

// Início: src/services/api.js — ponto único de acesso à API
const BASE_URL = 'https://jsonplaceholder.typicode.com';

// Faz a requisição, confere o status e devolve o corpo já convertido de JSON
export async function requisitar(caminho, opcoes = {}) {
  const headers = opcoes.body ? { 'Content-Type': 'application/json', ...opcoes.headers } : opcoes.headers;
  const resposta = await fetch(`${BASE_URL}${caminho}`, { ...opcoes, headers });
  if (!resposta.ok) {
    throw new Error(`Falha ${resposta.status} ao acessar ${caminho}.`);
  }
  return resposta.json();
}
// Fim de api.js

src/hooks/useBusca.js

// Início: src/hooks/useBusca.js — os três estados de uma busca reunidos num hook
import { useEffect, useState } from 'react';
import { requisitar } from '../services/api.js';

// Busca o caminho informado, cancela a busca anterior quando ele muda e devolve dados, carregando e erro
export function useBusca(caminho) {
  const [dados, setDados] = useState(null);
  const [carregando, setCarregando] = useState(true);
  const [erro, setErro] = useState(null);

  useEffect(() => {
    const controle = new AbortController();
    setCarregando(true);
    setErro(null);
    requisitar(caminho, { signal: controle.signal })
      .then((resposta) => setDados(resposta))
      .catch((falha) => {
        if (falha.name !== 'AbortError') setErro(falha.message);
      })
      .finally(() => {
        if (!controle.signal.aborted) setCarregando(false);
      });
    return () => controle.abort();
  }, [caminho]);

  return { dados, carregando, erro };
}
// Fim de useBusca.js

src/components/PainelEquipe.jsx

// Início: src/components/PainelEquipe.jsx — troca de pessoa sem condição de corrida
import { useState } from 'react';
import { useBusca } from '../hooks/useBusca.js';

// Painel que lista as tarefas da pessoa escolhida usando o hook useBusca
export default function PainelEquipe() {
  const [usuarioId, setUsuarioId] = useState(1);
  const usuarios = useBusca('/users');
  const tarefas = useBusca(`/todos?userId=${usuarioId}`);

  return (
    <section className="card">
      <h2>Equipe — Entrega Já</h2>
      <label htmlFor="pessoa">Pessoa: </label>
      <select id="pessoa" value={usuarioId} disabled={!usuarios.dados}
        onChange={(e) => setUsuarioId(Number(e.target.value))}>
        {(usuarios.dados ?? [{ id: 1, name: 'Carregando...' }]).map((u) => (
          <option key={u.id} value={u.id}>{u.name}</option>
        ))}
      </select>
      {tarefas.carregando && <p>Carregando tarefas...</p>}
      {tarefas.erro && <p className="erro">{tarefas.erro}</p>}
      {!tarefas.carregando && !tarefas.erro && tarefas.dados && (
        <ul className="tarefas">
          {tarefas.dados.slice(0, 6).map((t) => (
            <li key={t.id} className={t.completed ? 'feita' : ''}>
              <span>#{t.userId} · {t.title}</span>
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
// Fim de PainelEquipe.jsx

Como rodar

  1. Crie as pastas src/services e src/hooks e salve os arquivos acima
  2. Renderize <PainelEquipe /> no App.jsx
  3. npm run dev, abra a aba Rede e ative Slow 3G
  4. Troque de pessoa várias vezes seguidas e observe as requisições marcadas como canceled

O que observar

  • A função devolvida pelo useEffect roda antes do próximo efeito: é ali que a busca antiga é abortada.
  • O AbortError é ignorado no catch, porque cancelar foi uma decisão e não uma falha.
  • Trocar a URL base agora é mudar uma linha em api.js, e qualquer tela nova ganha os três estados com uma chamada de useBusca.
