Painel de Tarefas com Carregando, Erro e Lista — Resposta

Aula 17 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O painel da startup fictícia Entrega Já buscando tarefas na API pública jsonplaceholder.typicode.com ao abrir, com tela de carregamento, tela de erro com botão para tentar de novo e a lista com as concluídas riscadas. A busca roda uma vez por montagem e de novo a cada clique em Tentar de novo.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/PainelTarefas.jsx

// Início: src/components/PainelTarefas.jsx — busca inicial com três estados
import { useEffect, useState } from 'react';

const URL_TAREFAS = 'https://jsonplaceholder.typicode.com/todos?userId=1';

// Painel que busca as tarefas ao montar e mostra carregando, erro ou lista
export default function PainelTarefas() {
  const [tarefas, setTarefas] = useState([]);
  const [carregando, setCarregando] = useState(true);
  const [erro, setErro] = useState(null);
  const [tentativa, setTentativa] = useState(0);

  useEffect(() => {
    // Busca as tarefas, confere o status HTTP e atualiza os estados
    async function carregar() {
      setCarregando(true);
      setErro(null);
      try {
        const resposta = await fetch(URL_TAREFAS);
        if (!resposta.ok) {
          throw new Error(`A API respondeu com status ${resposta.status}.`);
        }
        const dados = await resposta.json();
        setTarefas(dados);
      } catch (falha) {
        setErro(falha.message);
      } finally {
        setCarregando(false);
      }
    }
    carregar();
  }, [tentativa]);

  if (carregando) {
    return <p className="card">Carregando tarefas...</p>;
  }

  if (erro) {
    return (
      <div className="card">
        <p className="erro">Não foi possível carregar: {erro}</p>
        <button onClick={() => setTentativa(tentativa + 1)}>Tentar de novo</button>
      </div>
    );
  }

  return (
    <section className="card">
      <h2>Tarefas da equipe — Entrega Já</h2>
      <p className="muted">{tarefas.filter((t) => t.completed).length} de {tarefas.length} concluídas</p>
      <ul className="tarefas">
        {tarefas.map((t) => (
          <li key={t.id} className={t.completed ? 'feita' : ''}>
            <span>{t.title}</span>
          </li>
        ))}
      </ul>
    </section>
  );
}
// Fim de PainelTarefas.jsx

Como rodar

  1. npm create vite@latest entrega-ja -- --template react, cd entrega-ja e npm install
  2. Crie src/components/PainelTarefas.jsx e renderize-o no App.jsx
  3. npm run dev com a aba Rede do DevTools aberta
  4. Ative a limitação Slow 3G para ver o carregando e Offline para ver o erro

O que observar

  • Um 404 não cai no catch sozinho: o fetch só rejeita em falha de rede, por isso a checagem de resposta.ok.
  • O finally desliga o carregando tanto no sucesso quanto na falha.
  • No modo de desenvolvimento com StrictMode, o efeito roda duas vezes na montagem; em produção, uma.
