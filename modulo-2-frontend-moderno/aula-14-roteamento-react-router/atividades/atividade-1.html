Três Páginas com BrowserRouter, Routes e Link — Resposta

Aula 14 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

A Livraria Ipê com três páginas (Início, Catálogo e Contato), cada uma com o próprio endereço, um menu que troca de tela sem recarregar e uma página para endereços inexistentes. O demo abaixo usa MemoryRouter, porque roda dentro de um iframe; no projeto real o roteador é o BrowserRouter do main.jsx.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/main.jsx

// Início: main.jsx — ponto de entrada que liga o roteador à aplicação
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { BrowserRouter } from 'react-router';
import App from './App.jsx';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
);
// Fim de main.jsx

src/App.jsx

// Início: src/App.jsx — mapa de rotas da aplicação
import { Routes, Route } from 'react-router';
import Menu from './components/Menu.jsx';
import Inicio from './pages/Inicio.jsx';
import Catalogo from './pages/Catalogo.jsx';
import Contato from './pages/Contato.jsx';
import NaoEncontrada from './pages/NaoEncontrada.jsx';

// Componente raiz: menu fixo e a área que muda conforme o endereço
export default function App() {
  return (
    <>
      <Menu />
      <Routes>
        <Route path="/" element={<Inicio />} />
        <Route path="/catalogo" element={<Catalogo />} />
        <Route path="/contato" element={<Contato />} />
        <Route path="*" element={<NaoEncontrada />} />
      </Routes>
    </>
  );
}
// Fim de App.jsx

src/components/Menu.jsx

// Início: src/components/Menu.jsx — menu presente em todas as páginas
import { Link } from 'react-router';

// Menu principal com links que trocam a rota sem recarregar a página
export default function Menu() {
  return (
    <nav className="menu">
      <Link to="/">Início</Link>
      <Link to="/catalogo">Catálogo</Link>
      <Link to="/contato">Contato</Link>
    </nav>
  );
}
// Fim de Menu.jsx

Como rodar

  1. npm create vite@latest livraria-ipe -- --template react e cd livraria-ipe
  2. npm install e depois npm install react-router
  3. Crie as pastas src/pages e src/components e salve os arquivos acima
  4. npm run dev e abra o endereço que o Vite mostrar no terminal

O que observar

  • Na aba Rede do DevTools, clicar num Link não baixa o documento de novo; um <a href> baixaria.
  • Os botões voltar e avançar do navegador funcionam, porque o roteador grava cada troca no histórico.
  • A rota path="*" fica por último na leitura, mas o React Router escolhe pela especificidade, não pela ordem.
