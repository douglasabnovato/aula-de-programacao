Catálogo com Página de Detalhe e Filtro na URL — Resposta

Aula 14 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um catálogo em que uma única rota (/livros/:id) mostra qualquer livro, e o filtro de categoria fica guardado na query string (?categoria=tecnico), então o link filtrado pode ser copiado e compartilhado.

src/pages/Catalogo.jsx

// Início: src/pages/Catalogo.jsx — lista com filtro guardado na URL
import { Link, useSearchParams } from 'react-router';
import { livros, categorias } from '../data/livros.js';

// Lista os livros e filtra pela categoria lida da query string
export default function Catalogo() {
  const [searchParams, setSearchParams] = useSearchParams();
  const categoria = searchParams.get('categoria');
  const visiveis = categoria ? livros.filter((l) => l.categoria === categoria) : livros;

  return (
    <section>
      <h1>Catálogo</h1>
      <div className="filtros">
        <button className={!categoria ? 'ativo' : ''} onClick={() => setSearchParams({})}>Todas</button>
        {categorias.map((c) => (
          <button key={c.chave} className={categoria === c.chave ? 'ativo' : ''}
            onClick={() => setSearchParams({ categoria: c.chave })}>
            {c.nome}
          </button>
        ))}
      </div>
      <ul className="lista">
        {visiveis.map((livro) => (
          <li key={livro.id}>
            <Link to={`/livros/${livro.id}`}>{livro.titulo}</Link> — {livro.autora}
          </li>
        ))}
      </ul>
    </section>
  );
}
// Fim de Catalogo.jsx

src/pages/DetalheLivro.jsx

// Início: src/pages/DetalheLivro.jsx — uma rota que atende qualquer livro
import { Link, useParams } from 'react-router';
import { livros } from '../data/livros.js';

// Lê o id da URL, busca o livro e trata o caso de id inexistente
export default function DetalheLivro() {
  const { id } = useParams();
  const livro = livros.find((l) => l.id === Number(id));

  if (!livro) {
    return (
      <section>
        <h1>Livro não encontrado</h1>
        <p>Nenhum livro com o código {id}. <Link to="/catalogo">Voltar ao catálogo</Link></p>
      </section>
    );
  }

  return (
    <section>
      <h1>{livro.titulo}</h1>
      <p>Autora: {livro.autora}</p>
      <p>Preço: {livro.preco.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' })}</p>
      <Link to={`/catalogo?categoria=${livro.categoria}`}>Ver outros desta categoria</Link>
    </section>
  );
}
// Fim de DetalheLivro.jsx

src/App.jsx

// Início: src/App.jsx — rotas do catálogo com segmento dinâmico
import { Routes, Route, Link } from 'react-router';
import Catalogo from './pages/Catalogo.jsx';
import DetalheLivro from './pages/DetalheLivro.jsx';

// Componente raiz com a rota fixa do catálogo e a rota dinâmica do detalhe
export default function App() {
  return (
    <>
      <nav className="menu">
        <Link to="/catalogo">Catálogo</Link>
        <Link to="/livros/99">Livro inexistente</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Catalogo />} />
        <Route path="/catalogo" element={<Catalogo />} />
        <Route path="/livros/:id" element={<DetalheLivro />} />
      </Routes>
    </>
  );
}
// Fim de App.jsx

Como rodar

  1. Use o projeto da prática anterior (com react-router instalado e o BrowserRouter no main.jsx)
  2. Crie src/data/livros.js e as duas páginas acima
  3. Substitua o App.jsx e rode npm run dev
  4. Acesse direto /livros/3, /livros/99 e /catalogo?categoria=infantil

O que observar

  • useParams() devolve sempre texto: sem o Number(id) a comparação estrita com o id numérico nunca encontra o livro.
  • O filtro sobrevive ao recarregar a página, porque está na URL e não num useState.
  • Os botões de categoria não criam rotas novas: mudam só o trecho depois do ?.
