Área do Cliente com Layout Compartilhado e Rota Protegida — Resposta

Aula 14 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Uma área do cliente em que Resumo, Pedidos e Dados compartilham o mesmo menu lateral via <Outlet />, o link da tela atual aparece destacado com NavLink e qualquer acesso sem login é desviado para /entrar. O login é simulado em memória: não há servidor nesta aula.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/RotaProtegida.jsx

// Início: src/components/RotaProtegida.jsx — guardião das rotas da conta
import { Navigate, Outlet } from 'react-router';

// Libera as rotas filhas só quando há usuário; senão redireciona para /entrar
export default function RotaProtegida({ usuario }) {
  if (!usuario) {
    return <Navigate to="/entrar" replace />;
  }
  return <Outlet />;
}
// Fim de RotaProtegida.jsx

src/layouts/LayoutConta.jsx

// Início: src/layouts/LayoutConta.jsx — moldura comum às telas da conta
import { NavLink, Outlet } from 'react-router';

// Define a classe do link conforme ele esteja ou não ativo
function classeLink({ isActive }) {
  return isActive ? 'ativo' : '';
}

// Menu lateral fixo e, ao lado, a rota filha que estiver ativa
export default function LayoutConta({ usuario, onSair }) {
  return (
    <div className="conta">
      <aside>
        <strong>Olá, {usuario.nome}</strong>
        <NavLink to="/conta" end className={classeLink}>Resumo</NavLink>
        <NavLink to="/conta/pedidos" className={classeLink}>Pedidos</NavLink>
        <NavLink to="/conta/dados" className={classeLink}>Dados</NavLink>
        <button className="secundario" onClick={onSair}>Sair</button>
      </aside>
      <main>
        <Outlet />
      </main>
    </div>
  );
}
// Fim de LayoutConta.jsx

src/pages/Conta.jsx

// Início: src/pages/Conta.jsx — páginas da área do cliente
import { useState } from 'react';
import { useNavigate } from 'react-router';

// Resumo exibido na rota índice /conta
export function Resumo() {
  return <p>Você tem 2 pedidos neste ano.</p>;
}

// Lista de pedidos fictícios
export function Pedidos() {
  return (
    <ul className="lista">
      <li>#1042 — O Rio das Mangueiras — entregue</li>
      <li>#1057 — JavaScript na Prática — a caminho</li>
    </ul>
  );
}

// Dados cadastrais do usuário logado
export function Dados({ usuario }) {
  return <p>Nome: {usuario.nome} · E-mail: {usuario.email}</p>;
}

// Formulário de entrada que grava o usuário e navega para a conta
export function Entrar({ onEntrar }) {
  const [nome, setNome] = useState('');
  const navegar = useNavigate();

  // Trata o envio do formulário de entrada
  function enviar(evento) {
    evento.preventDefault();
    onEntrar({ nome: nome || 'Cliente', email: 'cliente@exemplo.com' });
    navegar('/conta');
  }

  return (
    <form onSubmit={enviar}>
      <h1>Entrar</h1>
      <input value={nome} onChange={(e) => setNome(e.target.value)} placeholder="Seu nome" />
      <button type="submit">Entrar</button>
    </form>
  );
}
// Fim de Conta.jsx

src/App.jsx

// Início: src/App.jsx — rotas públicas, rota protegida e layout aninhado
import { useState } from 'react';
import { Routes, Route, Link } from 'react-router';
import RotaProtegida from './components/RotaProtegida.jsx';
import LayoutConta from './layouts/LayoutConta.jsx';
import { Resumo, Pedidos, Dados, Entrar } from './pages/Conta.jsx';

// Componente raiz: guarda a sessão e monta a árvore de rotas
export default function App() {
  const [usuario, setUsuario] = useState(null);

  return (
    <>
      <nav className="menu">
        <Link to="/">Início</Link>
        <Link to="/conta/pedidos">Meus pedidos</Link>
        {!usuario && <Link to="/entrar">Entrar</Link>}
      </nav>
      <Routes>
        <Route path="/" element={<p>Bem-vindo à Livraria Ipê.</p>} />
        <Route path="/entrar" element={<Entrar onEntrar={setUsuario} />} />
        <Route element={<RotaProtegida usuario={usuario} />}>
          <Route path="/conta" element={<LayoutConta usuario={usuario} onSair={() => setUsuario(null)} />}>
            <Route index element={<Resumo />} />
            <Route path="pedidos" element={<Pedidos />} />
            <Route path="dados" element={<Dados usuario={usuario} />} />
          </Route>
        </Route>
      </Routes>
    </>
  );
}
// Fim de App.jsx

Como rodar

  1. No projeto da aula, crie as pastas src/components, src/layouts e src/pages
  2. Salve os quatro arquivos acima
  3. npm run dev e clique em Meus pedidos sem ter entrado
  4. Entre com um nome, navegue entre Resumo, Pedidos e Dados, e depois clique em Sair

O que observar

  • Sem o <Outlet /> no layout, a URL muda mas o conteúdo da rota filha nunca aparece.
  • O replace do Navigate troca a entrada do histórico: o botão voltar não leva de novo à tela bloqueada.
  • O end no link de Resumo impede que ele fique ativo em /conta/pedidos.
