Persistindo Dados de Tarefas com useEffect e Storage — Resposta

Aula 13 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um gerenciador de tarefas que sobrevive ao recarregamento: o estado começa com a leitura do localStorage por inicialização preguiçosa (useState(carregarTarefas)), um useEffect grava a lista serializada a cada mudança e blocos try/catch protegem contra storage indisponível ou dado corrompido.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/TaskManager.jsx

// Início: src/components/TaskManager.jsx — tarefas persistidas no localStorage
import { useEffect, useState } from 'react';

const CHAVE = 'aula13-tarefas';

// Lê as tarefas salvas uma única vez; se não houver ou o dado estiver corrompido, começa vazio
function carregarTarefas() {
  try {
    const salvo = localStorage.getItem(CHAVE);
    return salvo ? JSON.parse(salvo) : [];
  } catch {
    return [];
  }
}

// Gerenciador de tarefas que sincroniza o estado com o armazenamento do navegador
export default function TaskManager() {
  const [tarefas, setTarefas] = useState(carregarTarefas);
  const [texto, setTexto] = useState('');
  const [aviso, setAviso] = useState('');

  useEffect(() => {
    try {
      localStorage.setItem(CHAVE, JSON.stringify(tarefas));
      setAviso('');
    } catch {
      setAviso('Não foi possível salvar neste navegador; as tarefas valem só até fechar a aba.');
    }
  }, [tarefas]);

  // Adiciona a tarefa digitada
  function adicionar(evento) {
    evento.preventDefault();
    if (!texto.trim()) return;
    setTarefas((atuais) => [...atuais, { id: Date.now(), texto: texto.trim(), feita: false }]);
    setTexto('');
  }

  // Marca ou desmarca uma tarefa
  function alternar(id) {
    setTarefas((atuais) => atuais.map((t) => (t.id === id ? { ...t, feita: !t.feita } : t)));
  }

  // Remove uma tarefa
  function remover(id) {
    setTarefas((atuais) => atuais.filter((t) => t.id !== id));
  }

  return (
    <section className="card">
      <h2>Tarefas do turno</h2>
      <form className="linha" onSubmit={adicionar}>
        <input value={texto} onChange={(e) => setTexto(e.target.value)} placeholder="Nova tarefa" aria-label="Nova tarefa" />
        <button type="submit">Adicionar</button>
        <button type="button" className="secundario" onClick={() => setTarefas([])}>Limpar tudo</button>
      </form>
      {aviso && <p className="erro">{aviso}</p>}
      {tarefas.length === 0 && <p className="muted">Nenhuma tarefa salva.</p>}
      <ul className="tarefas">
        {tarefas.map((t) => (
          <li key={t.id}>
            <input type="checkbox" checked={t.feita} onChange={() => alternar(t.id)} aria-label={`Concluir ${t.texto}`} />
            <span style={{ textDecoration: t.feita ? 'line-through' : 'none' }}>{t.texto}</span>
            <button className="secundario" onClick={() => remover(t.id)}>Remover</button>
          </li>
        ))}
      </ul>
    </section>
  );
}
// Fim de TaskManager.jsx

Como rodar

  1. Num projeto Vite + React, salve o arquivo acima e renderize <TaskManager /> no App.jsx
  2. npm run dev, adicione três tarefas e marque uma
  3. Recarregue a aba e confira que tudo continua lá
  4. No DevTools, aba Application, edite a chave aula13-tarefas para um texto inválido e recarregue

O que observar

  • useState(carregarTarefas), sem parênteses, lê o storage só na montagem; useState(carregarTarefas()) leria a cada renderização.
  • O storage guarda apenas texto: sem JSON.stringify a lista vira [object Object].
  • Com o JSON corrompido, o catch devolve uma lista vazia em vez de derrubar a página.
