Monitorando o Ciclo de Vida com useEffect — Resposta

Aula 13 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O LifecycleTracker com três efeitos: um de montagem com array vazio, um que roda quando cliques muda e um cronômetro com setInterval encerrado por clearInterval na função de limpeza. O App monta e desmonta o componente e mostra na tela o log de cada fase.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/LifecycleTracker.jsx

// Início: src/components/LifecycleTracker.jsx — montagem, atualização e limpeza
import { useEffect, useState } from 'react';

// Registra no log cada fase do ciclo de vida e mantém um cronômetro com limpeza
export default function LifecycleTracker({ registrar }) {
  const [cliques, setCliques] = useState(0);
  const [segundos, setSegundos] = useState(0);

  useEffect(() => {
    registrar('montado');
    return () => registrar('desmontado');
  }, []);

  useEffect(() => {
    registrar(`cliques mudou para ${cliques}`);
  }, [cliques]);

  useEffect(() => {
    const id = setInterval(() => setSegundos((s) => s + 1), 1000);
    return () => {
      clearInterval(id);
      registrar(`intervalo ${id} encerrado`);
    };
  }, []);

  return (
    <section className="card">
      <h2>LifecycleTracker</h2>
      <p className="grande">{segundos}s na tela</p>
      <button onClick={() => setCliques(cliques + 1)}>Cliques: {cliques}</button>
    </section>
  );
}
// Fim de LifecycleTracker.jsx

src/App.jsx

// Início: src/App.jsx — monta e desmonta o componente observado
import { useState } from 'react';
import LifecycleTracker from './components/LifecycleTracker.jsx';

// Controla se o tracker está na tela e exibe o log das fases
export default function App() {
  const [visivel, setVisivel] = useState(true);
  const [log, setLog] = useState([]);

  // Acrescenta uma linha ao log com o horário, também no console
  function registrar(mensagem) {
    const linha = `${new Date().toLocaleTimeString('pt-BR')} — ${mensagem}`;
    console.log(linha);
    setLog((atual) => [...atual, linha]);
  }

  return (
    <main>
      <div className="linha">
        <button onClick={() => setVisivel(!visivel)}>{visivel ? 'Desmontar' : 'Montar'} componente</button>
        <button className="secundario" onClick={() => setLog([])}>Limpar log</button>
      </div>
      {visivel && <LifecycleTracker registrar={registrar} />}
      <ol className="log">
        {log.map((linha, i) => (
          <li key={i}>{linha}</li>
        ))}
      </ol>
    </main>
  );
}
// Fim de App.jsx

Como rodar

  1. Num projeto Vite + React, salve os dois arquivos acima
  2. npm run dev com o console do DevTools aberto
  3. Clique algumas vezes, depois em Desmontar, e confira no log o intervalo encerrado
  4. Monte de novo e veja o cronômetro recomeçar do zero

O que observar

  • Sem o return com clearInterval, cada montagem deixa um intervalo antigo rodando e o tempo passa a contar em dobro.
  • Em desenvolvimento, o StrictMode monta, desmonta e monta de novo na primeira vez: por isso o log começa com montado, desmontado, montado. É assim que o React testa se a limpeza está certa.
  • Um efeito sem array de dependências roda depois de toda renderização; se ele alterar estado, vira um laço infinito.
