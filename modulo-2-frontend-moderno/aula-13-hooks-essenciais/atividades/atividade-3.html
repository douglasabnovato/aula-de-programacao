Foco Automático e Rastreamento com useRef — Resposta

Aula 13 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um formulário de busca em que o campo recebe o foco sozinho ao abrir e pelo botão Focar campo, usando inputRef.current.focus(), e duas refs de contagem: uma de renderizações e outra de cliques que muda sem redesenhar a tela, provando que alterar .current não dispara renderização.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/SearchForm.jsx

// Início: src/components/SearchForm.jsx — referência ao DOM e valor que não renderiza
import { useEffect, useRef, useState } from 'react';

// Formulário que foca o campo sozinho e conta renderizações sem provocar novas
export default function SearchForm() {
  const inputRef = useRef(null);
  const renders = useRef(0);
  const cliquesSilenciosos = useRef(0);
  const [busca, setBusca] = useState('');
  const [, setAtualizar] = useState(0);

  renders.current += 1;

  useEffect(() => {
    inputRef.current.focus();
  }, []);

  // Coloca o cursor no campo de busca
  function focarCampo() {
    inputRef.current.focus();
  }

  // Altera a ref sem pedir renderização: a tela não muda até o próximo render
  function contarEmSilencio() {
    cliquesSilenciosos.current += 1;
    console.log('cliquesSilenciosos =', cliquesSilenciosos.current);
  }

  return (
    <section className="card">
      <h2>Busca de clientes</h2>
      <div className="linha">
        <input ref={inputRef} value={busca} onChange={(e) => setBusca(e.target.value)} placeholder="Nome ou protocolo" aria-label="Buscar cliente" />
        <button onClick={focarCampo}>Focar campo</button>
      </div>
      <p>Renderizações: <strong>{renders.current}</strong></p>
      <p>Cliques silenciosos (ref): <strong>{cliquesSilenciosos.current}</strong></p>
      <div className="linha">
        <button className="secundario" onClick={contarEmSilencio}>Somar na ref</button>
        <button className="secundario" onClick={() => setAtualizar((n) => n + 1)}>Forçar renderização</button>
      </div>
    </section>
  );
}
// Fim de SearchForm.jsx

Como rodar

  1. Num projeto Vite + React, salve o arquivo acima e renderize <SearchForm /> no App.jsx
  2. npm run dev: o cursor já aparece no campo
  3. Clique três vezes em Somar na ref e observe que o número na tela não muda
  4. Clique em Forçar renderização ou digite no campo: o valor acumulado aparece de uma vez

O que observar

  • Na primeira renderização inputRef.current ainda é null; ele só aponta para o input depois que o React monta o elemento, por isso o foco fica no useEffect.
  • Cada letra digitada soma uma renderização, porque busca é estado; os cliques na ref não somam.
  • Em desenvolvimento com StrictMode, o contador de renderizações sobe de dois em dois.
