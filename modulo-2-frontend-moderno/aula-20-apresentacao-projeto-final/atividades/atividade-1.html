# Reserva Fácil — Escopo

## Problema
O coworking fictício Ladeira Hub controla reservas das três salas de reunião por mensagens de celular.
Duas reservas para o mesmo horário acontecem toda semana e ninguém sabe quais salas estão livres.
O Reserva Fácil mostra a agenda de cada sala e registra reservas sem conflito de horário.

## Quem usa
- Pessoas associadas ao coworking (reservam salas)
- Recepção (confere e cancela reservas)

## Requisitos do Módulo 2 e como o projeto atende
| Requisito | Onde aparece no projeto |
|---|---|
| Rotas com parâmetro (Aula 14) | `/salas/:id` mostra a agenda de uma sala |
| Formulário validado (Aula 16) | Nova reserva com data, horário e conflito checado |
| API REST com carregando e erro (Aula 17) | Salas e reservas lidas e gravadas na API |
| Estado global com Context (Aula 18) | Usuário logado e tema compartilhados |
| Deploy gratuito (Aula 19) | GitHub Pages com workflow de Actions |

## Fora do escopo
- Pagamento de reservas
- Notificação por e-mail
- Aplicativo de celular nativo

## Mapa de rotas
| Rota | Página | Dados |
|---|---|---|
| `/` | Início | lista de salas |
| `/salas/:id` | Agenda da sala | reservas da sala |
| `/reservar` | Nova reserva | formulário |
| `/minhas-reservas` | Minhas reservas (protegida) | reservas do usuário |

## Onde vive cada estado
- URL: sala escolhida e data filtrada
- Contexto: usuário logado e tema
- Local: campos do formulário, carregando e erro de cada busca

Como usar

  1. Preencha o canvas com o seu projeto até os cinco requisitos aparecerem como cobertos
  2. Copie a prévia para docs/escopo.md e para a seção Escopo do README
  3. Crie uma issue para cada linha da tabela de requisitos, com critério de aceite em lista de tarefas
  4. Organize as issues num quadro do GitHub Projects com as colunas A fazer, Fazendo e Feito

O que observar

  • Requisito sem "onde aparece" é risco de reprovação: o canvas marca como PENDENTE.
  • A lista Fora do escopo protege o prazo tanto quanto a lista do que será feito.
  • Uma issue como "Fazer o site" não tem fim verificável; "Formulário de reserva recusa horário ocupado" tem.
