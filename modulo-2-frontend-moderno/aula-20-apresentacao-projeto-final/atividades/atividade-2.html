# Reserva Fácil

Reservas de salas de reunião sem conflito de horário para o coworking fictício Ladeira Hub.

**Aplicação publicada:** https://SEU-USUARIO.github.io/reserva-facil/

## Funcionalidades
- Agenda de cada sala por data (`/salas/:id?data=2026-10-05`)
- Nova reserva com validação e checagem de conflito
- Área Minhas reservas, protegida por login simulado
- Tema claro e escuro

## Tecnologias
React 18, React Router, Tailwind CSS, Context API com useReducer, Vite, GitHub Pages.

## Como rodar
```bash
git clone https://github.com/SEU-USUARIO/reserva-facil.git
cd reserva-facil
npm install
npm run dev
```

## Decisões técnicas
| Decisão | Alternativa descartada | Motivo |
|---|---|---|
| Data filtrada na URL | useState na página | link da agenda pode ser compartilhado |
| Usuário em Context | props a partir do App | quatro níveis de repasse |
| Admin com lazy | import no topo | visitante comum não baixa o código do Admin |

## Qualidade verificada
- Sem erros no console
- Testado em 375px, 768px e 1280px
- Navegável só com teclado, com foco visível
- Contraste AA conferido nas cores da marca

## Próximos passos
- Autenticação real
- Aviso por e-mail um dia antes da reserva

Como usar

  1. Troque os dados do modelo pelos do seu projeto, mantendo as seções
  2. Percorra o checklist abaixo registrando a evidência de cada item (link do PR, print, comando)
  3. Corrija o que falhar antes de marcar; item marcado sem evidência não soma
  4. Com 100%, abra um pull request final e peça a revisão de um colega

O que observar

  • A primeira pergunta da banca costuma ser "onde está rodando?": o link publicado fica no topo do README.
  • A tabela de decisões técnicas já prepara a defesa da próxima prática.
  • Abrir o link em janela anônima pega os erros de base e de rotas que o seu navegador esconde com cache.
