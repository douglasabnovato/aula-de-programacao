Formulário de Agendamento com Estado Único — Resposta

Aula 16 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O formulário de agendamento do pet shop fictício Bicho Feliz com cinco campos de tipos diferentes (texto, telefone, select, radio e checkbox) guardados num único objeto de estado e atualizados por uma só função. O resumo abaixo do formulário mostra o estado mudando a cada tecla.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/FormAgendamento.jsx

// Início: src/components/FormAgendamento.jsx — formulário controlado com estado único
import { useState } from 'react';

const inicial = { tutor: '', telefone: '', porte: 'pequeno', servico: 'banho', termos: false };

// Formulário de agendamento em que todos os campos leem e escrevem no mesmo objeto
export default function FormAgendamento() {
  const [form, setForm] = useState(inicial);

  // Atualiza o campo que disparou o evento, tratando checkbox à parte
  function atualizar(evento) {
    const { name, value, type, checked } = evento.target;
    setForm({ ...form, [name]: type === 'checkbox' ? checked : value });
  }

  return (
    <form className="card">
      <h2>Agendar banho — Bicho Feliz</h2>
      <div className="campo">
        <label htmlFor="tutor">Nome do tutor</label>
        <input id="tutor" name="tutor" value={form.tutor} onChange={atualizar} />
      </div>
      <div className="campo">
        <label htmlFor="telefone">Telefone</label>
        <input id="telefone" name="telefone" type="tel" placeholder="(32) 99999-0000"
          value={form.telefone} onChange={atualizar} />
      </div>
      <div className="campo">
        <label htmlFor="porte">Porte do cachorro</label>
        <select id="porte" name="porte" value={form.porte} onChange={atualizar}>
          <option value="pequeno">Pequeno</option>
          <option value="medio">Médio</option>
          <option value="grande">Grande</option>
        </select>
      </div>
      <fieldset className="campo">
        <legend>Serviço</legend>
        <label>
          <input type="radio" name="servico" value="banho"
            checked={form.servico === 'banho'} onChange={atualizar} /> Banho
        </label>
        <label>
          <input type="radio" name="servico" value="banho-tosa"
            checked={form.servico === 'banho-tosa'} onChange={atualizar} /> Banho e tosa
        </label>
      </fieldset>
      <label className="check">
        <input type="checkbox" name="termos" checked={form.termos} onChange={atualizar} />
        Li e aceito as regras do pet shop
      </label>
      <p className="muted">Resumo ao vivo do estado:</p>
      <pre className="resumo">{JSON.stringify(form, null, 2)}</pre>
    </form>
  );
}
// Fim de FormAgendamento.jsx

Como rodar

  1. npm create vite@latest bicho-feliz -- --template react, cd bicho-feliz e npm install
  2. Crie src/components/FormAgendamento.jsx com o código acima
  3. No App.jsx, importe e renderize <FormAgendamento />
  4. npm run dev e preencha os campos observando o resumo

O que observar

  • Sem onChange, um value fixo trava o campo e o React avisa no console.
  • O colchete em [name]: value usa o atributo name do campo como chave, por isso uma função atende todos.
  • Clicar no texto do rótulo leva o foco ao campo: é o htmlFor ligado ao id.
