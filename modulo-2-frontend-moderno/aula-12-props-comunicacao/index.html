Aula 12: Props e Comunicação entre Componentes

Módulo 2: Frontend Moderno — Ecossistema learnTECH

📦 1. O Fluxo de Dados Unidirecional no React explicado na prática

Compreenda como as informações trafegam estruturalmente de cima para baixo na árvore de componentes utilizando propriedades (*props*).

  • ▶️ O Fluxo de Dados Unidirecional no React Visão conceitual e prática sobre a hierarquia de componentes e distribuição limpa de dados.
  • ▶️ Passando Dados com Props em Componentes Funcionais Como injetar atributos personalizados e reutilizar blocos visuais de forma dinâmica.
  • ▶️ Renderização de Listas e a Propriedade Key Estratégias para iterar coleções de dados com `.map()` e otimizar a reconciliação do DOM.
  • ▶️ Componentes Inteligentes vs Componentes de Apresentação Padrões de arquitetura para separar lógica de negócio e estruturação visual pura.

Siga os 10 passos abaixo para estruturar a comunicação descendente em sua aplicação:

  1. Estrutura Hierárquica: Crie uma estrutura básica de componentes pai (`App.jsx`) e filho (`UserCard.jsx`).
  2. Definição de Mock de Dados: Defina um objeto de dados estáticos de usuário no componente pai.
  3. Injeção de Propriedades: Passe o objeto de dados para o componente filho utilizando uma propriedade chamada user.
  4. Recepção de Parâmetros: Receba os parâmetros de entrada na função do componente filho.
  5. Renderização Dinâmica: Renderize dinamicamente as propriedades recebidas (nome, cargo, avatar) no JSX do filho.
  6. Múltiplos Elementos: Crie uma lista com múltiplos objetos de usuários no componente pai.
  7. Iteração com Map: Utilize o método `.map()` no pai para renderizar múltiplos componentes filhos iterativamente.
  8. Atribuição de Key: Atribua a prop obrigatória key baseada em identificadores únicos para cada item mapeado.
  9. Validação Visual: Valide no navegador a correta distribuição e exibição dos dados descendentes em tela.
  10. Refatoração Modular: Separe componentes de apresentação pura de componentes de lógica central.
Concluiu todos os passos?

📋 2. Desestruturação de Props e Tipagem Básica de Componentes

Domine técnicas avançadas para extração limpa de propriedades e validação de contratos de dados em seus componentes.

  • ▶️ Desestruturação de Objetos em JavaScript Aplicada ao React Como simplificar a extração de variáveis a partir do objeto props de forma limpa e moderna.
  • ▶️ Valores Padrão em Componentes com Default Props Evitando falhas em runtime ao definir comportamentos de fallback para propriedades opcionais.
  • ▶️ Validação de Tipos com PropTypes no React Introdução à verificação estática de tipos de dados passados entre componentes.
  • ▶️ Boas Práticas de Contratos de Dados em Frontends Modulares Como manter componentes previsíveis através de tipagens claras e documentadas.

Siga os 10 passos abaixo para refatorar e validar propriedades em componentes:

  1. Localização de Componente: Localize um componente existente que receba múltiplas propriedades.
  2. Desestruturação na Assinatura: Aplique a desestruturação do JavaScript diretamente na assinatura da função (ex: ({ title, description }) => ...).
  3. Remoção de Prefixo: Elimine a necessidade de acessar propriedades utilizando o prefixo props..
  4. Valores Fallback: Implemente valores padrão diretamente nos parâmetros desestruturados para propriedades opcionais.
  5. Casos de Teste Incompletos: Crie um caso de teste passando dados parciais para o componente.
  6. Validação de Fallback: Valide se os valores padrão assumem o controle corretamente sem gerar erros visuais.
  7. Configuração de Tipagem: Instale ou configure validações de tipo básicas para o componente.
  8. Contratos de Dados: Defina regras estritas de tipos de dados esperados (strings, números, booleans).
  9. Auditoria de Console: Teste passar um tipo incorreto e analise o aviso gerado no console do desenvolvedor.
  10. Documentação Limpa: Documente os contratos de propriedades utilizando comentários descritivos padronizados.
Concluiu todos os passos?

🔄 3. Comunicação Reversa e Padrões de Composição Avançada (children)

Aprenda a enviar eventos dos filhos para os pais utilizando callbacks e a criar layouts genéricos flexíveis com a prop children.

  • ▶️ Comunicação Reversa no React: Passando Funções via Props Como permitir que componentes filhos comuniquem ações e atualizem estados nos componentes pais.
  • ▶️ O Poder da Prop Children na Composição de Componentes Criando contêineres e wrappers reutilizáveis para estruturar layouts complexos.
  • ▶️ Padrões de Inversão de Controle e Callbacks Técnicas avançadas de engenharia frontend para desacoplar comportamentos de UI.
  • ▶️ Arquitetura Escalável com Componentes Compostos Como organizar ecossistemas de componentes altamente reutilizáveis e limpos.

Siga os 10 passos abaixo para estruturar comunicação reversa e composição avançada:

  1. Componente de Ação: Crie um componente de botão interativo filho chamado CustomButton.jsx.
  2. Função de Manipulação Pai: Defina uma função no componente pai que altere um estado local.
  3. Passagem de Callback: Passe essa função do pai para o filho utilizando uma propriedade chamada onClick.
  4. Conexão de Evento Nativo: Conecte o evento do botão filho para disparar a função recebida via prop.
  5. Validação Reversa: Valide a comunicação reversa alterando o estado do pai através da ação do filho.
  6. Contêiner Genérico: Crie um componente de layout contêiner chamado CardContainer.jsx.
  7. Utilização de Children: Utilize a propriedade especial children na estrutura interna do contêiner.
  8. Injeção de Conteúdo: Envolva diferentes blocos de elementos visuais utilizando o componente contêiner criado.
  9. Testes de Flexibilidade: Injete títulos, botões e textos variados dentro do container genérico validando o layout.
  10. Integração Completa: Valide o funcionamento conjunto de eventos reversos com a composição baseada em children.
Concluiu todos os passos?
