Aula 12: Props e Comunicação entre Componentes

Módulo 2: Frontend Moderno — Ecossistema ByteClass

🎯 Objetivo Pedagógico

Dominar a passagem de dados descendente (props) e a comunicação reversa por meio de funções de callback entre componentes no React.

🔗 Curadoria de Conteúdo (Links de Apoio)

  • [FUNDAMENTOS] O Fluxo de Dados Unidirecional no React explicado na prática
  • [INICIANTE] Desestruturação de Props e Tipagem Básica de Componentes
  • [INTERMEDIÁRIO] Comunicação Reversa: Passando Funções via Props para Filhos
  • [AVANÇADO] Composição Avançada com o padrão children e Componentes Genéricos

🛠️ Roteiro Prático (10 Passos)

  • 1. Criação do componente estrutural de lista de tarefas (TaskList.jsx).
  • 2. Implementação do componente de formulário de entrada (TaskInput.jsx).
  • 3. Definição do estado global de tarefas no componente principal App.jsx.
  • 4. Passagem da lista de dados via props para o componente de exibição.
  • 5. Desestruturação correta das propriedades recebidas no componente filho.
  • 6. Criação de função de adição de itens no pai e envio via *callback props*.
  • 7. Implementação da função de exclusão de tarefas mapeando por ID único.
  • 8. Estilização dinâmica condicional de estados concluídos e pendentes.
  • 9. Validação de integridade de dados e prevenção de comportamento padrão (preventDefault).
  • 10. Testes integrados do fluxo completo de adição e remoção via comunicação de componentes.
