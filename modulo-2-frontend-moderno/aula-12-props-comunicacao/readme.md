# ⚡ Ementa da Aula 12: Props e Comunicação entre Componentes | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa leva o aluno de uma lista de cards escrita à mão até componentes que recebem dados por props, declaram seu contrato de tipos, avisam o pai por callbacks e aceitam qualquer conteúdo por children.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: O Fluxo de Dados Unidirecional no React explicado na prática
* **Props de pai para filho:** o componente pai guarda os dados e os entrega a quem exibe.
* **Listas com `.map()` e `key`:** um componente por item, com identificador estável.
* **Apresentação e lógica separadas:** componentes que só exibem e componentes que organizam dados.

### 2. Bloco 2: Desestruturação de Props e Tipagem Básica de Componentes
* **Desestruturação na assinatura:** props lidas pelo nome, sem o prefixo `props.`.
* **Valores padrão:** comportamento seguro quando uma prop opcional não chega.
* **Contrato de tipos:** `prop-types` e JSDoc para declarar o que o componente espera.

### 3. Bloco 3: Comunicação Reversa e Padrões de Composição Avançada (children)
* **Callbacks via props:** o filho chama a função do pai para pedir uma mudança de estado.
* **A prop `children`:** moldura genérica que recebe qualquer conteúdo.
* **Composição:** combinar componentes pequenos em vez de criar variações de um grande.
