Aplicando Desestruturação e Validação de Tipos — Resposta

Aula 12 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

Um CourseCard com as props desestruturadas na assinatura, sem nenhum props., valores padrão para tudo que é opcional, contrato de tipos com prop-types e documentação JSDoc. O App.jsx testa um caso completo, um parcial (só o título) e um com tipo errado (hours="vinte").

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/components/CourseCard.jsx

// Início: src/components/CourseCard.jsx — props desestruturadas, valores padrão e contrato de tipos
import PropTypes from 'prop-types';

/**
 * Card de curso.
 * @param {string} title - nome do curso (obrigatório)
 * @param {string} description - resumo em uma frase
 * @param {number} hours - carga horária em horas
 * @param {'Iniciante'|'Intermediário'|'Avançado'} level - nível do curso
 * @param {string[]} tags - assuntos cobertos
 * @param {boolean} featured - destaca o card
 */
export default function CourseCard({
  title,
  description = 'Descrição em breve.',
  hours = 0,
  level = 'Iniciante',
  tags = [],
  featured = false,
}) {
  return (
    <article className="card" style={featured ? { borderColor: 'var(--primary)' } : undefined}>
      <h3>{title}</h3>
      <p className="muted">{description}</p>
      <p>{hours > 0 ? `${hours} h` : 'Carga horária a definir'} · {level}</p>
      <div className="tags">
        {tags.map((tag) => (
          <span key={tag}>{tag}</span>
        ))}
      </div>
    </article>
  );
}

CourseCard.propTypes = {
  title: PropTypes.string.isRequired,
  description: PropTypes.string,
  hours: PropTypes.number,
  level: PropTypes.oneOf(['Iniciante', 'Intermediário', 'Avançado']),
  tags: PropTypes.arrayOf(PropTypes.string),
  featured: PropTypes.bool,
};
// Fim de CourseCard.jsx

src/App.jsx

// Início: src/App.jsx — casos completo, parcial e com tipo errado
import CourseCard from './components/CourseCard.jsx';

// Renderiza três cards para testar valores padrão e o aviso de tipo
export default function App() {
  return (
    <main className="grade">
      <CourseCard title="React do Zero" description="Componentes, props e estado." hours={40}
        level="Iniciante" tags={['JSX', 'Props', 'useState']} featured />
      <CourseCard title="Node.js na Prática" />
      <CourseCard title="Testes no Frontend" hours="vinte" />
    </main>
  );
}
// Fim de App.jsx

Como rodar

  1. Num projeto Vite + React, rode npm install prop-types
  2. Salve os dois arquivos acima
  3. npm run dev e abra o console do DevTools
  4. Leia o aviso sobre hours e corrija para hours={20}

O que observar

  • O card só com título não quebra: descrição, nível e carga horária assumem os valores padrão da assinatura.
  • O aviso de prop-types aparece no React 18 (usado no demo). No React 19, que o Vite instala hoje, propTypes é ignorado e a verificação de tipos passa a ser feita com TypeScript; o JSDoc continua documentando o contrato.
  • Com hours="vinte", a comparação hours > 0 é falsa e o card mostra "a definir": o erro de tipo virou erro silencioso de tela.
