Tema Claro e Escuro com createContext, Provider e useContext — Resposta

Aula 18 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

A loja fictícia Tear Mineiro com o tema claro ou escuro disponível para qualquer componente via Context. Cabecalho e Vitrine deixaram de receber e repassar tema; só lê o contexto quem usa o valor. O hook useTema dá uma mensagem clara se alguém usar o tema fora do provedor.

src/data/produtos.js

// Início: src/data/produtos.js — produtos fictícios da loja Tear Mineiro
export const produtos = [
  { id: 1, nome: 'Tapete de tear', preco: 180 },
  { id: 2, nome: 'Toalha bordada', preco: 95 },
  { id: 3, nome: 'Cesto de palha', preco: 62 },
  { id: 4, nome: 'Almofada de crochê', preco: 74 },
];

// Formata um número como valor em reais
export function brl(valor) {
  return valor.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });
}
// Fim de produtos.js

src/contexts/TemaContext.jsx

// Início: src/contexts/TemaContext.jsx — contexto do tema da loja
import { createContext, useContext, useState } from 'react';

export const TemaContext = createContext(null);

// Guarda o tema e oferece a função de alternância para toda a árvore abaixo dele
export function TemaProvider({ children }) {
  const [tema, setTema] = useState('claro');

  // Troca entre claro e escuro a partir do valor atual
  function alternarTema() {
    setTema((atual) => (atual === 'claro' ? 'escuro' : 'claro'));
  }

  return <TemaContext.Provider value={{ tema, alternarTema }}>{children}</TemaContext.Provider>;
}

// Lê o contexto e avisa com clareza quando o componente está fora do provedor
export function useTema() {
  const contexto = useContext(TemaContext);
  if (!contexto) {
    throw new Error('useTema precisa ser usado dentro de <TemaProvider>.');
  }
  return contexto;
}
// Fim de TemaContext.jsx

src/components/Loja.jsx

// Início: src/components/Loja.jsx — árvore da loja sem repasse de props de tema
import { useTema } from '../contexts/TemaContext.jsx';
import { produtos, brl } from '../data/produtos.js';

// Botão que lê e altera o tema direto do contexto
function BotaoTema() {
  const { tema, alternarTema } = useTema();
  return <button onClick={alternarTema}>{tema === 'claro' ? 'Tema escuro' : 'Tema claro'}</button>;
}

// Cabeçalho que não sabe nada sobre tema: só posiciona o botão
function Cabecalho() {
  return (
    <header>
      <h2>Tear Mineiro</h2>
      <BotaoTema />
    </header>
  );
}

// Card que usa o tema para escolher o texto do selo
function CardProduto({ produto }) {
  const { tema } = useTema();
  return (
    <article className="produto">
      <strong>{produto.nome}</strong>
      <span>{brl(produto.preco)}</span>
      <small>{tema === 'claro' ? 'Feito à mão' : 'Feito à mão · modo noturno'}</small>
    </article>
  );
}

// Vitrine que também não recebe mais props de tema
function Vitrine() {
  return (
    <section className="vitrine">
      {produtos.map((p) => (
        <CardProduto key={p.id} produto={p} />
      ))}
    </section>
  );
}

// Moldura que aplica a classe do tema atual
export default function Layout() {
  const { tema } = useTema();
  return (
    <div className={`loja ${tema}`}>
      <Cabecalho />
      <Vitrine />
    </div>
  );
}
// Fim de Loja.jsx

src/App.jsx

// Início: src/App.jsx — o provedor envolve a loja inteira
import { TemaProvider } from './contexts/TemaContext.jsx';
import Layout from './components/Loja.jsx';

// Componente raiz: nenhuma prop de tema sai daqui
export default function App() {
  return (
    <TemaProvider>
      <Layout />
    </TemaProvider>
  );
}
// Fim de App.jsx

Como rodar

  1. npm create vite@latest tear-mineiro -- --template react, cd tear-mineiro e npm install
  2. Crie src/data, src/contexts e src/components com os arquivos acima e substitua o App.jsx
  3. Copie o CSS das classes .loja, .claro e .escuro para o index.css
  4. npm run dev e alterne o tema; com a extensão React Developer Tools, inspecione as props de cada componente

O que observar

  • Renderizar <BotaoTema /> fora do TemaProvider dispara o erro escrito em useTema, em vez de um "cannot destructure null" sem contexto.
  • No React Developer Tools, Cabecalho e Vitrine não têm mais props de tema.
  • Context resolve distância na árvore, não organização de estado: o tema continua sendo um useState comum dentro do provedor.
