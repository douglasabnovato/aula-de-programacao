Separando a Área Administrativa com lazy e Suspense — Resposta

Aula 19 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

O Cine Clube Paraibuna entregando primeiro só a programação: a página de administração vira um arquivo JavaScript separado, baixado apenas quando alguém a abre, com uma mensagem de carregamento enquanto isso. Os cartazes usam loading="lazy" e dimensões fixas para não empurrar o layout. No demo, o atraso do download é simulado com 1,2 s.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

src/pages/Admin.jsx

// Início: src/pages/Admin.jsx — página pesada que só a equipe usa
// Painel administrativo com relatório de público; em projeto real traria editor e gráficos
export default function Admin() {
  const publico = [
    { filme: 'Noite no Paraibuna', ingressos: 312 },
    { filme: 'Serra Azul', ingressos: 198 },
    { filme: 'Café com Neblina', ingressos: 254 },
  ];
  const maior = Math.max(...publico.map((p) => p.ingressos));
  return (
    <section className="card">
      <h2>Administração</h2>
      {publico.map((p) => (
        <div key={p.filme}>
          <span>{p.filme} — {p.ingressos}</span>
          <div className="barra"><div style={{ width: `${(p.ingressos / maior) * 100}%` }} /></div>
        </div>
      ))}
    </section>
  );
}
// Fim de Admin.jsx

src/App.jsx

// Início: src/App.jsx — programação carregada de início e administração sob demanda
import { lazy, Suspense, useState } from 'react';

const Admin = lazy(() => import('./pages/Admin.jsx'));

// Cartaz com carregamento adiado e dimensões reservadas (imagem SVG gerada no próprio código)
function Cartaz({ titulo }) {
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="160" height="240"><rect width="100%" height="100%" fill="#30363D"/><text x="50%" y="50%" fill="#00FF66" font-size="14" text-anchor="middle">${titulo}</text></svg>`;
  return (
    <img src={`data:image/svg+xml,${encodeURIComponent(svg)}`} alt={`Cartaz de ${titulo}`}
      width="160" height="240" loading="lazy" style={{ borderRadius: 8 }} />
  );
}

// Componente raiz: a página de administração só é baixada quando aberta
export default function App() {
  const [pagina, setPagina] = useState('programacao');

  return (
    <>
      <div className="linha">
        <button className={pagina === 'programacao' ? '' : 'secundario'} onClick={() => setPagina('programacao')}>Programação</button>
        <button className={pagina === 'admin' ? '' : 'secundario'} onClick={() => setPagina('admin')}>Administração</button>
      </div>
      {pagina === 'programacao' && (
        <section className="card">
          <h2>Em cartaz</h2>
          <div className="linha">
            <Cartaz titulo="Serra Azul" />
            <Cartaz titulo="Café com Neblina" />
          </div>
        </section>
      )}
      {pagina === 'admin' && (
        <Suspense fallback={<p className="card">Carregando administração...</p>}>
          <Admin />
        </Suspense>
      )}
    </>
  );
}
// Fim de App.jsx

Como rodar

  1. Crie os dois arquivos num projeto Vite + React
  2. npm run build e veja em dist/assets um arquivo separado para o Admin
  3. npm run preview com a aba Rede aberta: o arquivo do Admin só aparece ao clicar em Administração
  4. Rode o Lighthouse no modo celular e compare a nota de desempenho com a versão sem lazy

O que observar

  • Sem o Suspense em volta, o React não tem o que mostrar enquanto o arquivo chega e interrompe a renderização com erro.
  • O import() dinâmico é o que faz o Vite gerar o arquivo separado; um import no topo juntaria tudo de novo.
  • width e height na imagem reservam o espaço antes do download e evitam o salto de layout.
