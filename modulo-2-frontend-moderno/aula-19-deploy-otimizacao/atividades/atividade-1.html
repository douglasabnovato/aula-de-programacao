Publicando a SPA com Configuração por Ambiente — Resposta

Aula 19 · Módulo 2: Frontend Moderno · ByteClass

O que esta atividade entrega

A configuração de publicação do site fictício Cine Clube Paraibuna: arquivos .env por modo, leitura centralizada em config.js, base ajustada para o GitHub Pages, workflow de deploy gratuito com fallback de rotas e um painel que mostra a configuração ativa com o checklist de publicação. No demo, os botões simulam o que o Vite injeta em cada modo.

src/config.js

// Início: src/config.js — ponto único de leitura das variáveis de ambiente
// Monta a configuração da aplicação a partir do objeto de ambiente recebido
export function lerConfiguracao(env) {
  return {
    modo: env.MODE,
    producao: env.PROD,
    apiUrl: env.VITE_API_URL ?? 'variável VITE_API_URL não definida',
    ambiente: env.VITE_NOME_AMBIENTE ?? 'sem nome',
    base: env.BASE_URL,
  };
}

export const config = lerConfiguracao(import.meta.env);
// Fim de config.js

src/components/PainelPublicacao.jsx

// Início: src/components/PainelPublicacao.jsx — configuração ativa e checklist antes do deploy
import { useState } from 'react';

const ITENS = [
  'npm run build termina sem erros nem avisos novos',
  'npm run preview abre e navega por todas as rotas',
  'Nenhum segredo em variáveis VITE_ (tudo nelas é público)',
  'base do vite.config.js igual ao nome do repositório',
  '404.html copiado do index.html para as rotas da SPA',
  'Pages configurado com a fonte GitHub Actions',
];

// Mostra a configuração lida do ambiente e acompanha o checklist de publicação
export default function PainelPublicacao({ config }) {
  const [feitos, setFeitos] = useState([]);
  const progresso = Math.round((feitos.length / ITENS.length) * 100);

  // Marca ou desmarca um item do checklist
  function alternar(item) {
    setFeitos((atuais) => (atuais.includes(item) ? atuais.filter((i) => i !== item) : [...atuais, item]));
  }

  return (
    <section className="card">
      <h2>Cine Clube Paraibuna — publicação</h2>
      <table>
        <tbody>
          <tr><th>Modo</th><td><code>{config.modo}</code></td></tr>
          <tr><th>Ambiente</th><td>{config.ambiente}</td></tr>
          <tr><th>API</th><td><code>{config.apiUrl}</code></td></tr>
          <tr><th>Base</th><td><code>{config.base}</code></td></tr>
        </tbody>
      </table>
      <h3 style={{ marginTop: 16 }}>Checklist de deploy ({progresso}%)</h3>
      <div className="barra"><div style={{ width: `${progresso}%` }} /></div>
      <ul className="check">
        {ITENS.map((item) => (
          <li key={item}>
            <label>
              <input type="checkbox" checked={feitos.includes(item)} onChange={() => alternar(item)} /> {item}
            </label>
          </li>
        ))}
      </ul>
      {progresso === 100 && <p><strong>Pronto para publicar.</strong></p>}
    </section>
  );
}
// Fim de PainelPublicacao.jsx

.github/workflows/deploy.yml

# Início: .github/workflows/deploy.yml — build e publicação no GitHub Pages
name: Deploy static content to Pages

on:
  push:
    branches: ['main']
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v7
      - name: Set up Node
        uses: actions/setup-node@v7
        with:
          node-version: lts/*
          cache: 'npm'
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run build
      - name: Fallback da SPA
        run: cp dist/index.html dist/404.html
      - name: Setup Pages
        uses: actions/configure-pages@v6
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v5
        with:
          path: './dist'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v5
# Fim de deploy.yml

Como rodar

  1. Crie os arquivos acima num projeto Vite + React versionado num repositório chamado cine-clube
  2. npm run dev e confira a API de desenvolvimento no painel; depois npm run build e npm run preview
  3. No GitHub, em Settings → Pages, escolha GitHub Actions como fonte
  4. Faça push na main, acompanhe a aba Actions e abra o endereço publicado

O que observar

  • Variável sem o prefixo VITE_ chega como undefined: o Vite só expõe ao navegador o que tem o prefixo.
  • Tudo que está em VITE_ vai parar no JavaScript público; chave secreta fica no servidor.
  • Sem o 404.html, recarregar uma rota interna no GitHub Pages devolve a página de erro do próprio Pages.
