Painel de Vendas do Dia — map, filter e reduce

Aula 4 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um painel que filtra as vendas pelo valor mínimo escolhido, formata cada linha em reais e soma o faturamento — tudo com filter, map e reduce, sem laço for escrito à mão.

script.js

// Início: painel de vendas do dia usando filter, map e reduce
const vendas = [
  { id: 1, cliente: 'Ana Ribeiro', produto: 'Bolo de fubá', valor: 42.5 },
  { id: 2, cliente: 'Caio Mendes', produto: 'Pão de queijo (12 un.)', valor: 18 },
  { id: 3, cliente: 'Lia Souto', produto: 'Torta de frango', valor: 65 },
  { id: 4, cliente: 'Rui Batista', produto: 'Café coado 1 L', valor: 12.9 },
  { id: 5, cliente: 'Nina Farias', produto: 'Cesta de café da manhã', valor: 79.9 },
  { id: 6, cliente: 'Téo Aragão', produto: 'Broa de milho', valor: 9.5 },
  { id: 7, cliente: 'Bia Lacerda', produto: 'Bolo de cenoura', valor: 38 },
  { id: 8, cliente: 'Davi Prates', produto: 'Salgados (25 un.)', valor: 55 }
];

const campoMinimo = document.querySelector('#valorMinimo');
const saidaMinimo = document.querySelector('#saidaMinimo');
const lista = document.querySelector('#listaVendas');
const resumo = document.querySelector('#resumo');

// formata um número como moeda brasileira
const formatarMoeda = (valor) => valor.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });

// devolve só as vendas com valor igual ou acima do mínimo
const filtrarVendas = (itens, minimo) => itens.filter((venda) => venda.valor >= minimo);

// transforma cada venda num item de lista em HTML
const montarItens = (itens) => itens.map((venda) => `<li><span>${venda.cliente} — ${venda.produto}</span><strong>${formatarMoeda(venda.valor)}</strong></li>`);

// soma o valor de todas as vendas recebidas
const somarVendas = (itens) => itens.reduce((total, venda) => total + venda.valor, 0);

// atualiza lista e resumo conforme o valor mínimo escolhido
const renderizar = () => {
  const minimo = Number(campoMinimo.value);
  const selecionadas = filtrarVendas(vendas, minimo);
  saidaMinimo.textContent = formatarMoeda(minimo);
  lista.innerHTML = montarItens(selecionadas).join('') || '<li class="muted">Nenhuma venda nesse valor.</li>';
  resumo.textContent = `${selecionadas.length} de ${vendas.length} vendas · faturamento ${formatarMoeda(somarVendas(selecionadas))}`;
};

campoMinimo.addEventListener('input', renderizar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Arraste o controle e acompanhe a lista e o faturamento mudarem juntos.

O que observar

  • filter, map e reduce devolvem valores novos: o array vendas nunca muda, e por isso o controle pode ir e voltar sem perder dados.
  • Sem o .join(''), o array de strings vira texto separado por vírgulas quando entra no innerHTML.
  • O 0 no fim do reduce é o valor inicial: com ele, uma lista vazia soma zero em vez de lançar erro.
