Carrinho com Cupom — Imutabilidade na Prática

Aula 4 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Dois carrinhos lado a lado: o pedido original e o pedido com cupom de 10%. Um botão aplica o cupom alterando os objetos (versão com bug) e outro cria cópias com spread (versão correta), para o aluno ver a diferença.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

script.js

// Início: carrinho com cupom aplicado sem alterar o pedido original
const DESCONTO_CUPOM = 0.1;

const listaOriginal = document.querySelector('#listaOriginal');
const totalOriginal = document.querySelector('#totalOriginal');
const listaCupom = document.querySelector('#listaCupom');
const totalCupom = document.querySelector('#totalCupom');

// cria o pedido de exemplo do zero, sempre com objetos novos
const criarPedido = () => [
  { id: 1, nome: 'Caneca térmica', preco: 60, qtd: 1 },
  { id: 2, nome: 'Café 500 g', preco: 32, qtd: 2 },
  { id: 3, nome: 'Filtro de pano', preco: 18, qtd: 3 }
];

let original = criarPedido();
let comCupom = [];

// soma preço vezes quantidade de cada item
const totalDe = (itens) => itens.reduce((soma, { preco, qtd }) => soma + preco * qtd, 0);

// gera as linhas de um carrinho
const linhas = (itens) => itens.map(({ nome, preco, qtd }) => `<li><span>${qtd}x ${nome}</span><span>R$ ${(preco * qtd).toFixed(2)}</span></li>`).join('');

// desenha os dois carrinhos lado a lado
const renderizar = () => {
  listaOriginal.innerHTML = linhas(original);
  totalOriginal.textContent = `Total: R$ ${totalDe(original).toFixed(2)}`;
  listaCupom.innerHTML = comCupom.length ? linhas(comCupom) : '<li class="muted">Nenhum cupom aplicado.</li>';
  totalCupom.textContent = comCupom.length ? `Total: R$ ${totalDe(comCupom).toFixed(2)}` : '';
};

// versão com bug: altera os objetos do próprio pedido original
const aplicarMutando = () => {
  original.forEach((item) => {
    item.preco = item.preco * (1 - DESCONTO_CUPOM);
  });
  comCupom = original;
  renderizar();
};

// versão correta: cria um array novo com objetos novos
const aplicarImutavel = () => {
  comCupom = original.map((item) => ({ ...item, preco: item.preco * (1 - DESCONTO_CUPOM) }));
  renderizar();
};

// volta os dois carrinhos ao estado inicial
const restaurar = () => {
  original = criarPedido();
  comCupom = [];
  renderizar();
};

document.querySelector('#btnMutando').addEventListener('click', aplicarMutando);
document.querySelector('#btnImutavel').addEventListener('click', aplicarImutavel);
document.querySelector('#btnRestaurar').addEventListener('click', restaurar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Clique em 'Aplicar alterando (bug)' duas vezes, depois em 'Restaurar' e em 'Aplicar com cópia' duas vezes.

O que observar

  • Na versão com bug, o total do pedido original cai a cada clique: comCupom e original são o mesmo array.
  • Na versão com spread, o cupom é aplicado sempre sobre o preço cheio, porque o original nunca é tocado.
  • { ...item } é uma cópia rasa: se um item tivesse um objeto dentro (ex.: fornecedor), ele ainda seria compartilhado.
