Consulta de Acervo — find, some, every e sort

Aula 4 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma tela de consulta de biblioteca que busca um livro pelo código (find), mostra dois indicadores do acervo (some e every) e lista os livros ordenados por título ou por ano (sort sobre uma cópia).

script.js

// Início: consulta de acervo com find, some, every e sort
const livros = [
  { codigo: 'LV-101', titulo: 'Sertão de Vidro', autor: 'Clara Nunes Prado', ano: 2004, atrasado: false },
  { codigo: 'LV-102', titulo: 'Manual do Jardim Vertical', autor: 'Otávio Reis', ano: 2019, atrasado: true },
  { codigo: 'LV-103', titulo: 'Água de Março', autor: 'Helena Brito', ano: 1998, atrasado: false },
  { codigo: 'LV-104', titulo: 'Contos da Serra', autor: 'Mateus Coelho', ano: 2011, atrasado: false },
  { codigo: 'LV-105', titulo: 'Zona Azul', autor: 'Irene Duarte', ano: 2022, atrasado: false },
  { codigo: 'LV-106', titulo: 'Bússola Quebrada', autor: 'Paulo Viana', ano: 1987, atrasado: true },
  { codigo: 'LV-107', titulo: 'Érica e o Farol', autor: 'Sônia Macedo', ano: 2015, atrasado: false },
  { codigo: 'LV-108', titulo: 'Lógica para Curiosos', autor: 'Renato Alves', ano: 2008, atrasado: false }
];

const formBusca = document.querySelector('#formBusca');
const campoCodigo = document.querySelector('#campoCodigo');
const resultadoBusca = document.querySelector('#resultadoBusca');
const indicadores = document.querySelector('#indicadores');
const seletorOrdem = document.querySelector('#seletorOrdem');
const listaLivros = document.querySelector('#listaLivros');

// procura um livro pelo código, ignorando espaços e minúsculas
const buscarPorCodigo = (codigo) => livros.find((livro) => livro.codigo === codigo.trim().toUpperCase());

// mostra o resultado da busca ou uma mensagem de não encontrado
const mostrarBusca = (evento) => {
  evento.preventDefault();
  const livro = buscarPorCodigo(campoCodigo.value);
  resultadoBusca.textContent = livro ? `${livro.codigo}: ${livro.titulo} (${livro.autor}, ${livro.ano})` : 'Nenhum livro com esse código.';
  resultadoBusca.className = livro ? 'ok' : 'erro';
};

// calcula os indicadores gerais do acervo
const montarIndicadores = () => {
  const temAtraso = livros.some((livro) => livro.atrasado);
  const todosComAutor = livros.every((livro) => livro.autor.trim() !== '');
  indicadores.innerHTML = `<li>Algum livro atrasado? <strong>${temAtraso ? 'sim' : 'não'}</strong></li><li>Todos com autor preenchido? <strong>${todosComAutor ? 'sim' : 'não'}</strong></li>`;
};

// devolve uma cópia ordenada conforme o critério escolhido
const ordenar = (criterio) => {
  const copia = [...livros];
  if (criterio === 'ano') {
    return copia.sort((a, b) => a.ano - b.ano);
  }
  return copia.sort((a, b) => a.titulo.localeCompare(b.titulo, 'pt-BR'));
};

// desenha a lista de livros na ordem escolhida
const renderizarLista = () => {
  listaLivros.innerHTML = ordenar(seletorOrdem.value)
    .map((livro) => `<li class="${livro.atrasado ? 'atrasado' : ''}"><span>${livro.titulo}</span><small class="muted">${livro.codigo} · ${livro.ano}</small></li>`)
    .join('');
};

formBusca.addEventListener('submit', mostrarBusca);
seletorOrdem.addEventListener('change', renderizarLista);
montarIndicadores();
renderizarLista();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Busque lv-104 (em minúsculas) e depois LV-999.
  5. No console, rode [...livros].map((l) => l.titulo).sort() e compare com a lista ordenada da tela.

O que observar

  • O sort() sem função coloca 'Água de Março' e 'Érica e o Farol' depois de 'Zona Azul', porque compara códigos de caractere; localeCompare resolve.
  • find devolve o objeto ou undefined; some e every devolvem sempre um booleano.
  • Como a ordenação acontece em [...livros], a ordem de cadastro do array original continua intacta.
