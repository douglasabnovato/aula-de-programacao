🧮 1. map, filter e reduce: Transformar, Selecionar e Resumir

🎯 Desafio

A padaria fictícia Forno da Serra registra as vendas do dia num array de objetos. O dono quer ver só as vendas acima de um valor mínimo, com o preço já formatado em reais e o faturamento somado no rodapé, e hoje isso é feito com três laços for que ninguém mais entende. Como chegar no mesmo resultado encadeando três métodos de array?

Quase todo dado que chega numa interface é uma lista. map transforma cada item, filter escolhe quais ficam e reduce resume a lista num único valor — três perguntas diferentes, três métodos que devolvem algo novo sem alterar o array original.

  • 📄 Array.prototype.map() — MDN Como gerar um array novo aplicando a mesma transformação em cada item.
  • 📄 Array.prototype.filter() — MDN Como manter só os itens que passam num teste, sem remover nada do original.
  • 📄 Array.prototype.reduce() — MDN (pt-BR) O acumulador, o valor inicial e por que esquecer o segundo argumento dá erro em lista vazia.
  • 📄 Arrays — MDN Learn Revisão curta de criação, acesso por índice e os métodos mais usados no dia a dia.

🔎 2. Buscar, Verificar e Ordenar: find, some, every e sort

🎯 Desafio

A biblioteca fictícia Leitura Viva tem o acervo num array. A atendente precisa achar um livro pelo código, saber se algum está atrasado, confirmar se todos têm autor preenchido e listar por título em ordem alfabética — com o título acentuado no lugar certo. Qual método responde cada pergunta sem escrever um laço para cada uma?

Nem toda pergunta sobre uma lista devolve outra lista. find devolve um item, some e every devolvem verdadeiro ou falso, e sort reorganiza a lista — mas altera o array original e compara texto de um jeito que surpreende quem não passa uma função de comparação.

  • 📄 Array.prototype.find() — MDN Como achar o primeiro item que satisfaz uma condição e o que acontece quando nenhum satisfaz.
  • 📄 Array.prototype.some() — MDN Responder 'existe pelo menos um?' parando no primeiro acerto.
  • 📄 Array.prototype.every() — MDN Responder 'todos obedecem à regra?' e o resultado curioso com array vazio.
  • 📄 Array.prototype.sort() — MDN A função de comparação, o fato de o sort alterar o array e o uso de localeCompare para texto.

  2. Estrutura de Dados: declare const livros com oito objetos { codigo, titulo, autor, ano, atrasado }, incluindo um título que comece com acento.

🧊 3. Imutabilidade: Spread, Desestruturação e Cópias

🎯 Desafio

No app fictício Carrinho Rápido, ao aplicar um cupom de 10% no carrinho, o pedido original também muda de valor — e o suporte não consegue mais mostrar quanto o cliente pagaria sem o cupom. O problema está numa linha que altera os objetos existentes em vez de criar novos. Como aplicar o desconto sem tocar nos dados originais?

Em JavaScript, arrays e objetos são passados por referência: duas variáveis podem apontar para o mesmo dado. Spread e desestruturação permitem criar cópias e extrair campos de forma legível, e entender a diferença entre cópia rasa e profunda evita bugs que só aparecem longe de onde foram criados.

  • 📄 Spread syntax (...) — MDN Como copiar arrays e objetos e sobrescrever só um campo numa linha.
  • 📄 Desestruturação — MDN Extrair campos de objetos e posições de arrays direto nos parâmetros da função.
  • 📄 Array.prototype.slice() — MDN Um método que copia parte do array sem alterar o original, ao contrário do splice.
  • 📄 Shallow copy — Glossário MDN Por que uma cópia rasa ainda compartilha os objetos de dentro com o original.
