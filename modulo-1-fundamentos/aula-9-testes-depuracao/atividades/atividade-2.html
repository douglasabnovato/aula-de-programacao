Nota Dez — Mini Test Runner

Aula 9 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um executor de testes feito à mão, no formato teste/esperar().toBe(), que verifica as funções calcularMedia e situacao. Um checkbox troca >= por > para mostrar os testes pegando a regressão.

Demonstração ao vivo

Arraste a borda inferior para aumentar a área.

script.js

// Início: mini test runner para as regras de média e situação
const introduzirBug = document.querySelector('#introduzirBug');
const placar = document.querySelector('#placar');
const listaResultados = document.querySelector('#resultados');
let resultados = [];

// calcula a média com duas casas decimais (lista vazia vale zero)
const calcularMedia = (notas) => {
  if (notas.length === 0) return 0;
  const soma = notas.reduce((total, nota) => total + nota, 0);
  return Math.round((soma / notas.length) * 100) / 100;
};

// classifica a média; com o bug ativo, usa > onde deveria ser >=
const situacao = (media) => {
  const atingiu = (limite) => (introduzirBug.checked ? media > limite : media >= limite);
  if (atingiu(7)) return 'aprovado';
  if (atingiu(5)) return 'recuperação';
  return 'reprovado';
};

// cria uma asserção no formato esperar(valor).toBe(esperado)
const esperar = (valor) => ({
  toBe(esperado) {
    if (!Object.is(valor, esperado)) {
      throw new Error(`esperava ${JSON.stringify(esperado)}, recebeu ${JSON.stringify(valor)}`);
    }
  }
});

// executa um teste e guarda se passou ou falhou
const teste = (descricao, fn) => {
  try {
    fn();
    resultados.push({ descricao, passou: true });
  } catch (erro) {
    resultados.push({ descricao, passou: false, motivo: erro.message });
  }
};

// declara todos os casos de teste da suíte
const suite = () => {
  teste('média de [7, 8, 9] é 8', () => esperar(calcularMedia([7, 8, 9])).toBe(8));
  teste('média de lista vazia é 0', () => esperar(calcularMedia([])).toBe(0));
  teste('média de [0.1, 0.2] é 0.15', () => esperar(calcularMedia([0.1, 0.2])).toBe(0.15));
  teste('média 7 aprova', () => esperar(situacao(7)).toBe('aprovado'));
  teste('média 6.99 vai para recuperação', () => esperar(situacao(6.99)).toBe('recuperação'));
  teste('média 5 vai para recuperação', () => esperar(situacao(5)).toBe('recuperação'));
  teste('média 4.99 reprova', () => esperar(situacao(4.99)).toBe('reprovado'));
  teste('notas [6, 8] aprovam', () => esperar(situacao(calcularMedia([6, 8]))).toBe('aprovado'));
};

// roda a suíte e mostra o relatório na tela
const rodar = () => {
  resultados = [];
  suite();
  console.assert(resultados.length > 0, 'a suíte não tem testes');
  const falhas = resultados.filter((r) => !r.passou).length;
  placar.textContent = `${resultados.length - falhas} passaram · ${falhas} falharam`;
  placar.className = `sub ${falhas ? 'erro' : 'ok'}`;
  listaResultados.innerHTML = resultados
    .map((r) => `<li class="${r.passou ? 'passou' : 'falhou'}"><span>${r.passou ? 'OK' : 'FALHOU'} — ${r.descricao}</span>${r.motivo ? `<small>${r.motivo}</small>` : ''}</li>`)
    .join('');
};

document.querySelector('#btnRodar').addEventListener('click', rodar);
introduzirBug.addEventListener('change', rodar);
rodar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Leia o relatório com todos os testes passando.
  5. Marque 'Introduzir bug' e veja quais testes falham.

O que observar

  • Só os testes de borda (média exatamente 7 e exatamente 5) pegam o bug: casos 'confortáveis' como 8 passariam nas duas versões.
  • Sem o arredondamento, (0.1 + 0.2) / 2 dá 0.15000000000000002 e o teste de decimais falharia.
  • calcularMedia e situacao são funções puras de regra; a leitura do checkbox é o único ponto que depende da tela, e fica isolada para o experimento.
