Rota Verde — Depurando a Calculadora de Frete

Aula 9 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma calculadora de frete com duas versões do cálculo: a com bug (soma texto com número) e a corrigida. Um checkbox insere a instrução debugger para pausar a execução com o DevTools aberto, e cada cálculo é registrado com console.table.

script.js

// Início: calculadora de frete com bug de tipo para praticar depuração
const formFrete = document.querySelector('#formFrete');
const usarCorrecao = document.querySelector('#usarCorrecao');
const pausar = document.querySelector('#pausar');
const resultado = document.querySelector('#resultado');

// versão com bug: o frete chega como texto e o + concatena
const calcularTotalComBug = (campos) => {
  const subtotal = campos.preco.value * campos.qtd.value;
  const frete = campos.frete.value;
  return subtotal + frete;
};

// versão corrigida: converte cada campo em número na leitura
const calcularTotalCorrigido = (campos) => {
  const subtotal = Number(campos.preco.value) * Number(campos.qtd.value);
  const frete = Number(campos.frete.value);
  return subtotal + frete;
};

// escolhe a versão, pausa se pedido e registra o cálculo no console
const calcular = (evento) => {
  evento.preventDefault();
  const campos = formFrete.elements;
  if (pausar.checked) {
    debugger;
  }
  const total = usarCorrecao.checked ? calcularTotalCorrigido(campos) : calcularTotalComBug(campos);
  console.table([
    { campo: 'preco', valor: campos.preco.value, tipo: typeof campos.preco.value },
    { campo: 'frete', valor: campos.frete.value, tipo: typeof campos.frete.value },
    { campo: 'total', valor: total, tipo: typeof total }
  ]);
  resultado.textContent = `Total: R$ ${total}`;
  resultado.className = `resultado ${typeof total === 'number' ? 'ok' : 'erro'}`;
};

formFrete.addEventListener('submit', calcular);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Abra o DevTools (F12), calcule com os valores padrão e leia a tabela no console.
  5. Marque 'Pausar com debugger', calcule e inspecione as variáveis em Scope.
  6. Marque 'Usar versão corrigida' e calcule de novo.

O que observar

  • A multiplicação converte texto em número sozinha, mas o + com texto concatena: por isso 30 + '10' vira '3010'.
  • O console.table mostra que todo input.value é string, mesmo com type="number".
  • A instrução debugger só pausa com o DevTools aberto; sem ele, o navegador a ignora.
