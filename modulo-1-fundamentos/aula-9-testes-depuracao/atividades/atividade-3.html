Semana Tech — Inscrição com Validação por Exceções

Aula 9 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um formulário de inscrição que valida os dados lançando ErroValidacao, mostra a mensagem no campo certo e separa erro do usuário de falha interna com instanceof. Um checkbox simula um erro de programação para ver o outro caminho.

script.js

// Início: inscrição com validação por exceções e tipos de erro separados
class ErroValidacao extends Error {
  // guarda o campo com problema junto da mensagem
  constructor(campo, mensagem) {
    super(mensagem);
    this.name = 'ErroValidacao';
    this.campo = campo;
  }
}

const formInscricao = document.querySelector('#formInscricao');
const btnEnviar = document.querySelector('#btnEnviar');
const resultado = document.querySelector('#resultado');
const simularFalha = document.querySelector('#simularFalha');

// confere cada regra e lança ErroValidacao na primeira que falhar
const validarInscricao = ({ nome, email, idade }) => {
  if (nome.trim().length < 3) {
    throw new ErroValidacao('nome', 'Informe seu nome com pelo menos 3 letras.');
  }
  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    throw new ErroValidacao('email', 'Informe um e-mail no formato nome@dominio.com.');
  }
  const numero = Number(idade);
  if (!Number.isInteger(numero) || numero < 14 || numero > 99) {
    throw new ErroValidacao('idade', 'Informe a idade em números, entre 14 e 99.');
  }
  return { nome: nome.trim(), email, idade: numero };
};

// monta o comprovante; com a falha simulada, acessa um dado que não existe
const gerarComprovante = (inscricao) => {
  const origem = simularFalha.checked ? undefined : { canal: 'site' };
  return `Inscrição confirmada: ${inscricao.nome} (${inscricao.idade} anos) via ${origem.canal}.`;
};

// limpa mensagens e destaques de todos os campos
const limparErros = () => {
  formInscricao.querySelectorAll('.msg').forEach((msg) => {
    msg.textContent = '';
  });
  formInscricao.querySelectorAll('input').forEach((campo) => campo.classList.remove('invalido'));
};

// valida, gera o comprovante e trata cada tipo de erro
const inscrever = (evento) => {
  evento.preventDefault();
  btnEnviar.disabled = true;
  limparErros();
  try {
    const dados = Object.fromEntries(new FormData(formInscricao));
    const inscricao = validarInscricao(dados);
    resultado.textContent = gerarComprovante(inscricao);
    resultado.className = 'ok';
  } catch (erro) {
    if (erro instanceof ErroValidacao) {
      formInscricao.elements[erro.campo].classList.add('invalido');
      formInscricao.querySelector(`[data-msg="${erro.campo}"]`).textContent = erro.message;
      resultado.textContent = 'Corrija o campo destacado.';
    } else {
      console.error('Falha interna na inscrição:', erro);
      resultado.textContent = 'Algo deu errado do nosso lado. Tente de novo em instantes.';
    }
    resultado.className = 'erro';
  } finally {
    btnEnviar.disabled = false;
  }
};

formInscricao.addEventListener('submit', inscrever);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Envie o formulário vazio, depois com idade abc e com e-mail sem @.
  5. Preencha tudo certo e envie; depois marque 'Simular falha interna' e envie de novo com o console aberto.

O que observar

  • Erros de validação viram mensagem no campo; o TypeError da falha simulada vai para o console.error e o usuário recebe uma mensagem genérica.
  • erro instanceof ErroValidacao só funciona porque a classe estende Error e chama super(mensagem).
  • O finally reabilita o botão tanto no sucesso quanto nos dois tipos de erro.
