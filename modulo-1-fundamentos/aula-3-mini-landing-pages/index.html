📐 1. Estruturação de Seções e Containers no Layout Web

Compreenda a anatomia de uma Landing Page de alta conversão e utilize tags semânticas do HTML5 para dividir e organizar o esqueleto da aplicação.

  • [FUNDAMENTOS] Anatomia de uma Landing Page de Alta Conversão Entendendo a disposição visual e estratégica dos elementos de topo, meio e rodapé.
  • [INICIANTE] Dividindo seções com tags de bloco e linha no HTML5 O uso correto de containers estruturais como <header>, <main>, <section> e <footer>.
  • [INTERMEDIÁRIO] Boas práticas de organização e legibilidade de código Manutenibilidade e clareza na construção da árvore DOM em projetos front-end.
  • [AVANÇADO] Arquitetura de componentes estáticos orientados a páginas reais Padrões de mercado para estruturação e prototipagem de aplicações web corporativas.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Criação de Pastas: Crie a pasta da Aula 3 (modulo-1-fundamentos/aula-3/atividades) e adicione os arquivos base.
  2. Boilerplate HTML5: Configure a estrutura padrão com a tag <meta charset="UTF-8"> e lang pt-BR.
  3. Cabeçalho Semântico: Adicione a tag <header> contendo o logotipo e o menu de navegação (<nav>).
  4. Seção de Destaque: Crie uma seção principal de introdução utilizando a tag <section class="hero">.
  5. Conteúdo de Impacto: Insira o título principal (<h1>) e o subtítulo descritivo (<p>) no Hero.
  6. Botão de Ação: Adicione uma chamada para ação (CTA) principal com link estruturado.
  7. Seção de Recursos: Crie uma seção secundária (<section class="features">) para acomodar os cards de diferenciais.
  8. Rodapé Institucional: Insira o bloco <footer> contendo as informações de copyright e direitos reservados.
  9. Vinculação CSS: Faça a ligação correta do arquivo style.css na seção <head> da página.
  10. Validação Estrutural: Abra o arquivo no navegador e valide a organização limpa dos blocos de texto antes de aplicar estilos.
Concluiu todos os passos?

📦 2. Domínio do Flexbox para Alinhamento e Distribuição

Domine as propriedades avançadas do Flexible Box Layout para alinhar itens, controlar eixos e distribuir espaçamentos de forma fluida.

  • [FUNDAMENTOS] O Guia Definitivo do Flexbox no CSS Compreendendo o funcionamento dos eixos principal e transversal com `flex-direction`.
  • [INICIANTE] Alinhando e Distribuindo com Justify-Content e Align-Items Técnicas visuais essenciais para alinhamento horizontal e vertical de containers.
  • [INTERMEDIÁRIO] Criando Grades Flexíveis com Flex-Wrap e Gap Como quebrar linhas de elementos de forma limpa e espaçadas sem margens complexas.
  • [AVANÇADO] Controle com Flex-Grow, Flex-Shrink e Flex-Basis Ajustes finos de crescimento, encolhimento e dimensionamento proporcional em layouts flexíveis.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Reset e Variáveis: Configure o seletor universal * e defina as variáveis de cores institucionais no :root.
  2. Alinhamento do Header: Aplique display: flex, justify-content: space-between e align-items: center no cabeçalho.
  3. Navegação Flexível: Formate o menu utilizando uma lista horizontal flexível com espaçamento otimizado via gap.
  4. Centralização no Hero: Utilize propriedades Flexbox na seção de destaque para centralizar textos e botões com precisão.
  5. Distribuição de Cards: Configure a seção de recursos com display: flex e flex-wrap: wrap para acomodação fluida.
  6. Proporção e Espaçamento: Defina largura base flexível para os cards de recursos utilizando a propriedade moderna gap.
  7. Estilização de Superfícies: Aplique cores de superfície, bordas discretas e cantos arredondados nos blocos de cards.
  8. Alinhamento do Rodapé: Organize os elementos textuais e institucionais do rodapé com distribuição simétrica.
  9. Unidades Relativas: Ajuste margens e paddings de todos os blocos utilizando unidades proporcionais.
  10. Validação de Layout: Redimensione a largura da janela do navegador para testar a flexibilidade inicial dos blocos.
Concluiu todos os passos?

📱 3. Responsividade e Adaptação para Telas Mobile

Aprenda a utilizar Media Queries para transformar layouts horizontais complexos em experiências verticais otimizadas para smartphones.

  • [FUNDAMENTOS] O que são Media Queries e Design Responsivo Introdução conceitual aos pontos de quebra (breakpoints) e adaptação de interfaces.
  • [INICIANTE] Adaptando colunas para linhas verticais no mobile Como alterar a direção dos eixos flexíveis utilizando regras de `@media`.
  • [INTERMEDIÁRIO] Técnicas de Adaptação de Menus e Blocos Ocultando, exibindo e reorganizando elementos utilitários em telas compactas.
  • [AVANÇADO] Otimização de Performance e Usabilidade Mobile-First Boas práticas profissionais para garantir excelente experiência de navegação em dispositivos móveis.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Configuração do Viewport: Garanta a meta tag de escala responsiva configurada corretamente no <head>.
  2. Bloco de Media Query: Adicione a regra de ponto de quebra para telas menores no final do CSS (@media (max-width: 768px)).
  3. Empilhamento do Header: Altere a direção do cabeçalho de linha para coluna (flex-direction: column) no mobile.
  4. Ajuste de Navegação: Reduza espaçamentos e centralize os links do menu superior para telas compactas.
  5. Proporção Tipográfica: Diminua o tamanho da fonte do título principal (<h1>) no Hero para evitar quebras excessivas.
  6. Coluna Única de Recursos: Mude o comportamento dos cards de recursos para empilhamento vertical total.
  7. Otimização de Padding: Reduza os espaçamentos internos das seções para aproveitar melhor a tela útil do smartphone.
  8. Alinhamento do Rodapé: Centralize os textos institucionais do rodapé para manter a harmonia visual.
  9. Simulação Responsiva: Utilize o modo responsivo das ferramentas de inspecionar do navegador para validar resoluções variadas.
  10. Validação Final: Confirme a transição fluida entre desktop e mobile e conclua a implementação da Aula 3.
Concluiu todos os passos?
