Hábito Diário — Estado Salvo no Navegador

Aula 8 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma grade de hábitos por dia da semana cujo estado é salvo no localStorage a cada clique e restaurado ao abrir a página. A leitura é protegida contra dado corrompido e contra navegadores que bloqueiam o armazenamento.

script.js

// Início: rastreador de hábitos com estado salvo no localStorage
const CHAVE = 'habito-diario:v1';
const DIAS = ['Seg', 'Ter', 'Qua', 'Qui', 'Sex', 'Sáb', 'Dom'];

const grade = document.querySelector('#grade');
const aviso = document.querySelector('#aviso');

// cria o estado inicial com todos os dias desmarcados
const estadoInicial = () => ({
  habitos: ['Beber 2 L de água', 'Estudar 30 min', 'Caminhar'].map((nome) => ({ nome, dias: DIAS.map(() => false) }))
});

// mostra uma mensagem de situação do armazenamento
const avisar = (texto, classe = 'muted') => {
  aviso.textContent = texto;
  aviso.className = classe;
};

// lê o estado salvo, com volta ao inicial se estiver ausente ou inválido
const carregar = () => {
  try {
    const texto = localStorage.getItem(CHAVE);
    if (!texto) return estadoInicial();
    const salvo = JSON.parse(texto);
    avisar('Estado restaurado do navegador.', 'ok');
    return salvo;
  } catch (erro) {
    avisar(`Dado salvo inválido ou armazenamento bloqueado (${erro.name}). Começando do zero.`, 'erro');
    return estadoInicial();
  }
};

let estado = carregar();

// grava o estado atual como texto JSON
const salvar = () => {
  try {
    localStorage.setItem(CHAVE, JSON.stringify(estado));
  } catch (erro) {
    avisar('Não foi possível salvar neste navegador.', 'erro');
  }
};

// redesenha a grade de hábitos a partir do estado
const render = () => {
  const cabecalho = `<tr><th>Hábito</th>${DIAS.map((d) => `<th>${d}</th>`).join('')}<th>Total</th></tr>`;
  const linhas = estado.habitos
    .map((h, hi) => `<tr><td>${h.nome}</td>${h.dias.map((feito, di) => `<td><input type="checkbox" aria-label="${h.nome} ${DIAS[di]}" data-habito="${hi}" data-dia="${di}" ${feito ? 'checked' : ''}></td>`).join('')}<td>${h.dias.filter(Boolean).length}/7</td></tr>`)
    .join('');
  grade.innerHTML = cabecalho + linhas;
};

// alterna um dia de um hábito, salva e redesenha
const aoMarcar = (evento) => {
  const caixa = evento.target.closest('input[data-habito]');
  if (!caixa) return;
  const hi = Number(caixa.dataset.habito);
  const di = Number(caixa.dataset.dia);
  estado = {
    habitos: estado.habitos.map((h, i) => (i === hi ? { ...h, dias: h.dias.map((v, j) => (j === di ? !v : v)) } : h))
  };
  salvar();
  render();
};

// grava um texto inválido na chave para testar a proteção da leitura
const corromper = () => {
  try {
    localStorage.setItem(CHAVE, '{quebrado');
    avisar('Dado corrompido gravado. Recarregue a página para ver a proteção agir.', 'erro');
  } catch (erro) {
    avisar('Armazenamento bloqueado neste navegador.', 'erro');
  }
};

// apaga a chave e volta ao estado inicial
const limpar = () => {
  try {
    localStorage.removeItem(CHAVE);
  } catch (erro) {
    avisar('Armazenamento bloqueado neste navegador.', 'erro');
  }
  estado = estadoInicial();
  avisar('Dados apagados.');
  render();
};

grade.addEventListener('change', aoMarcar);
document.querySelector('#btnCorromper').addEventListener('click', corromper);
document.querySelector('#btnLimpar').addEventListener('click', limpar);
render();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Marque alguns dias e recarregue a página (F5).
  5. Clique em 'Corromper dado salvo' e recarregue de novo.
  6. Abra DevTools › Application › Local Storage para ver a chave habito-diario:v1.

O que observar

  • O localStorage só guarda texto: sem JSON.stringify, o estado viraria [object Object].
  • Com o dado corrompido, o JSON.parse lança SyntaxError, o catch avisa e a página abre com o estado inicial em vez de quebrar.
  • O :v1 na chave permite mudar o formato do estado no futuro sem ler um dado antigo incompatível.
