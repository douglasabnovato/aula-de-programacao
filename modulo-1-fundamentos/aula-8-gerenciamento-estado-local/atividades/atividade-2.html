Feira da Semana — Delegação e Ações

Aula 8 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma lista de compras com botões de aumentar, diminuir e remover em cada item, controlados por um único ouvinte na lista. Os botões carregam data-acao e data-id, e toda mudança passa por despachar, que registra a ação num log.

script.js

// Início: lista de compras com delegação de eventos e ações nomeadas
let estado = {
  proximoId: 4,
  itens: [
    { id: 1, nome: 'Tomate', qtd: 6 },
    { id: 2, nome: 'Alface', qtd: 1 },
    { id: 3, nome: 'Banana (dúzia)', qtd: 2 }
  ]
};

const lista = document.querySelector('#lista');
const log = document.querySelector('#log');
const formItem = document.querySelector('#formItem');
const campoItem = document.querySelector('#campoItem');

// calcula o estado novo para cada tipo de ação, sem alterar o anterior
const atualizar = (atual, acao) => {
  switch (acao.tipo) {
    case 'adicionar':
      return { proximoId: atual.proximoId + 1, itens: [...atual.itens, { id: atual.proximoId, nome: acao.nome, qtd: 1 }] };
    case 'aumentar':
      return { ...atual, itens: atual.itens.map((i) => (i.id === acao.id ? { ...i, qtd: i.qtd + 1 } : i)) };
    case 'diminuir':
      return { ...atual, itens: atual.itens.map((i) => (i.id === acao.id ? { ...i, qtd: Math.max(1, i.qtd - 1) } : i)) };
    case 'remover':
      return { ...atual, itens: atual.itens.filter((i) => i.id !== acao.id) };
    default:
      return atual;
  }
};

// redesenha a lista com os botões marcados por data-attributes
const render = () => {
  lista.innerHTML = estado.itens
    .map((i) => `<li><span>${i.nome}</span><span class="acoes"><button data-acao="diminuir" data-id="${i.id}">-</button><strong>${i.qtd}</strong><button data-acao="aumentar" data-id="${i.id}">+</button><button data-acao="remover" data-id="${i.id}">x</button></span></li>`)
    .join('') || '<li class="muted">Lista vazia.</li>';
};

// aplica uma ação, registra no log e redesenha
const despachar = (acao) => {
  estado = atualizar(estado, acao);
  log.insertAdjacentHTML('afterbegin', `<li>${JSON.stringify(acao)}</li>`);
  render();
};

// único ouvinte da lista: descobre o botão clicado e despacha a ação
const aoClicarNaLista = (evento) => {
  const botao = evento.target.closest('button[data-acao]');
  if (!botao) return;
  despachar({ tipo: botao.dataset.acao, id: Number(botao.dataset.id) });
};

// adiciona um item novo a partir do formulário
const aoEnviarItem = (evento) => {
  evento.preventDefault();
  despachar({ tipo: 'adicionar', nome: campoItem.value.trim() });
  formItem.reset();
};

lista.addEventListener('click', aoClicarNaLista);
formItem.addEventListener('submit', aoEnviarItem);
render();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Adicione dois itens e use os botões + , - e x.
  5. Acompanhe o log de ações e, no DevTools, confira em Elements que a <ul> tem um único ouvinte.

O que observar

  • O ouvinte é registrado uma vez, fora do render: redesenhar a lista não cria ouvintes novos.
  • closest('button[data-acao]') resolve o clique mesmo que ele caia num elemento dentro do botão.
  • atualizar não mexe no DOM nem no estado antigo: recebe estado e ação e devolve o estado novo, o que facilita testar.
