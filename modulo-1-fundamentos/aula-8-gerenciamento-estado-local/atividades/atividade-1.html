Mutirão Digital — Estado Único

Aula 8 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um quadro de tarefas em que tudo o que aparece — contador, filtro ativo e lista — é calculado a partir de um único objeto estado. Toda mudança passa por setEstado, que congela o estado novo e chama render.

script.js

// Início: quadro de tarefas com estado único e função render
const FILTROS = { todas: 'Todas', pendentes: 'Pendentes', feitas: 'Feitas' };

let estado = Object.freeze({
  filtro: 'todas',
  tarefas: [
    { id: 1, texto: 'Revisar o roteiro do vídeo', feita: false },
    { id: 2, texto: 'Comprar cabos HDMI', feita: true },
    { id: 3, texto: 'Montar a apresentação de sexta', feita: false },
    { id: 4, texto: 'Responder e-mails de parceiros', feita: false }
  ]
});

const contador = document.querySelector('#contador');
const filtros = document.querySelector('#filtros');
const lista = document.querySelector('#lista');

// devolve as tarefas visíveis conforme o filtro do estado
const tarefasVisiveis = ({ tarefas, filtro }) => {
  if (filtro === 'pendentes') return tarefas.filter((t) => !t.feita);
  if (filtro === 'feitas') return tarefas.filter((t) => t.feita);
  return tarefas;
};

// substitui o estado por uma versão nova e redesenha a tela
const setEstado = (parcial) => {
  estado = Object.freeze({ ...estado, ...parcial });
  render();
};

// troca o valor de feita de uma tarefa gerando um array novo
const alternarTarefa = (id) => {
  setEstado({ tarefas: estado.tarefas.map((t) => (t.id === id ? { ...t, feita: !t.feita } : t)) });
};

// redesenha contador, filtros e lista a partir do estado
const render = () => {
  const pendentes = estado.tarefas.filter((t) => !t.feita).length;
  contador.textContent = `${pendentes} pendente(s) de ${estado.tarefas.length} tarefas`;
  filtros.innerHTML = Object.entries(FILTROS)
    .map(([valor, rotulo]) => `<button class="${estado.filtro === valor ? 'ativo' : ''}" data-filtro="${valor}">${rotulo}</button>`)
    .join('');
  filtros.querySelectorAll('button').forEach((botao) => {
    botao.onclick = () => setEstado({ filtro: botao.dataset.filtro });
  });
  lista.innerHTML = tarefasVisiveis(estado)
    .map((t) => `<li class="${t.feita ? 'feita' : ''}" data-id="${t.id}"><span>${t.texto}</span><small>${t.feita ? 'feita' : 'pendente'}</small></li>`)
    .join('') || '<li class="muted">Nada por aqui.</li>';
  lista.querySelectorAll('li[data-id]').forEach((item) => {
    item.onclick = () => alternarTarefa(Number(item.dataset.id));
  });
};

render();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Clique nas tarefas e nos filtros e confira o contador.
  5. No console, rode estado.filtro = 'feitas' e veja que nada muda; depois setEstado({ filtro: 'feitas' }).

O que observar

  • O número de pendentes não é guardado: é calculado no render, por isso nunca fica desatualizado.
  • Como o estado é congelado, alterar estado.filtro por fora é ignorado — só setEstado muda a tela.
  • Aqui cada render religa onclick em cada elemento; a atividade 2 troca isso por um único ouvinte.
