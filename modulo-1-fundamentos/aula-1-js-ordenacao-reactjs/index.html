🔎 1. Fundamentos de JavaScript, DOM e Algoritmos

Pratique os conceitos essenciais da linguagem, manipulação de elementos e lógicas de programação diretamente aplicadas no desenvolvimento web moderno.

  • ▶️ Revisando fundamentos do Javascript (em menos de 30 minutos) Uma passada rápida e prática pelos conceitos base, variáveis, tipos e manipulação inicial de elementos por Mayk Brito.
  • ▶️ Estrutura de Dados (A famosa ED que todo dev tem que aprender) Desmistificando a estrutura de dados na computação e entendendo a importância disso para a performance de aplicações reais.
  • ▶️ Array - Estrutura de dados com javascript Compreensão prática de como funcionam os vetores, coleções e sua manipulação nativa eficiente em JavaScript.
  • ▶️ Árvores: O Começo de TUDO | Estruturas de Dados e Algoritmos Introdução conceitual e prática a estruturas hierárquicas complexas para buscas e organização avançada de dados.

Siga os 10 passos abaixo para criar sua aplicação prática aplicando os conceitos dos vídeos:

  1. Configuração do Ambiente: Crie um arquivo index.html e um arquivo script.js vinculados na sua máquina.
  2. Estrutura HTML Base: Adicione um campo de texto (<input>), um botão de adicionar e uma lista (<ul>) vazia na tela.
  3. Seleção de Elementos (DOM): Utilize o document.querySelector para capturar os elementos criados no HTML dentro do seu JavaScript.
  4. Criação da Estrutura de Dados: Declare uma variável do tipo Array (vetor) vazia chamada atividades para armazenar os itens.
  5. Aplicação de Variáveis e Tipos: Crie constantes e variáveis (usando const e let) para gerenciar os valores digitados pelo usuário.
  6. Função de Cadastro: Desenvolva uma função Arrow Function para capturar o valor digitado no input e inseri-lo no array utilizando o método adequado.
  7. Manipulação de Coleções: Utilize métodos de array para garantir que novos itens sejam inseridos de forma limpa e organizada na memória.
  8. Renderização Dinâmica na Tela: Atualize o conteúdo do elemento HTML da lista utilizando template literals para exibir os itens cadastrados.
  9. Simulação de Lógica de Busca: Crie uma pequena função de busca que percorra o array para encontrar e destacar um item específico na tela.
  10. Validação e Testes: Abra o arquivo no navegador, insira dados, teste o fluxo completo e valide o comportamento no Console do Desenvolvedor.
Concluiu todos os passos?

📊 2. Algoritmos de Ordenação em JavaScript

Estude a lógica por trás dos principais métodos de ordenação de elementos para otimizar o desempenho computacional e a resolução de problemas.

  • ▶️ O que é e COMO FUNCIONA o BubbleSort (passo-a-passo) Demonstração visual detalhada de como o algoritmo da bolha realiza as comparações sucessivas e as trocas de posições em um vetor.
  • ▶️ Insertion Sort - Ordenação por Inserção Estudo prático de como o algoritmo constrói a sub-lista ordenada elemento por elemento, semelhante à organização de cartas na mão.
  • ▶️ SelectionSort, demonstração do algoritmo de ordenação por seleção em JavaScript Demonstração aplicada em código JavaScript puro de como buscar o menor elemento a cada ciclo e posicioná-lo corretamente.

Siga os 10 passos abaixo para criar sua aplicação prática de ordenação baseada nos vídeos do bloco:

  1. Ambiente de Testes: Crie um arquivo HTML simples e vincule um script JavaScript dedicado aos testes lógicos de ordenação.
  2. Criação do Vetor Desordenado: Declare um array numérico contendo elementos fora de ordem (ex: [5, 2, 9, 1, 7]).
  3. Função de Troca (Swap): Desenvolva uma lógica auxiliar ou função para alternar as posições de dois elementos dentro de um vetor.
  4. Estrutura de Repetição Aninhada: Configure laços de repetição (como for cruzados) para varrer os elementos comparando vizinhos.
  5. Implementação do BubbleSort: Aplique a lógica do algoritmo da bolha empurrando os maiores valores para o final da matriz a cada passada.
  6. Isolamento do SelectionSort: Crie uma função separada para encontrar o índice do menor elemento do vetor e posicioná-lo no início.
  7. Manipulação de Índices: Utilize variáveis de controle indexadas para rastrear o menor número ou a posição correta de inserção.
  8. Exibição no Console: Utilize console.log() antes e depois da execução de cada algoritmo para validar o estado inicial e final do array.
  9. Interface Visual Opcional: Conecte os arrays ordenados a elementos HTML de lista (<ul>) para exibir a ordenação em tela.
  10. Validação de Performance: Teste diferentes tamanhos de arrays e analise o comportamento de execução de cada método estudado.
Concluiu todos os passos?

🌟 3. Meu Primeiro Projeto em React.js

Dê seus primeiros passos estruturando componentes modulares, entendendo props, estados e criando aplicações ricas em interface com o ecossistema moderno do React.

  • ▶️ 3 CONCEITOS QUE VOCÊ PRECISA DOMINAR | REACTJS Explicação direta e focada nos pilares fundamentais que todo programador iniciante precisa dominar no ecossistema React.
  • ▶️ Ciclo de vida de um componente React e useState Estudo detalhado sobre o comportamento e ciclo de vida dos componentes associados ao gerenciamento de estado com o Hook useState.
  • ▶️ Aprenda REACT HOOKS em 30 minutos | Tutorial sobre Hooks Tutorial intensivo e prático focado em desmistificar o uso dos Hooks do React em meia hora de código.
  • ▶️ Se Você Passar Por Esses 5 Desafios, Você Aprendeu React JS Análise prática baseada em desafios reais para testar se você realmente absorveu os fundamentos essenciais do React.
  • ▶️ PROJETO de React JS para INICIANTES - Faça uma To Do List do zero! Mão na massa construindo uma aplicação completa do zero (Lista de Tarefas) para consolidar o aprendizado na prática.

Siga os 10 passos abaixo para planejar e estruturar seu projeto prático em React.js:

  1. Configuração do Node.js e Vite: Inicialize um projeto moderno utilizando Vite e React no terminal executando npm create vite@latest.
  2. Estrutura de Pastas e Limpeza: Remova arquivos padrões desnecessários e organize a pasta src/ mantendo um padrão limpo.
  3. Compreensão do JSX: Estude como o React mescla a lógica JavaScript com a estrutura visual por meio da sintaxe JSX.
  4. Criação do Primeiro Componente: Desenvolva uma função JavaScript com a primeira letra maiúscula retornando um elemento visual.
  5. Modularização e Importação: Importe e insira o componente criado dentro do componente principal da aplicação (App.jsx).
  6. Utilização de Props: Adicione parâmetros de entrada no seu componente para permitir a customização dinâmica de dados.
  7. Introdução ao Hook useState: Importe o gancho useState para gerenciar estados reativos locais.
  8. Captura de Eventos de Tela: Conecte ações de usuário (cliques e digitação) para disparar as funções de alteração de estado.
  9. Estilização Aplicada: Utilize classes CSS estruturadas para garantir um design limpo e responsivo.
  10. Build e Validação: Execute o empacotamento do projeto e valide o funcionamento completo da aplicação.
Concluiu todos os passos?
