# ⚡ Ementa da Aula 1: JS, Algoritmos de Ordenação e React.js | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa detalha o percurso técnico e prático da primeira aula do Módulo 1, desenhada para guiar o estudante desde os fundamentos essenciais da manipulação de dados em JavaScript até a construção de interfaces reativas modernas utilizando o ecossistema React.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: Fundamentos de JavaScript e Manipulação do DOM
* **Revisão de Sintaxe e Estruturas:** Declaração de variáveis (`const` e `let`), tipos primitivos e organização lógica do código.
* **Seleção e Manipulação de Elementos:** Como capturar e interagir com elementos da página HTML utilizando métodos modernos (`querySelector`).
* **Funções e Eventos:** Criação de *arrow functions* e associação de gatilhos de clique/digitação para manipulação dinâmica de listas.

### 2. Bloco 2: Algoritmos de Ordenação em JavaScript
* **Lógica Computacional:** Introdução ao raciocínio lógico aplicado à ordenação de estruturas de dados (vetores).
* **Algoritmo BubbleSort (Método da Bolha):** Como funcionam as comparações sequenciais e o mecanismo de troca (*swap*) entre elementos adjacentes.
* **Algoritmo SelectionSort:** Lógica de varredura para identificação e posicionamento do menor elemento de um array passo a passo.

### 3. Bloco 3: Introdução ao React.js e Componentes
* **Configuração de Ambiente Moderno:** Utilização de ferramentas performáticas como o **Vite** e organização limpa de arquivos em uma aplicação Node.js.
* **Sintaxe JSX:** Compreensão das regras e integração de marcação HTML dentro do ecossistema JavaScript.
* **Pilares do React:** 
  * *Componentes:* Criação e importação modular de blocos de interface reutilizáveis.
  * *Props:* Passagem de parâmetros e customização dinâmica de dados entre componentes.
  * *Hook useState:* Gerenciamento de estado local para reatividade de tela em tempo real.
