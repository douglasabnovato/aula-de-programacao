Cadastro de Endereço — ViaCEP e POST

Aula 6 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um formulário de cadastro que valida o CEP, consulta o endereço no ViaCEP ao sair do campo, trata o CEP inexistente e envia o cadastro completo com POST para a API de testes JSONPlaceholder.

script.js

// Início: cadastro de endereço com consulta ao ViaCEP e envio por POST
const formEndereco = document.querySelector('#formEndereco');
const campoCep = document.querySelector('#cep');
const aviso = document.querySelector('#aviso');
const CAMPOS_ENDERECO = { rua: 'logradouro', bairro: 'bairro', cidade: 'localidade', uf: 'uf' };

// mostra uma mensagem abaixo do formulário
const avisar = (texto, classe = 'muted') => {
  aviso.textContent = texto;
  aviso.className = classe;
};

// remove tudo que não for dígito do CEP digitado
const limparCep = (valor) => valor.replace(/\D/g, '');

// copia os dados do ViaCEP para os campos do formulário
const preencherEndereco = (dados) => {
  Object.entries(CAMPOS_ENDERECO).forEach(([campo, chave]) => {
    formEndereco.elements[campo].value = dados[chave] || '';
  });
};

// consulta o endereço do CEP no ViaCEP
async function buscarCep() {
  const cep = limparCep(campoCep.value);
  if (cep.length !== 8) {
    avisar('O CEP precisa ter 8 dígitos.', 'erro');
    return;
  }
  avisar('Buscando endereço...');
  try {
    const resposta = await fetch(`https://viacep.com.br/ws/${encodeURIComponent(cep)}/json/`);
    if (!resposta.ok) {
      throw new Error(`status ${resposta.status}`);
    }
    const dados = await resposta.json();
    if (dados.erro) {
      preencherEndereco({});
      avisar('CEP não encontrado. Confira os números.', 'erro');
      return;
    }
    preencherEndereco(dados);
    avisar('Endereço preenchido. Informe o número.', 'ok');
    formEndereco.elements.numero.focus();
  } catch (erro) {
    avisar(`Falha na consulta: ${erro.message}.`, 'erro');
  }
}

// envia o cadastro completo para a API de testes
async function enviarCadastro(evento) {
  evento.preventDefault();
  const cadastro = Object.fromEntries(new FormData(formEndereco));
  avisar('Enviando...');
  try {
    const resposta = await fetch('https://jsonplaceholder.typicode.com/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json; charset=UTF-8' },
      body: JSON.stringify(cadastro)
    });
    const salvo = await resposta.json();
    avisar(`Cadastro recebido (status ${resposta.status}, id ${salvo.id}).`, 'ok');
  } catch (erro) {
    avisar(`Falha no envio: ${erro.message}.`, 'erro');
  }
}

campoCep.addEventListener('blur', buscarCep);
formEndereco.addEventListener('submit', enviarCadastro);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Digite 36010-000 (ou o CEP da sua rua), saia do campo, informe o número e envie.
  5. Repita com 99999-999 e com 123.

O que observar

  • O ViaCEP responde 200 com { "erro": true } para CEP inexistente: é uma regra da API, e só a documentação avisa.
  • O pattern impede o envio de um CEP mal formatado antes de qualquer requisição, sem uma linha de JavaScript.
  • O JSONPlaceholder responde 201 e devolve um id, mas não grava nada de verdade — serve só para praticar o envio.
