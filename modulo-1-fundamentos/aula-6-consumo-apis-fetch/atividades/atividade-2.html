Tarefas por Usuário — os Quatro Estados da Interface

Aula 6 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma busca de tarefas por usuário que mostra quatro estados distintos: carregando, sucesso, vazio (usuário sem tarefas) e erro (status HTTP ou tempo limite). Um checkbox troca a rota por uma inexistente para provocar o 404.

script.js

// Início: busca de tarefas com os estados carregando, sucesso, vazio e erro
const BASE = 'https://jsonplaceholder.typicode.com';

const formBusca = document.querySelector('#formBusca');
const campoUsuario = document.querySelector('#campoUsuario');
const btnBuscar = document.querySelector('#btnBuscar');
const rotaQuebrada = document.querySelector('#rotaQuebrada');
const resultado = document.querySelector('#resultado');

// troca a aparência e o conteúdo da caixa conforme o estado
const mostrarEstado = (tipo, conteudo) => {
  resultado.className = `estado ${tipo}`;
  resultado.innerHTML = conteudo;
};

// monta a lista HTML das tarefas recebidas
const listaDeTarefas = (tarefas) => `<ul class="lista">${tarefas
  .map((t) => `<li><span class="${t.completed ? 'feita' : ''}">${t.title}</span><small>${t.completed ? 'feita' : 'pendente'}</small></li>`)
  .join('')}</ul>`;

// busca as tarefas do usuário e trata cada desfecho
async function buscarTarefas(evento) {
  evento.preventDefault();
  const rota = rotaQuebrada.checked ? 'todoss' : 'todos';
  const usuario = Number(campoUsuario.value);
  btnBuscar.disabled = true;
  mostrarEstado('carregando', 'Carregando tarefas...');
  try {
    const resposta = await fetch(`${BASE}/${rota}?userId=${usuario}`, { signal: AbortSignal.timeout(5000) });
    if (!resposta.ok) {
      throw new Error(`o servidor respondeu com status ${resposta.status}`);
    }
    const tarefas = await resposta.json();
    if (tarefas.length === 0) {
      mostrarEstado('vazio', `O usuário ${usuario} não tem tarefas cadastradas.`);
      return;
    }
    mostrarEstado('sucesso', `<strong>${tarefas.length} tarefas</strong>${listaDeTarefas(tarefas.slice(0, 8))}`);
  } catch (erro) {
    const motivo = erro.name === 'TimeoutError' ? 'a API demorou mais de 5 segundos' : erro.message;
    mostrarEstado('erro', `Não foi possível carregar: ${motivo}.`);
  } finally {
    btnBuscar.disabled = false;
  }
}

formBusca.addEventListener('submit', buscarTarefas);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Busque o usuário 1, depois o 11.
  5. Marque 'Usar rota errada' e busque de novo.

O que observar

  • Com a rota errada, o fetch não rejeita: quem detecta o 404 é o if (!resposta.ok).
  • Vazio não é erro: a requisição deu certo, só não há dados — e a mensagem precisa dizer isso.
  • O finally reabilita o botão até quando o return do estado vazio encerra a função mais cedo.
