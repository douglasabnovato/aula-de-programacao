🏷️ 1. Fundamentos de HTML Semântico e Estruturação de Tags

Compreenda a importância da semântica web utilizando tags corretas para organizar o documento e construir componentes de perfil acessíveis e estruturados.

  • ▶️ O que é HTML Semântico e por que você deve usar Introdução aos elementos semânticos essenciais (`<header>`, `<main>`, `<article>`, `<section>`) para uma web limpa.
  • ▶️ Estruturando uma página web do zero com HTML5 Organização correta de blocos de conteúdo e hierarquia de títulos em aplicações modernas.
  • ▶️ Boas práticas de acessibilidade e SEO com tags semânticas Como motores de busca e leitores de tela interpretam a estrutura do seu código HTML.
  • ▶️ Arquitetura de Documentos e Padrões W3C na Web Moderna Profundidade em árvore de elementos e conformidade com os padrões oficiais da web.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Configuração do Ambiente: Crie uma pasta para a Aula 2 e adicione os arquivos index.html e style.css.
  2. Estrutura Boilerplate: Configure o documento HTML5 com a tag <meta charset="UTF-8"> e lang pt-BR.
  3. Tag Semântica Principal: Adicione a tag semântica <main> para envolver o componente principal de perfil.
  4. Container do Card: Crie um elemento <article> ou <div> que funcionará como o container visual do card.
  5. Foto de Perfil: Insira uma tag <img> para a imagem de avatar do usuário.
  6. Informações de Identidade: Utilize tags de cabeçalho (<h2>) para o nome e (<p>) para a profissão/bio.
  7. Lista de Redes/Contatos: Adicione uma lista semântica (<ul> com <li>) para os links de contato.
  8. Botão de Ação: Insira um botão de ação (<button>) com o texto "Seguir" ou "Entrar em Contato".
  9. Vinculação de Estilos: Faça a ligação correta do arquivo style.css na tag <head> do HTML.
  10. Validação Inicial: Abra o arquivo no navegador e valide a estrutura pura antes de iniciar a estilização CSS.
Concluiu todos os passos?

📦 2. Box Model, Centralização e Layout de Cards no CSS

Domine o Modelo de Caixa (Box Model), margens, preenchimentos e técnicas modernas de centralização para estilizar componentes profissionais.

  • ▶️ Entendendo o CSS Box Model (Margin, Border, Padding) O conceito essencial de espaçamento, dimensões e cálculo de largura em elementos web.
  • ▶️ Como centralizar qualquer coisa no CSS com Flexbox Técnicas modernas e eficientes de alinhamento absoluto e flexível na tela.
  • ▶️ Aplicando Sombreados, Arredondamento e Bordas Modernas Uso refinado de `border-radius`, sombras profundas com `box-shadow` e contornos.
  • ▶️ Gerenciamento de Unidades Responsivas (px, %, rem, vh/vw) Como escolher a unidade ideal para garantir escalabilidade fluida de layouts.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Reset e Box-Sizing: Configure o seletor universal * com box-sizing: border-box e margens zeradas.
  2. Fundo da Página: Defina uma cor de fundo moderna para o corpo (<body>) da aplicação.
  3. Centralização com Flexbox: Centralize o card na tela utilizando display: flex, justify-content: center e align-items: center.
  4. Dimensões do Card: Estilize o container definindo largura máxima, cor de fundo contrastante e bordas estruturadas.
  5. Preenchimento Interno: Aplique padding interno generoso para afastar os textos das bordas do componente.
  6. Profundidade e Arredondamento: Arredonde os cantos com border-radius: 12px e adicione profundidade com box-shadow.
  7. Avatar Circular: Ajuste a imagem de perfil com largura fixa, formato circular (border-radius: 50%) e margem inferior.
  8. Tipografia Refinada: Trabalhe o peso (font-weight), cores e entrelinha (line-height) dos textos.
  9. Estilização de Botões: Formate botões e links internos com alinhamento e respiros visuais adequados.
  10. Validação de Layout: Teste o comportamento do card em diferentes larguras de tela para validar a estabilidade do Box Model.
Concluiu todos os passos?

✨ 3. Estados Interativos, Hover e Transições CSS

Aprenda a utilizar pseudo-classes e propriedades de transição para adicionar micro-interações, dinamismo e feedback visual de excelência.

  • ▶️ O poder das Pseudo-classes no CSS (:hover, :focus, :active) Como alterar o estado visual de elementos com base na interação do usuário.
  • ▶️ Criando Animações e Transições Suaves com CSS Transition Adicionando fluidez e elegância a mudanças de propriedades com transições nativas.
  • ▶️ Efeitos Visuais Avançados em Cards (Elevação e Escala) Uso de transform: translateY() e sombras dinâmicas para simular profundidade.
  • ▶️ Otimização de Performance em Animações CSS (GPU Acceleration) Boas práticas para garantir animações suaves a 60fps sem sobrecarregar o navegador.

Siga os 10 passos abaixo para executar a aplicação prática:

  1. Transição Base: Adicione a propriedade transition: all 0.3s ease no seletor base do card para suavizar alterações.
  2. Pseudo-classe Hover: Crie a regra de interação .card:hover no arquivo de estilos.
  3. Elevação Visual: Aplique uma leve elevação vertical utilizando transform: translateY(-6px).
  4. Aprofundamento de Sombra: Intensifique sutilmente a propriedade box-shadow no hover para simular aproximação.
  5. Destaque de Bordas: Configure transições nas bordas, alterando a cor de contorno ao passar o mouse.
  6. Botão de Destaque: Estilize o botão de ação principal com uma cor vibrante alinhada à identidade visual.
  7. Interação em Botões: Configure o :hover específico do botão com alteração de tom e micro-escala (scale(1.02)).
  8. Links Dinâmicos: Adicione efeitos visuais interativos nos links e ícones das redes sociais.
  9. Teste de Fluidez: Valide a experiência de uso passando o cursor sobre os elementos para garantir respostas sem travamentos.
  10. Finalização: Salve os arquivos de código e confirme o encerramento do laboratório prático da Aula 2.
Concluiu todos os passos?
