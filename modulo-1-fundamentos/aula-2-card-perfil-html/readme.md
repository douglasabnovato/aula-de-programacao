# ⚡ Ementa da Aula 2: Card de Perfil, HTML Semântico e Box Model | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa consolida o percurso prático da segunda aula do Módulo 1, focada na estruturação limpa de documentos web utilizando tags semânticas e no domínio completo do Modelo de Caixa (*Box Model*) para a criação de componentes visuais profissionais e responsivos.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: Fundamentos de HTML Semântico e Estruturação de Tags
* **Semântica Web:** Utilização correta de elementos estruturais (`<header>`, `<main>`, `<article>`, `<section>`).
* **Hierarquia de Documentos:** Organização de títulos, cabeçalhos e seções para otimização de acessibilidade e SEO.
* **Componentização de Perfil:** Montagem da árvore de elementos de um card de perfil utilizando listas e botões nativos.

### 2. Bloco 2: Box Model, Centralização e Layout de Cards no CSS
* **Modelo de Caixa:** Compreensão profunda de `margin`, `border`, `padding` e a propriedade `box-sizing: border-box`.
* **Alinhamento e Posicionamento:** Técnicas modernas de centralização de elementos na tela com **Flexbox**.
* **Estilização Visual:** Aplicação de cantos arredondados (`border-radius`), sombras profundas (`box-shadow`) e unidades responsivas (`rem`, `%`).

### 3. Bloco 3: Estados Interativos, Hover e Transições CSS
* **Pseudo-classes:** Manipulação de estados reativos com `:hover`, `:focus` e `:active`.
* **Transições Suaves:** Uso da propriedade `transition` para criar micro-interações elegantes.
* **Transformações e Elevação:** Aplicação de `transform: translateY()` e efeitos de escala para feedback visual em tempo real.

---

## 🛠️ Aplicação Prática e Dinâmica
