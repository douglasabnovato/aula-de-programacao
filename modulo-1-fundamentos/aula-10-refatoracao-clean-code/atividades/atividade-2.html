Cine Largo — Regras em Um Lugar Só

Aula 10 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma tabela de preços de ingressos em que as regras (preço base e taxa) ficam num único objeto e as variações de ingresso são dados num array. Alterar a taxa na tela recalcula todos os tipos de uma vez.

script.js

// Início: tabela de ingressos com regras centralizadas
const REGRAS_PADRAO = Object.freeze({ PRECO_BASE: 28, TAXA_CONVENIENCIA: 3.5 });

const TIPOS_INGRESSO = [
  { id: 'inteira', nome: 'Inteira', fator: 1, regra: 'preço cheio' },
  { id: 'meia', nome: 'Meia-entrada', fator: 0.5, regra: 'estudantes e idosos' },
  { id: 'crianca', nome: 'Criança até 10 anos', fator: 0.4, regra: 'com responsável' },
  { id: 'professor', nome: 'Professor', fator: 0.5, regra: 'com comprovante' }
];

const formRegras = document.querySelector('#formRegras');
const tabela = document.querySelector('#tabela');

// formata um valor em reais
const formatarMoeda = (valor) => valor.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });

// calcula o preço final de um tipo a partir das regras
const precoDoIngresso = (tipo, regras) => regras.PRECO_BASE * tipo.fator + regras.TAXA_CONVENIENCIA;

// lê as regras da tela, caindo no padrão se o campo estiver vazio
const lerRegras = () => {
  const campos = formRegras.elements;
  return Object.freeze({
    PRECO_BASE: Number(campos.precoBase.value) || REGRAS_PADRAO.PRECO_BASE,
    TAXA_CONVENIENCIA: campos.taxa.value === '' ? REGRAS_PADRAO.TAXA_CONVENIENCIA : Number(campos.taxa.value)
  });
};

// desenha a tabela inteira a partir dos dados e das regras
const renderizar = () => {
  const regras = lerRegras();
  tabela.innerHTML = TIPOS_INGRESSO
    .map((tipo) => `<li><div><strong>${tipo.nome}</strong><small>${tipo.regra} · ${tipo.fator * 100}% do base + taxa</small></div><span class="preco">${formatarMoeda(precoDoIngresso(tipo, regras))}</span></li>`)
    .join('');
};

formRegras.addEventListener('input', renderizar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Mude a taxa de 3,5 para 4 e veja os quatro preços mudarem.
  5. No código, adicione um tipo novo no array TIPOS_INGRESSO e recarregue.

O que observar

  • O preço base e a taxa aparecem uma vez cada: a função precoDoIngresso não tem nenhum número solto.
  • Os tipos de ingresso são dados, não ifs: um tipo novo é um objeto a mais no array.
  • Object.freeze nas regras impede que alguma função altere o preço base sem querer no meio do cálculo.
