Casa do Tempero — Nomes e Funções Pequenas

Aula 10 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma calculadora de pedidos com duas implementações: a função f original, com nomes de uma letra, e a versão refatorada em funções pequenas com nomes do negócio. A tela mostra o resultado das duas e confirma que são idênticos.

script.js

// Início: comparação entre a função f original e a versão refatorada

// versão original, mantida só para comparação de resultados
function f(x, c, d) {
  let y = 0;
  let tmp = 0;
  if (x > 200 && c) {
    y = x * 0.1;
  }
  if (d === 'sede') {
    tmp = x - y >= 150 ? 0 : 12;
  } else if (d === 'regiao') {
    tmp = 25;
  } else {
    tmp = 40;
  }
  return 'Subtotal R$ ' + x.toFixed(2) + ' | desconto R$ ' + y.toFixed(2) + ' | frete R$ ' + tmp.toFixed(2) + ' | total R$ ' + (x - y + tmp).toFixed(2);
}

const LIMITE_DESCONTO_FIDELIDADE = 200;
const PERCENTUAL_DESCONTO_FIDELIDADE = 0.1;
const LIMITE_FRETE_GRATIS = 150;
const FRETE_POR_CIDADE = { sede: 12, regiao: 25, outra: 40 };

// calcula o desconto de fidelidade sobre o subtotal
const calcularDesconto = (subtotal, clienteFiel) => {
  const ganhaDescontoFidelidade = clienteFiel && subtotal > LIMITE_DESCONTO_FIDELIDADE;
  return ganhaDescontoFidelidade ? subtotal * PERCENTUAL_DESCONTO_FIDELIDADE : 0;
};

// calcula o frete conforme a cidade e o valor já com desconto
const calcularFrete = (valorComDesconto, cidade) => {
  const temFreteGratis = cidade === 'sede' && valorComDesconto >= LIMITE_FRETE_GRATIS;
  return temFreteGratis ? 0 : FRETE_POR_CIDADE[cidade];
};

// junta as regras e devolve os números do pedido
const resumirPedido = (subtotal, clienteFiel, cidade) => {
  const desconto = calcularDesconto(subtotal, clienteFiel);
  const frete = calcularFrete(subtotal - desconto, cidade);
  return { subtotal, desconto, frete, total: subtotal - desconto + frete };
};

// transforma o resumo no texto exibido na tela
const formatarMensagem = ({ subtotal, desconto, frete, total }) => [
  `Subtotal R$ ${subtotal.toFixed(2)}`,
  `desconto R$ ${desconto.toFixed(2)}`,
  `frete R$ ${frete.toFixed(2)}`,
  `total R$ ${total.toFixed(2)}`
].join(' | ');

const formPedido = document.querySelector('#formPedido');
const saidaNova = document.querySelector('#saidaNova');
const comparacao = document.querySelector('#comparacao');

// calcula com as duas versões e mostra se os resultados batem
const calcular = (evento) => {
  if (evento) evento.preventDefault();
  const campos = formPedido.elements;
  const subtotal = Number(campos.subtotal.value);
  const clienteFiel = campos.fiel.checked;
  const cidade = campos.cidade.value;
  const textoNovo = formatarMensagem(resumirPedido(subtotal, clienteFiel, cidade));
  const textoAntigo = f(subtotal, clienteFiel, cidade);
  saidaNova.textContent = textoNovo;
  comparacao.textContent = textoNovo === textoAntigo ? 'Resultado idêntico ao da função f original.' : `Diferente da original: ${textoAntigo}`;
  comparacao.className = textoNovo === textoAntigo ? 'ok' : 'erro';
};

formPedido.addEventListener('submit', calcular);
calcular();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Teste subtotais de 100, 180, 220 e 250 nas três cidades, com e sem cliente fiel.
  5. Compare a leitura de f com a de resumirPedido no código.

O que observar

  • Os números 200, 0.1, 150, 12, 25 e 40 ganharam nomes: a regra pode ser lida sem abrir a especificação.
  • Cada função nova faz uma coisa: duas calculam, uma junta os números e uma só monta o texto.
  • A comparação com f na tela é a garantia de que a refatoração não mudou o comportamento.
