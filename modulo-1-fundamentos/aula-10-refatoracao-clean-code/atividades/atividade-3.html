Placar Amador — Refatoração Protegida por Testes

Aula 10 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma tabela de campeonato organizada em três partes — dados, regras e interface — com uma suíte de testes de caracterização. Um checkbox simula uma 'limpeza' que muda o valor do empate, para mostrar os testes denunciando a mudança de comportamento.

script.js

// Início: tabela de campeonato separada em dados, regras e interface

const JOGOS = [
  { casa: 'Unidos do Morro', gols: [2, 1], fora: 'Estrela da Serra' },
  { casa: 'Vila Nova FC', gols: [1, 1], fora: 'Unidos do Morro' },
  { casa: 'Estrela da Serra', gols: [3, 0], fora: 'Vila Nova FC' },
  { casa: 'Atlético Largo', gols: [0, 0], fora: 'Unidos do Morro' },
  { casa: 'Atlético Largo', gols: [2, 2], fora: 'Estrela da Serra' },
  { casa: 'Vila Nova FC', gols: [1, 0], fora: 'Atlético Largo' }
];
const PONTOS = Object.freeze({ VITORIA: 3, EMPATE: 1, DERROTA: 0 });

// cria a linha zerada de um time
const linhaVazia = (time) => ({ time, pontos: 0, jogos: 0, vitorias: 0, empates: 0, saldo: 0 });

// soma o resultado de um jogo na linha de um time
const somarJogo = (linha, golsPro, golsContra, pontos) => {
  const venceu = golsPro > golsContra;
  const empatou = golsPro === golsContra;
  return {
    ...linha,
    jogos: linha.jogos + 1,
    vitorias: linha.vitorias + (venceu ? 1 : 0),
    empates: linha.empates + (empatou ? 1 : 0),
    saldo: linha.saldo + golsPro - golsContra,
    pontos: linha.pontos + (venceu ? pontos.VITORIA : empatou ? pontos.EMPATE : pontos.DERROTA)
  };
};

// ordena por pontos, depois vitórias, depois saldo
const compararTimes = (a, b) => b.pontos - a.pontos || b.vitorias - a.vitorias || b.saldo - a.saldo;

// calcula a tabela completa a partir dos jogos, sem tocar no DOM
const calcularTabela = (jogos, pontos) => {
  const linhas = {};
  jogos.forEach(({ casa, fora, gols: [golsCasa, golsFora] }) => {
    linhas[casa] = somarJogo(linhas[casa] || linhaVazia(casa), golsCasa, golsFora, pontos);
    linhas[fora] = somarJogo(linhas[fora] || linhaVazia(fora), golsFora, golsCasa, pontos);
  });
  return Object.values(linhas).sort(compararTimes);
};

const tabelaHtml = document.querySelector('#tabela');
const refatoracaoErrada = document.querySelector('#refatoracaoErrada');
const placarTestes = document.querySelector('#placarTestes');
const listaTestes = document.querySelector('#listaTestes');

// devolve os pontos em uso, com a versão errada quando o checkbox está marcado
const pontosEmUso = () => (refatoracaoErrada.checked ? { ...PONTOS, EMPATE: 0 } : PONTOS);

// escreve a tabela no HTML
const renderizarTabela = (tabela) => {
  const cabecalho = '<tr><th>#</th><th>Time</th><th>P</th><th>J</th><th>V</th><th>E</th><th>SG</th></tr>';
  tabelaHtml.innerHTML = cabecalho + tabela
    .map((l, i) => `<tr><td>${i + 1}</td><td>${l.time}</td><td><strong>${l.pontos}</strong></td><td>${l.jogos}</td><td>${l.vitorias}</td><td>${l.empates}</td><td>${l.saldo}</td></tr>`)
    .join('');
};

// testes de caracterização: registram o comportamento atual da tabela
const rodarTestes = () => {
  const tabela = calcularTabela(JOGOS, pontosEmUso());
  const linha = (time) => tabela.find((l) => l.time === time);
  const casos = [
    ['Unidos do Morro lidera com 5 pontos', tabela[0].time === 'Unidos do Morro' && tabela[0].pontos === 5],
    ['Estrela da Serra fica à frente de Vila Nova FC pelo saldo', tabela[1].time === 'Estrela da Serra'],
    ['Atlético Largo soma 2 pontos em dois empates', linha('Atlético Largo').pontos === 2],
    ['Vila Nova FC tem saldo -2', linha('Vila Nova FC').saldo === -2],
    ['Todo time jogou 3 partidas', tabela.every((l) => l.jogos === 3)]
  ];
  const falhas = casos.filter(([, passou]) => !passou).length;
  placarTestes.textContent = `${casos.length - falhas} de ${casos.length} testes passaram`;
  placarTestes.className = falhas ? 'erro' : 'ok';
  listaTestes.innerHTML = casos
    .map(([descricao, passou]) => `<li class="${passou ? '' : 'falhou'}"><span>${descricao}</span><strong class="${passou ? 'ok' : 'erro'}">${passou ? 'OK' : 'FALHOU'}</strong></li>`)
    .join('');
  renderizarTabela(tabela);
};

document.querySelector('#btnTestes').addEventListener('click', rodarTestes);
refatoracaoErrada.addEventListener('change', rodarTestes);
rodarTestes();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Leia a tabela e o resultado dos testes.
  5. Marque 'Simular refatoração errada' e veja a tabela e os testes mudarem juntos.

O que observar

  • Com o empate valendo 0, a liderança muda de time e três testes falham — antes de qualquer pessoa perceber na tabela.
  • calcularTabela não conhece o DOM: por isso os testes conseguem chamá-la direto, sem clicar em nada.
  • As três seções (dados, regras, interface) são candidatas naturais a virar três arquivos com import/export no Módulo 2.
