# 📚 Módulo 1: Fundamentos da Programação | ByteClass

## 🎯 Visão Geral do Módulo
Este módulo é a porta de entrada para a formação técnica na **ByteClass**. Ele abrange os pilares essenciais da lógica computacional, manipulação do DOM com JavaScript puro, bases de algoritmos de ordenação e a introdução ao desenvolvimento frontend moderno com React.js.

---

## 🗺️ Trilha de Aulas do Módulo 1

* **Aula 1:** JS, DOM, Algoritmos de Ordenação e React.js *(Disponível)*
* **Aula 2 a 10:** Estruturas de Dados, Funções, Arrays, Assincronicidade, APIs, OOP e Clean Code *(Em Construção)*
* **Aula 11:** Apresentação e Defesa do Projeto Prático A *(Em Construção)*

---

## 🧠 Metodologia de Aprendizagem
Cada aula deste módulo segue o padrão de **Blocos Teóricos com Vídeos de Apoio** seguidos por uma **Prática Guiada de 10 Passos**, garantindo que o aluno construa portfólio e autonomia progressivamente.
