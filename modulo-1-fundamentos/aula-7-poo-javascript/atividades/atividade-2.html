Sala Aberta — Catálogo com Herança

Aula 7 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um catálogo com três tipos de curso que herdam de Curso. Cada classe filha acrescenta seus dados e sobrescreve só o que muda, reaproveitando a mãe com super. O filtro usa instanceof.

script.js

// Início: catálogo de cursos com classe base e classes filhas
class Curso {
  // guarda os dados comuns a todo curso
  constructor(nome, horas, preco) {
    this.nome = nome;
    this.horas = horas;
    this.preco = preco;
  }

  // descrição padrão, reaproveitada pelas filhas
  descricao() {
    return `${this.horas} h`;
  }

  // preço padrão, sem acréscimos
  precoFinal() {
    return this.preco;
  }
}

class CursoGravado extends Curso {
  // acrescenta o tempo de acesso às aulas gravadas
  constructor(nome, horas, preco, mesesDeAcesso) {
    super(nome, horas, preco);
    this.mesesDeAcesso = mesesDeAcesso;
  }

  // complementa a descrição da classe mãe
  descricao() {
    return `${super.descricao()} · gravado · acesso por ${this.mesesDeAcesso} meses`;
  }
}

class CursoAoVivo extends Curso {
  // acrescenta a data de início da turma
  constructor(nome, horas, preco, inicio) {
    super(nome, horas, preco);
    this.inicio = inicio;
  }

  // complementa a descrição da classe mãe
  descricao() {
    return `${super.descricao()} · ao vivo · turma começa em ${this.inicio}`;
  }
}

class CursoPresencial extends Curso {
  // acrescenta cidade e taxa de material
  constructor(nome, horas, preco, cidade, taxaMaterial) {
    super(nome, horas, preco);
    this.cidade = cidade;
    this.taxaMaterial = taxaMaterial;
  }

  // complementa a descrição da classe mãe
  descricao() {
    return `${super.descricao()} · presencial em ${this.cidade}`;
  }

  // soma a taxa de material ao preço da classe mãe
  precoFinal() {
    return super.precoFinal() + this.taxaMaterial;
  }
}

const TIPOS = { gravado: CursoGravado, aovivo: CursoAoVivo, presencial: CursoPresencial };

const cursos = [
  new CursoGravado('HTML e CSS do Zero', 20, 149, 12),
  new CursoAoVivo('JavaScript na Prática', 32, 390, '03/11'),
  new CursoPresencial('Oficina de Git', 8, 120, 'Serra Azul', 30),
  new CursoGravado('Lógica de Programação', 16, 99, 6),
  new CursoPresencial('Montagem de Computadores', 12, 260, 'Vale Verde', 80)
];

const filtroTipo = document.querySelector('#filtroTipo');
const listaCursos = document.querySelector('#listaCursos');

// formata o preço em reais
const moeda = (valor) => valor.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });

// devolve os cursos do tipo escolhido usando instanceof
const filtrar = (tipo) => (tipo === 'todos' ? cursos : cursos.filter((curso) => curso instanceof TIPOS[tipo]));

// desenha os cursos chamando os mesmos métodos em todas as instâncias
const renderizar = () => {
  listaCursos.innerHTML = filtrar(filtroTipo.value)
    .map((curso) => `<li><div><strong>${curso.nome}</strong><small>${curso.descricao()}</small></div><span class="preco">${moeda(curso.precoFinal())}</span></li>`)
    .join('');
};

filtroTipo.addEventListener('change', renderizar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Troque o filtro entre os tipos.
  5. No console, rode cursos[2] instanceof Curso e cursos[2] instanceof CursoGravado.

O que observar

  • O preço da 'Oficina de Git' aparece com a taxa de material somada: só CursoPresencial sobrescreveu precoFinal().
  • Todo curso presencial também é instanceof Curso, porque herda da classe mãe.
  • super.descricao() evita repetir o trecho comum: mudar a classe base muda os três tipos de uma vez.
