Academia Pulso Fit — Classe Aluno

Aula 7 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Um cadastro de alunos em que cada aluno é uma instância da classe Aluno. O IMC, a faixa de IMC e a situação da mensalidade são calculados pelos métodos da própria classe.

script.js

// Início: cadastro de alunos usando a classe Aluno
class Aluno {
  // guarda os dados de cada aluno na instância
  constructor(nome, peso, altura, diaVencimento) {
    this.nome = nome;
    this.peso = peso;
    this.altura = altura;
    this.diaVencimento = diaVencimento;
  }

  // calcula o índice de massa corporal com uma casa decimal
  imc() {
    return Number((this.peso / (this.altura * this.altura)).toFixed(1));
  }

  // classifica o IMC em três faixas
  faixaImc() {
    const valor = this.imc();
    if (valor < 18.5) return 'abaixo';
    if (valor < 25) return 'adequado';
    return 'acima';
  }

  // diz se a mensalidade está em dia na data informada
  estaEmDia(hoje = new Date()) {
    return hoje.getDate() <= this.diaVencimento;
  }

  // monta o texto de resumo usado no card
  resumo() {
    return `IMC ${this.imc()} (${this.faixaImc()}) · vence dia ${this.diaVencimento}`;
  }
}

const alunos = [new Aluno('Rita Guedes', 62, 1.66, 10), new Aluno('Igor Salles', 88, 1.78, 28)];
const formAluno = document.querySelector('#formAluno');
const listaAlunos = document.querySelector('#listaAlunos');

// desenha um card por aluno usando apenas os métodos da instância
const renderizar = () => {
  listaAlunos.innerHTML = alunos
    .map((aluno) => `<li><div><strong>${aluno.nome}</strong><small>${aluno.resumo()}</small></div><span class="${aluno.estaEmDia() ? 'ok' : 'erro'}">${aluno.estaEmDia() ? 'em dia' : 'vencida'}</span></li>`)
    .join('');
};

// cria uma nova instância com os dados do formulário
const cadastrar = (evento) => {
  evento.preventDefault();
  const dados = new FormData(formAluno);
  alunos.push(new Aluno(dados.get('nome'), Number(dados.get('peso')), Number(dados.get('altura')), Number(dados.get('dia'))));
  formAluno.reset();
  renderizar();
};

formAluno.addEventListener('submit', cadastrar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Cadastre um aluno e compare o IMC com uma calculadora.
  5. No console, rode Aluno('Teste', 70, 1.7, 5) sem new.

O que observar

  • Nenhum cálculo acontece fora da classe: a interface só chama resumo() e estaEmDia().
  • Cada new Aluno(...) cria um objeto independente, mas todos compartilham os mesmos métodos.
  • Chamar a classe sem new gera TypeError: Class constructor Aluno cannot be invoked without 'new'.
