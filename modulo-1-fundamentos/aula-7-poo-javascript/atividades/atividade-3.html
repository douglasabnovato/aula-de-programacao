Troco Certo — Carteira com Saldo Protegido

Aula 7 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma carteira digital em que o saldo é um campo privado (#saldo). Ele só muda por depositar e sacar, que aplicam as regras definidas como membros static. O botão 'Alterar saldo direto' mostra que a atribuição externa não tem efeito.

script.js

// Início: carteira digital com saldo encapsulado
class Carteira {
  static LIMITE_SAQUE = 500;

  #saldo = 0;
  #extrato = [];

  // guarda o nome do titular da carteira
  constructor(titular) {
    this.titular = titular;
  }

  // lança erro se o valor não for um número positivo
  static validarValor(valor) {
    if (!Number.isFinite(valor) || valor <= 0) {
      throw new Error('Informe um valor maior que zero.');
    }
  }

  // permite ler o saldo, mas não gravar
  get saldo() {
    return this.#saldo;
  }

  // entrega uma cópia do extrato para ninguém alterar o original
  get extrato() {
    return [...this.#extrato];
  }

  // registra uma movimentação no extrato interno
  #registrar(tipo, valor) {
    this.#extrato.unshift({ tipo, valor, saldo: this.#saldo });
  }

  // soma um valor validado ao saldo
  depositar(valor) {
    Carteira.validarValor(valor);
    this.#saldo += valor;
    this.#registrar('depósito', valor);
  }

  // retira um valor respeitando saldo e limite
  sacar(valor) {
    Carteira.validarValor(valor);
    if (valor > Carteira.LIMITE_SAQUE) {
      throw new Error(`O limite por saque é R$ ${Carteira.LIMITE_SAQUE}.`);
    }
    if (valor > this.#saldo) {
      throw new Error('Saldo insuficiente.');
    }
    this.#saldo -= valor;
    this.#registrar('saque', valor);
  }
}

const carteira = new Carteira('Joana Pires');
const campoValor = document.querySelector('#campoValor');
const saidaSaldo = document.querySelector('#saldo');
const mensagem = document.querySelector('#mensagem');
const listaExtrato = document.querySelector('#extrato');

// formata um valor em reais
const moeda = (valor) => valor.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });

// atualiza saldo e extrato a partir dos getters
const renderizar = () => {
  saidaSaldo.textContent = moeda(carteira.saldo);
  listaExtrato.innerHTML = carteira.extrato
    .map((mov) => `<li><span>${mov.tipo} de ${moeda(mov.valor)}</span><small class="muted">saldo ${moeda(mov.saldo)}</small></li>`)
    .join('');
};

// executa uma operação e mostra sucesso ou o erro da regra
const operar = (acao) => {
  try {
    carteira[acao](Number(campoValor.value));
    mensagem.textContent = 'Operação realizada.';
    mensagem.className = 'ok';
  } catch (erro) {
    mensagem.textContent = erro.message;
    mensagem.className = 'erro';
  }
  renderizar();
};

// tenta mudar o saldo por fora da classe
const burlar = () => {
  carteira.saldo = 999999;
  mensagem.textContent = `Tentativa de gravar 999999 ignorada. Saldo continua ${moeda(carteira.saldo)}.`;
  mensagem.className = 'erro';
  renderizar();
};

document.querySelector('#btnDepositar').addEventListener('click', () => operar('depositar'));
document.querySelector('#btnSacar').addEventListener('click', () => operar('sacar'));
document.querySelector('#btnBurlar').addEventListener('click', burlar);
renderizar();
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Deposite 800, tente sacar 600, depois 900 e depois -10.
  5. Clique em 'Alterar saldo direto'.
  6. No console, rode carteira.extrato.push('fraude') e depois carteira.extrato.length.

O que observar

  • carteira.saldo = 999999 não tem efeito porque só existe get saldo(); em modo estrito isso lançaria TypeError.
  • As três regras (valor positivo, limite, saldo suficiente) vivem dentro da classe: não há como sacar sem passar por elas.
  • O getter extrato devolve uma cópia, então alterar o array recebido não mexe no histórico interno.
