Agenda Vet — Confirmação com async/await

Aula 5 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma tela de confirmação de consulta escrita com async/await: verifica o horário, reserva, trata falhas com try/catch/finally e consulta a disponibilidade de todos os horários com Promise.allSettled.

script.js

// Início: confirmação de agendamento com async/await
const HORARIOS = ['09:00', '10:00', '11:00', '14:00', '15:00'];
const OCUPADOS = ['10:00', '15:00'];

const seletorHorario = document.querySelector('#seletorHorario');
const btnConfirmar = document.querySelector('#btnConfirmar');
const simularQueda = document.querySelector('#simularQueda');
const mensagem = document.querySelector('#mensagem');
const listaHorarios = document.querySelector('#listaHorarios');

// simula a consulta de um horário no servidor
const verificarHorario = (hora) => new Promise((resolve) => {
  setTimeout(() => resolve(!OCUPADOS.includes(hora)), 700);
});

// simula a reserva, que pode falhar se o servidor cair
const reservar = (hora) => new Promise((resolve, reject) => {
  setTimeout(() => {
    if (simularQueda.checked) {
      reject(new Error('servidor de reservas fora do ar, tente de novo'));
      return;
    }
    resolve(`AV-${hora.replace(':', '')}-${Math.floor(Math.random() * 900 + 100)}`);
  }, 900);
});

// mostra uma mensagem com a classe de cor indicada
const avisar = (texto, classe) => {
  mensagem.textContent = texto;
  mensagem.className = classe;
};

// fluxo completo de confirmação, escrito de cima para baixo
async function confirmar() {
  const hora = seletorHorario.value;
  btnConfirmar.disabled = true;
  btnConfirmar.textContent = 'Confirmando...';
  avisar(`Verificando ${hora}...`, 'muted');
  try {
    const livre = await verificarHorario(hora);
    if (!livre) {
      throw new Error(`o horário ${hora} já está ocupado`);
    }
    const protocolo = await reservar(hora);
    avisar(`Consulta confirmada às ${hora}. Protocolo ${protocolo}.`, 'ok');
  } catch (erro) {
    avisar(`Não foi possível confirmar: ${erro.message}.`, 'erro');
  } finally {
    btnConfirmar.disabled = false;
    btnConfirmar.textContent = 'Confirmar';
  }
}

// consulta todos os horários ao mesmo tempo e lista o resultado de cada um
async function verDisponibilidade() {
  listaHorarios.innerHTML = '<li class="muted">Consultando...</li>';
  const resultados = await Promise.allSettled(HORARIOS.map((hora) => verificarHorario(hora)));
  listaHorarios.innerHTML = resultados
    .map((resultado, i) => `<li><span>${HORARIOS[i]}</span><strong class="${resultado.value ? 'ok' : 'erro'}">${resultado.value ? 'livre' : 'ocupado'}</strong></li>`)
    .join('');
}

btnConfirmar.addEventListener('click', confirmar);
document.querySelector('#btnDisponibilidade').addEventListener('click', verDisponibilidade);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Confirme 09:00, depois 10:00.
  5. Marque 'Simular queda' e confirme 11:00: o botão precisa voltar ao normal.
  6. Clique em 'Ver disponibilidade'.

O que observar

  • O código de confirmar lê como uma receita: verifica, decide, reserva. Não há then aninhado.
  • Tanto o throw do horário ocupado quanto a rejeição da reserva caem no mesmo catch.
  • O finally roda nos três cenários, por isso o botão nunca fica travado em 'Confirmando...'.
