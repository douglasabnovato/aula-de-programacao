Pedido com Promises — then, catch e Promise.all

Aula 5 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma tela que monta um pedido a partir de três fontes simuladas. O botão sequencial encadeia then, o paralelo usa Promise.all, e um checkbox faz o frete falhar para testar o catch e o finally.

script.js

// Início: montagem de pedido com Promises, then/catch e Promise.all
const btnSequencial = document.querySelector('#btnSequencial');
const btnParalelo = document.querySelector('#btnParalelo');
const simularFalha = document.querySelector('#simularFalha');
const saida = document.querySelector('#saida');

// cria uma Promise que resolve (ou rejeita) depois de alguns milissegundos
const atraso = (ms, valor, falhar = false) => new Promise((resolve, reject) => {
  setTimeout(() => (falhar ? reject(new Error(valor)) : resolve(valor)), ms);
});

// simula a busca dos dados do cliente
const buscarCliente = () => atraso(800, { nome: 'Marina Tavares', cidade: 'Serra Azul' });

// simula a busca dos itens do pedido
const buscarItens = () => atraso(1200, ['Controle sem fio', 'Headset com microfone']);

// simula o cálculo do frete, com opção de falhar
const calcularFrete = () => (simularFalha.checked
  ? atraso(1000, 'serviço de frete indisponível', true)
  : atraso(1000, '3 dias úteis'));

// habilita ou desabilita os botões durante a busca
const alternarBotoes = (desabilitar) => {
  btnSequencial.disabled = desabilitar;
  btnParalelo.disabled = desabilitar;
};

// prepara a tela e devolve o horário de início
const iniciar = () => {
  saida.textContent = 'Carregando...';
  saida.className = 'saida muted';
  alternarBotoes(true);
  return Date.now();
};

// escreve o pedido completo na tela
const mostrarPedido = ([cliente, itens, frete], inicio) => {
  saida.innerHTML = `<p><strong>${cliente.nome}</strong> (${cliente.cidade})</p><p>Itens: ${itens.join(', ')}</p><p>Frete: ${frete}</p><p class="tempo">Tempo total: ${Date.now() - inicio} ms</p>`;
  saida.className = 'saida ok';
};

// mostra a mensagem de erro de qualquer etapa
const mostrarErro = (erro) => {
  saida.textContent = `Falha: ${erro.message}`;
  saida.className = 'saida erro';
};

// busca as três partes, uma depois da outra
const buscarSequencial = () => {
  const inicio = iniciar();
  const partes = [];
  buscarCliente()
    .then((cliente) => {
      partes.push(cliente);
      return buscarItens();
    })
    .then((itens) => {
      partes.push(itens);
      return calcularFrete();
    })
    .then((frete) => mostrarPedido([...partes, frete], inicio))
    .catch(mostrarErro)
    .finally(() => alternarBotoes(false));
};

// busca as três partes ao mesmo tempo
const buscarParalelo = () => {
  const inicio = iniciar();
  Promise.all([buscarCliente(), buscarItens(), calcularFrete()])
    .then((resultado) => mostrarPedido(resultado, inicio))
    .catch(mostrarErro)
    .finally(() => alternarBotoes(false));
};

btnSequencial.addEventListener('click', buscarSequencial);
btnParalelo.addEventListener('click', buscarParalelo);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Clique em 'Buscar em sequência', anote o tempo, depois em 'Buscar em paralelo'.
  5. Marque 'Simular falha no frete' e repita os dois botões.

O que observar

  • O sequencial leva a soma dos tempos (cerca de 3 s); o paralelo leva o tempo da etapa mais lenta (cerca de 1,2 s).
  • Um único .catch no fim pega a falha de qualquer etapa da cadeia, e o finally reabilita os botões nos dois casos.
  • Com Promise.all, basta uma Promise rejeitar para o conjunto inteiro cair no catch.
