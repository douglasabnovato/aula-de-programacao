Simulador de Espera — Bloqueante x Callback

Aula 5 · Módulo 1: Fundamentos · ByteClass

O que esta atividade entrega

Uma página com três experimentos: uma espera que trava a thread principal, uma consulta simulada com setTimeout e callback, e um teste de ordem de execução. Um contador de cliques mostra se a página está respondendo.

script.js

// Início: comparação entre espera bloqueante e espera com callback
const log = document.querySelector('#log');
const contador = document.querySelector('#contador');
let cliques = 0;

// escreve uma linha no log com o horário atual
const registrar = (texto) => {
  const hora = new Date().toLocaleTimeString('pt-BR');
  log.insertAdjacentHTML('beforeend', `<li><time>${hora}</time><span>${texto}</span></li>`);
};

// soma um clique para mostrar se a página está respondendo
const contarClique = () => {
  cliques += 1;
  contador.textContent = cliques;
};

// trava a thread principal por alguns milissegundos (erro proposital)
const esperarBloqueando = (ms) => {
  const fim = Date.now() + ms;
  while (Date.now() < fim) {
    Math.random();
  }
};

// simula uma consulta lenta e entrega o resultado por callback
const consultarEntrega = (codigo, callback) => {
  setTimeout(() => callback(`Entrega ${codigo}: saiu para entrega`), 2000);
};

// experimento 1: espera que congela a página
const rodarBloqueante = () => {
  registrar('Consulta bloqueante iniciada');
  esperarBloqueando(3000);
  registrar('Consulta bloqueante terminou');
};

// experimento 2: espera entregue ao navegador
const rodarCallback = () => {
  registrar('Consulta com callback iniciada');
  consultarEntrega('RC-204', registrar);
};

// experimento 3: ordem entre código síncrono e setTimeout(0)
const rodarOrdem = () => {
  registrar('1. antes do setTimeout');
  setTimeout(() => registrar('3. dentro do setTimeout de 0 ms'), 0);
  registrar('2. depois do setTimeout');
};

document.querySelector('#btnContador').addEventListener('click', contarClique);
document.querySelector('#btnBloquear').addEventListener('click', rodarBloqueante);
document.querySelector('#btnCallback').addEventListener('click', rodarCallback);
document.querySelector('#btnOrdem').addEventListener('click', rodarOrdem);
// Fim de script.js

Como rodar

  1. Crie uma pasta com os arquivos index.html, style.css e script.js.
  2. Cole cada bloco de código acima no arquivo com o mesmo nome.
  3. Abra o index.html no navegador (duplo clique ou Live Server no VS Code).
  4. Clique em 'Esperar bloqueando' e, logo em seguida, clique várias vezes no contador.
  5. Repita com 'Consultar com callback' e compare.

O que observar

  • Durante a espera bloqueante o contador não muda e nem a linha 'iniciada' aparece: a tela só é redesenhada quando o JavaScript devolve o controle.
  • Na versão com callback, o contador responde durante os 2 segundos e a mensagem chega sozinha no fim.
  • Mesmo com 0 ms, o setTimeout roda depois da linha '2', porque a função vai para a fila e espera a pilha esvaziar.
