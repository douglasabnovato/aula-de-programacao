# ⚡ Ementa da Aula 62: Padrões de Projeto (Design Patterns) em Produção | ByteClass

## 🎯 Visão Geral da Ementa
Esta ementa apresenta os padrões que de fato aparecem em código JavaScript de produção, com o critério de quando usar — e com a advertência sobre o excesso, que é o erro mais comum de quem acabou de estudá-los.

---

## 📋 Tópicos e Conteúdo Programático (O que o aluno vai ver)

### 1. Bloco 1: Padrões de Criação: Factory, Builder e Singleton
* **Factory:** escolher a implementação em tempo de execução, sem o chamador saber qual veio.
* **Builder:** montar objeto complexo em etapas, sem construtor de dez parâmetros.
* **Singleton:** uma instância só, e por que ele é o padrão mais criticado da lista.

### 2. Bloco 2: Padrões Estruturais e Comportamentais no Dia a Dia
* **Adapter:** encaixar uma biblioteca de terceiro sem espalhar a API dela pelo código.
* **Strategy:** trocar algoritmo em tempo de execução, substituindo o `switch` gigante.
* **Observer:** o padrão por trás de todo `addEventListener` e de todo sistema de eventos.

### 3. Bloco 3: O Excesso: Quando o Padrão Piora o Código
* **Abstração especulativa:** a interface criada para uma segunda implementação que nunca veio.
* **Indireção sem ganho:** quando seguir o código exige abrir seis arquivos para achar um `if`.
* **Regra dos três:** por que esperar a terceira repetição antes de abstrair.
