O Custo Real de Cada Índice

Aula 63 · Módulo 7: Avançado (Engenharia e Arquitetura Master) · ByteClass

Índice não é de graça

Toda escrita atualiza todos os índices da tabela. Cinco índices significam cinco estruturas a manter em cada INSERT, UPDATE e DELETE.

O experimento

-- 1. Sem índice
\timing on
INSERT INTO pedidos (cliente_id, status, total)
SELECT (random()*5000)::int, 'novo', 100 FROM generate_series(1,10000);
-- Time: ~180 ms

-- 2. Cinco índices
CREATE INDEX i1 ON pedidos (cliente_id);
CREATE INDEX i2 ON pedidos (status);
CREATE INDEX i3 ON pedidos (criado_em);
CREATE INDEX i4 ON pedidos (total);
CREATE INDEX i5 ON pedidos (cliente_id, status);

-- 3. A mesma inserção
INSERT INTO pedidos (cliente_id, status, total)
SELECT (random()*5000)::int, 'novo', 100 FROM generate_series(1,10000);
-- Time: ~640 ms

Mais de três vezes mais lento. Numa tabela com escrita intensa, isso decide o projeto.

Medindo o espaço

SELECT
  relname AS objeto,
  pg_size_pretty(pg_relation_size(relid)) AS tamanho
FROM pg_stat_user_tables
WHERE relname = 'pedidos';

SELECT
  indexrelname AS indice,
  pg_size_pretty(pg_relation_size(indexrelid)) AS tamanho,
  idx_scan AS vezes_usado
FROM pg_stat_user_indexes
WHERE relname = 'pedidos'
ORDER BY idx_scan;

A coluna vezes_usado é a mais importante: índice com 0 só custa.

A ordem das colunas no índice composto

CREATE INDEX idx_comp ON pedidos (cliente_id, status);

-- Usa o índice: filtra pela primeira coluna
WHERE cliente_id = 42
WHERE cliente_id = 42 AND status = 'pago'

-- NÃO usa: pula a primeira
WHERE status = 'pago'

A analogia é a lista telefônica ordenada por sobrenome e depois nome: dá para achar "Silva, João" e dá para achar todos os "Silva". Não dá para achar todos os "João" sem ler tudo.

Índice parcial: indexe só o que se consulta

-- Se 95% dos pedidos estão finalizados e a aplicação só
-- consulta os pendentes:
CREATE INDEX idx_pendentes ON pedidos (criado_em)
  WHERE status IN ('novo', 'pago');

O índice fica com 5% do tamanho e atualiza só quando o pedido está nesses estados.
